0 导学：这一章在讲什么

第一章给了符号，这一章开始真算输出。问题很朴素：给一个 LTI 连续系统和输入 f(t)，求输出 y(t)。时域里有三条路，本章依次走完：

① 解微分方程（经典法）：直接解 n 阶常系数线性常微分方程。

② 拆响应：把输出拆成“系统自己记住的历史（零输入）”和“输入惹的祸（零状态）”，分别解。

③ 用 h(t) 做卷积：一旦知道冲激响应 h(t)，任意输入的零状态响应就是一次卷积。从此再也不用逐题解方程。

yzs(t) = f(t) * h(t) = ∫−∞∞ f(τ) h(t−τ) dτ

为什么叫“时域分析”？因为全程都在时间轴上做：横轴始终是 t，画图、分段、积分上下限都看得见。代价是：高阶方程难解、积分容易算错。所以第 4、5 章要上变换域，把微分变成乘法。

第 1 节　从电路到方程，从方程到响应

这一节是第一章“系统建模”的正式展开：先把物理系统写成微分方程，再用经典法（齐次解 + 特解）把它解出来。虽然第 5 章有更快的拉普拉斯变换，但经典法是理解“响应由哪几部分组成”的唯一途径。

1.1 数学模型的建立

以 RLC 串联电路为例：以 uS(t) 为激励、uC(t) 为响应，由 KVL 与元件 VAR 列方程，整理得：

LC·d²uC/dt² + RC·duC/dt + uC = uS(2-1)

图 2-1　RLC 串联电路：以 u_{S} 为激励、u_{C} 为响应（PPT 第 3 页）

抽去物理含义，就是n 阶常系数线性微分方程：

a2·d²y/dt² + a1·dy/dt + a0y = f(t)(2-2)

同一个方程也能描述机械减振系统（M 质量、C 阻尼、k 弹簧刚度、x 位移、f 外力）：

M·d²x/dt² + C·dx/dt + k·x = f(t)(2-3)

这就是“相似系统”——物理不同、数学同构。课件还复习了模拟框图（加法器、数乘器、积分器），第二章的框图与第一章完全一致：方程 ↔ 框图是同一件事的两种写法。

1.2 经典解法：完全解 = 齐次解 + 特解

n 阶方程的通解由两部分组成：齐次解 yh（由系统自身决定）与特解 yp（由激励决定）。

y(t) = yh(t) + yp(t)(2-4)

齐次解的形式由特征方程的根决定：

λn + an−1λn−1 + … + a1λ + a0 = 0(2-5)

例 1　y″ + 5y′ + 6y = f(t)，求完全解（课件第 14—15 页）

特征方程：λ² + 5λ + 6 = 0 ⇒ λ₁ = −2，λ₂ = −3，故 yh = C₁e−2t + C₂e−3t。

(1) f(t) = 2e−t，y(0)=2，y′(0)=−1。

　设 yp = Qe−t，代入：Qe−t − 5Qe−t + 6Qe−t = 2e−t ⇒ 2Q = 2 ⇒ Q = 1。

　全解 y = C₁e−2t + C₂e−3t + e−t。代入初值：C₁ + C₂ + 1 = 2；−2C₁ − 3C₂ − 1 = −1。

y(t) = 3e−2t − 2e−3t + e−t , t ≥ 0

(2) f(t) = e−2t，y(0)=1，y′(0)=0。

　注意：−2 是特征单根，特解必须设成 yp = (Q₀ + Q₁t)e−2t。代入得 Q₁ = 1。

　全解 y = (C₁+Q₀)e−2t + C₂e−3t + te−2t；由初值得 C₁+Q₀ = 2，C₂ = −1。

y(t) = 2e−2t − e−3t + t·e−2t , t ≥ 0

点评：C₁ 与 Q₀ 只能合起来定出 2，这正说明“齐次解与特解不能唯一分离”——所以后面要用零输入/零状态来重新分解。

特解形式三不要

· 不要在 α 是特征根时还写 P·eαt，必须乘 t（二重根乘 t²）。

· 不要把特解里的待定常数和齐次解的常数混在一起解——先定特解系数，再代初值定齐次系数。

· 不要忘记“t ≥ 0”的注记：经典解只在激励接入后成立。

1.3 初始值：0₋ 与 0₊ 的区别

初始状态 y(j)(0₋) 是激励接入前一刻的值，反映系统历史，与激励无关；初始值 y(j)(0₊) 是激励接入后一刻的值。两者可能相同，也可能跃变——关键在于方程右端有没有冲激。

系数匹配法（也叫冲激匹配法）就是干这件事的：把 f(t) 代入方程右端，看出现了几阶冲激，再令左右两端的 δ 及其导数系数相等，从而定出哪个初值发生跃变。

为什么只在 [0₋, 0₊] 上积分

对方程两边从 0₋ 到 0₊ 积分。由于区间长度趋于 0，任何有界项积分都为 0，只有含冲激的项会留下“跳跃量”。

∫0₋0₊ y″ dt = y′(0₊) − y′(0₋) , ∫0₋0₊ 2δ(t) dt = 2

于是 y′ 的跃变量 = 右端 δ 的系数；而 y 本身不跃变（因为 ∫y′ dt 在无穷小区间上为 0）。

例 2　y″ + 3y′ + 2y = 2f′ + 6f，f = ε(t)，y(0₋)=2，y′(0₋)=0（课件第 18—19 页）

第一步：把 f = ε(t) 代入右端。因为 ε′(t) = δ(t)，右端变成 2δ(t) + 6ε(t)：

y″ + 3y′ + 2y = 2δ(t) + 6ε(t)

第二步：匹配冲激。右端只有一个 2δ(t)，而左端最高阶是 y″，所以只有 y″ 含 δ(t)，则 y′ 含 ε(t)（即 y′ 跃变），y 连续。

第三步：两边积分并取系数。

y′(0₊) − y′(0₋) = 2 ⇒ y′(0₊) = 2 , y(0₊) = y(0₋) = 2

结论：右端含 δ(t) ⇒ 最高阶导数的次高阶发生跃变，其余连续；右端不含冲激 ⇒ 全部连续。

跳变规则一句话

右端有 δ 就“往下跳一级”：y″ 含 δ ⇒ y′ 跳；y″ 含 δ′ ⇒ y′ 含 δ、y 也跳。

1.4 零输入响应 y_{zi}

零输入响应是没有输入、只靠初始储能撑出来的响应。此时方程右端为 0，是齐次方程；又因为没有激励，所以初值不发生跃变：

yzi(0₊) = yzi(0₋) = y(0₋)(2-6)
例 3　求例 2 系统的零输入响应（课件第 22 页）

齐次方程 yzi″ + 3yzi′ + 2yzi = 0，特征根 −1、−2 ⇒ yzi = C₁e−t + C₂e−2t。

代入 yzi(0₊) = 2，yzi′(0₊) = 0：C₁ + C₂ = 2，−C₁ − 2C₂ = 0 ⇒ C₁ = 4，C₂ = −2。

yzi(t) = 4e−t − 2e−2t , t > 0

1.5 零状态响应 y_{zs}

零状态响应是初始储能为零、只有输入时的响应，所以 yzs(j)(0₋) = 0。它要用非齐次方程解，初值由系数匹配法从 0₋ 推 0₊。

例 4　求例 2 系统的零状态响应（课件第 25—26 页）

方程 yzs″ + 3yzs′ + 2yzs = 2δ(t) + 6ε(t)，且 yzs(0₋) = yzs′(0₋) = 0。

系数匹配：yzs(0₊) = 0；yzs′(0₊) − yzs′(0₋) = 2 ⇒ yzs′(0₊) = 2。

t>0 时右端只剩 6，故特解为常数 p：2p = 6 ⇒ p = 3。

齐次解 D₁e−t + D₂e−2t，代初值 D₁ + D₂ + 3 = 0，−D₁ − 2D₂ = 2 ⇒ D₁ = −4，D₂ = 1。

yzs(t) = −4e−t + e−2t + 3 , t ≥ 0

例 5　给响应贴标签（课件第 30—31 页）

系统 y″ + 5y′ + 6y = f(t)，特征根 −2、−3。

(1) f₁ = 10cos t ⇒ y₁ = 2e−2t − e−3t + cos(t − π/4)。

　　2e−2t − e−3t：固有响应 + 暂态响应；cos(t−π/4)：强迫响应 + 稳态响应。

(2) f₂ = 2e−t ⇒ y₂ = 3e−2t − 2e−3t + e−t。

　　前两项固有、末项强迫；但三项都随时间衰减 ⇒ 全部是暂态响应，没有稳态分量。

(3) f₃ = ε(t) ⇒ y₃ = −e−2t + 3。

　　−e−2t：固有 + 暂态；3：强迫 + 稳态（直流稳态）。

点评：稳态响应不一定“振”，直流也是稳态；判断标准是 t→∞ 时是否残留。

固有响应 ≠ 零输入响应

· 固有响应是按“齐次解”分的，它的系数里混有激励的影响（由初值定系数时用到激励）。

· 零输入响应是按“激励为零”分的，系数只由初始状态决定。

· 两者数值上常常相同（当激励不引起跃变时），但概念依据完全不同，简答题常考这句区别。

第 2 节　冲激响应与阶跃响应：系统的身份证

上一节每换一个输入就要重解一遍方程，太累。本节给出一个“一劳永逸”的办法：先求系统对 δ(t) 的响应 h(t)，之后任意输入的零状态响应都能由 h(t) 卷积出来。所以 h(t) 是系统的身份证——LTI 系统与 h(t) 一一对应。

2.1 定义

h(t) = T[{δ(t)}, {0}] （冲激响应）(2-8)
g(t) = T[{ε(t)}, {0}] （阶跃响应）(2-9)

注意两个定语：零状态（初值为零）、线性时不变（否则 h 不足以刻画系统）。

2.2 h(t) 的求法：h₁ 辅助函数法

难点在于方程右端可能含 f 的导数（例如 4f′ + f）。如果直接把 δ 代进去，右端会出现 δ′，很难匹配。标准做法分两步：

① 先解一个右端只有 δ 的辅助方程，得到 h₁(t)：

h1″ + a1h1′ + a0h1 = δ(t) , h1(0₋) = h1′(0₋) = 0(2-10)

② 再利用线性与微分特性，把原方程的右端“搬”到解上：

h(t) = b2h1″(t) + b1h1′(t) + b0h1(t)(2-11)
第二步为什么成立

原方程是 A(P)y = B(P)f。因为系统 LTI，算子可以“穿过”系统：对 h₁ 有 A(P)h₁ = δ，两边同乘 B(P) 得 A(P)[B(P)h₁] = B(P)δ。

而 B(P)δ 就是原方程在 f=δ 时的右端，故 B(P)h₁ 就是 h(t)。

一句话：右端有几个导数，就把 h₁ 求几次导再组合，不必重新匹配冲激。

例 6　由框图求 h(t)（课件第 35—37 页）

已知框图：f(t) 进加法器得 x″，两级积分得 x′、x；反馈 −3x′ − 2x；输出取 y = −x′ + 2x。

第一步（写方程）：由框图 x″ = f − 3x′ − 2x，即 x″ + 3x′ + 2x = f；又 y = −x′ + 2x。合并消去 x，得系统方程：

y″ + 3y′ + 2y = −f′ + 2f

第二步（求 h₁）：h₁″ + 3h₁′ + 2h₁ = δ(t)，初值 h₁(0₊)=0、h₁′(0₊)=1（δ 的系数）。

　特征根 −1、−2，特解为 0，故 h₁ = C₁e−t + C₂e−2t；代初值得 C₁=1，C₂=−1。

h1(t) = (e−t − e−2t)·ε(t)

第三步（组合）：h = −h₁′ + 2h₁。

h(t) = (3e−t − 4e−2t)·ε(t)

点评：如果不走 h₁ 法，直接对 y″+3y′+2y = −δ′+2δ 匹配冲激，会同时出现 δ′ 与 δ，极易算错。h₁ 法把“求导”这一步挪到最后，风险小得多。

2.3 阶跃响应 g(t)

同样可以用辅助函数 g₁ 求：

g1″ + a1g1′ + a0g1 = ε(t) , g1(0₊) = g1′(0₊) = 0(2-12)
g(t) = b2g1″(t) + b1g1′(t) + b0g1(t)(2-13)

但更常用的是 h 与 g 的微积分关系——因为 ε 是 δ 的积分，而 LTI 系统对积分“照搬”：

g(t) = ∫−∞t h(τ) dτ ⇔ h(t) = dg(t)/dt(2-14)
例 7　沿用例 6 的系统求 g(t)（课件第 42—44 页）

解法一（先求 g₁）：g₁″ + 3g₁′ + 2g₁ = ε(t)，g₁(0₊)=g₁′(0₊)=0。

　t>0 时右端为 1，特解为 0.5，故 g₁ = C₁e−t + C₂e−2t + 0.5；代初值得 C₁=−1，C₂=0.5。

g1(t) = (−e−t + 0.5e−2t + 0.5)·ε(t)

　再组合 g = −g₁′ + 2g₁：

g(t) = (−3e−t + 2e−2t + 1)·ε(t)

解法二（对 h 积分）：直接算 ∫₀ᵗ(3e−τ − 4e−2τ)dτ，结果完全相同。

校验：h = g′ 是否对得上？求出 g′ = (3e−t−4e−2t)ε(t) ✓。

g₁ 的初值为什么是 0

· 因为右端是 ε(t)（有界），在 [0₋,0₊] 上积分为 0，所以 g₁ 及其导数都不跃变，直接取 0₋ 的零值。

· 而 h₁ 的右端是 δ(t)，积分后留下 1，所以 h₁′(0₊) = 1——两者的初值差一个冲激。

h 与 g 的互换

h 积分得 g，g 求导得 h；解题时哪条方便走哪条，通常“先求 h 再积分”更省事。

第 3 节　卷积积分：把 h(t) 变成万能公式

这一节是本章的核心，也是很多人第一次真正“卡住”的地方。好消息是：卷积的推导只有一句话——任意信号都能拆成一串加权冲激；剩下的全是这句话的推论和算法。

3.1 卷积是怎么冒出来的：时域分解

先把 f(t) 用一堆窄矩形去逼近：第 n 个矩形宽 Δ、高 f(nΔ)、位置 nΔ，它的“面积”是 f(nΔ)·Δ。当 Δ→0 时，这个矩形退化成一根冲激：

f(t) = limΔ→0 Σn f(nΔ)·Δ·δ(t − nΔ)(2-15)
f(t) = ∫−∞∞ f(τ)·δ(t − τ) dτ(2-16)

这个式子是恒等式：f(t) 与 δ(t) 卷积等于它自己。它的价值不在计算，而在于把“任意输入”翻译成“冲激的线性组合”。既然是线性的，就可以逐项求响应再叠加：

表 2-8　卷积公式的四步推导

一句话记住卷积的来历

把输入拆成冲激 → 每个冲激引起一个平移的 h → 全部加起来，这个“加起来”就是卷积。

所以卷积不是数学家发明的运算，而是“线性 + 时不变”两条性质的必然结果。

3.2 定义与记号

对定义在 (−∞, ∞) 上的两个函数 f₁、f₂，称下式为它们的卷积积分，记作 f₁ * f₂：

f(t) = ∫−∞∞ f1(τ)·f2(t−τ) dτ = f1(t) * f2(t)(2-18)

三个要点：τ 是积分变量（积完就没了），t 是参变量（结果仍是 t 的函数），积分限可随 f 的区间收缩（实际做题几乎总要重新定限）。另外，卷积存在的前提是两个信号都绝对可积（实际工程信号都满足）。

3.3 图解法：四步 + 分段

图解法不是用来“算得快”，而是用来“看清结构”。四步口诀：换元、反转、平移、积分。

① 换元：把 t 换成 τ，得 f₁(τ)、f₂(τ)。

② 反转：把 f₂(τ) 翻成 f₂(−τ)。

③ 平移：f₂(−τ) 右移 t，得 f₂(t−τ)。（t 是参变量，边移边看）

④ 相乘积分：两图重叠部分相乘，再对 τ 积分——积分限由“重叠区间的端点”决定。

例 8　h(t) 是斜变、f(t) 是矩形，分段求卷积（课件第 56 页）

已知：h(τ) = τ（0<τ<2），f(t) 是 0~1 上高 1/2 的矩形，求 yzs = h * f。

思路：把 h 换元成 h(τ)、f 换元成 f(τ) 再反转平移成 f(t−τ)，看它与 h(τ) 的重叠区间。

① t<0 或 t>3：两图不重叠，yzs = 0。

② 0 ≤ t ≤ 1：重叠区 τ ∈ [0, t]。

yzs(t) = ∫0t τ·(1/2) dτ = t²/4

③ 1 ≤ t ≤ 2：重叠区 τ ∈ [t−1, t]。

yzs(t) = ∫t−1t τ/2 dτ = t/2 − 1/4

④ 2 ≤ t ≤ 3：重叠区 τ ∈ [t−1, 2]。

yzs(t) = ∫t−12 τ/2 dτ = −t²/4 + t/2 + 3/4

校验：t=2 处峰值为 −1+1+0.75 = 0.75；t=1 处两段相接：1/4 = 1/2−1/4 ✓。

例 9　只求某一时刻的值：y(6)（课件第 57—58 页）

已知：f₁ 在 2~4 幅 1、4~6 幅 2；f₂ 在 1~3 幅 2。求 y(6) = f₁ * f₂ 在 t=6 的值。

关键：只要一个点，就不必求整条曲线——固定 t=6，看 f₂(6−τ) 与 f₁(τ) 的重叠。

f₂(6−τ) 非零要求 1 ≤ 6−τ ≤ 3 ⇒ 3 ≤ τ ≤ 5，与 f₁ 在 3~5 段（幅 1 与 2）重叠。

y(6) = ∫34 1×2 dτ + ∫45 2×2 dτ = 2 + 4 = 6

点评：图解法在“求某点值”时最省力；但定限是唯一难点，务必画图。

3.4 代数性质与复合系统

卷积满足乘法的三条运算律，这让“系统互联”变得极好算：

f1*f2 = f2*f1 （交换律）(2-19)
f1*(f2+f3) = f1*f2 + f1*f3 （分配律）(2-20)
(f1*f2)*f3 = f1*(f2*f3) （结合律）(2-21)

于是系统互联可以写成 h 的运算：

并联：h(t) = h1(t) + h2(t)(2-22)
级联：h(t) = h1(t)*h2(t) = h2(t)*h1(t)(2-23)
为什么级联可以交换次序

因为卷积满足交换律。物理上“先过滤波器再放大”与“先放大再滤波”结果相同——这正是 LTI 系统可以任意级联的理论依据（也是第 5 章框图化简的基础）。

3.5 奇异函数的卷积特性

δ 和 ε 与任何函数卷积都有极简结果，这组公式必须背熟——它们是化简一切卷积的“快捷方式”。

f(t)*δ(t) = f(t) （重现性质）(2-24)
f(t)*δ(t−t0) = f(t−t0)(2-25)
f(t)*δ′(t) = f′(t) , f(t)*δ(n)(t) = f(n)(t)(2-26)
f(t)*ε(t) = ∫−∞t f(τ) dτ(2-27)
ε(t)*ε(t) = t·ε(t)(2-28)

理解方式：卷积 δ 是“照镜子”，卷积 δ′ 是“求导”，卷积 ε 是“积分”。所以卷积能把微分、积分运算“外部化”，这正是 3.6 节微积分性质的来源。

别把“卷积 δ′”和“乘 δ′”搞混

· 卷积 δ′(t)：f(t)*δ′(t) = f′(t)，是求导。

· 相乘 δ′(t)：f(t)·δ′(t) = f(0)δ′(t) − f′(0)δ(t)，是取样。

· 一个用星号、一个用点号，意义完全相反，考试专挑这个字眼。

3.6 微积分性质与那个著名陷阱

既然“卷积 δ′ = 求导”“卷积 ε = 积分”，那么导数和积分可以在两个函数之间随意搬家：

[f1*f2]′ = f1′*f2 = f1*f2′(2-29)
∫−∞t[f1*f2]dτ = f1(−1)*f2 = f1*f2(−1)(2-30)
f1*f2 = f1′*f2(−1) （需 f1(−∞) = 0 或 f2(−1)(∞) = 0）(2-31)
套公式套出 0 的经典错题（课件第 66 页）

题目：f₁(t) = 1，f₂(t) = e−tε(t)，求 f₁ * f₂。

正解：∫−∞∞ 1·e−(t−τ)ε(t−τ)dτ = ∫−∞t e−(t−τ)dτ = 1。

错解：套 f₁′*f₂(−1) = 0 * f₂(−1) = 0。错在哪？前提 f₁(−∞) = 0 不成立（常数 1 在 −∞ 处不为 0）。

教训：微积分性质不是无条件成立的，用之前先查前提。

例 10　矩形与指数卷积：用一个求导、另一个求积分（课件第 66 页）

已知：f₁ 是 0~2 上高 1 的矩形，f₂ = e−tε(t)，求 f₁ * f₂。

第一步：矩形求导变两根冲激：f₁′(t) = δ(t) − δ(t−2)。

f2(−1)(t) = (1 − e−t)·ε(t)

第二步：用 f₁*f₂ = f₁′*f₂(−1)，即把冲激“贴”到 f₂(−1) 上（重现 + 时移）：

f1*f2 = (1 − e−t)ε(t) − [1 − e−(t−2)]ε(t−2)

点评：把矩形求导成冲激，是化简卷积最常用的一招——积分的活儿全丢给另一边。

3.7 时移特性

两个信号各自时移后卷积，等于原卷积整体平移（位移相加）：

f1(t−t1)*f2(t−t2) = f(t − t1 − t2)(2-32)
例 11　两个矩形脉冲卷积（课件第 69 页）

已知：f₁ = 2[ε(t) − ε(t−1)]（0~1 幅 2），f₂ = ε(t+1) − ε(t−1)（−1~1 幅 1）。

展开成四项（分配律），再用 ε*ε = tε(t) 和时移特性逐项写：

f1*f2 = 2(t+1)ε(t+1) − 2(t−1)ε(t−1) − 2tε(t) + 2(t−2)ε(t−2)

点评：矩形乘矩形是“最容易设陷阱”的题型——四个时移项少写一项就全错。建议先画两条矩形，确认输出总长度 = 两矩形长度之和。

第 4 节　相关函数：两个信号有多像

卷积问的是“系统对输入做了什么”，相关问的是“两个信号像不像”。它在雷达、通信同步、信号识别里是核心工具，而算法上又与卷积几乎一样。

4.1 互相关与自相关

为了比较 f₁(t) 与“延迟了 τ 的 f₂(t)”有多相似，定义互相关函数：

R12(τ) = ∫−∞∞ f1(t)·f2(t−τ) dt = ∫−∞∞ f1(t+τ)·f2(t) dt(2-35)
R21(τ) = ∫−∞∞ f1(t−τ)·f2(t) dt = ∫−∞∞ f1(t)·f2(t+τ) dt(2-36)

记号约定（很容易记反）：下标中数字在前的信号，领先 τ。即 R₁₂ 表示 f₁ 领先 f₂ 的时间为 τ。

当两个信号是同一个信号时，互相关退化为自相关函数：

R(τ) = ∫−∞∞ f(t)·f(t−τ) dt , R(τ) = R(−τ)（实信号的偶函数）(2-37)

4.2 性质：互相关与自相关的关系

R12(τ) = R21(−τ)(2-38)

一般 R₁₂(τ) ≠ R₂₁(τ)，两者互为“时间反转”。自相关是偶函数，且在 τ=0 处取最大值——这很直观：一个信号与“没有延迟的自己”最像。

4.3 相关与卷积的比较

把互相关定义式里的 t 与 τ 互换，就能和卷积摆在一起看：

f1(t)*f2(t) = ∫ f1(τ)·f2(t−τ) dτ(2-39)
R12(t) = ∫ f1(τ)·f2(τ−t) dτ(2-40)

差别只有一个：卷积要反转，相关不反转；移位、相乘、积分三步完全相同。由此得到两者最实用的换算关系：

R12(t) = f1(t) * f2(−t)(2-41)

也就是说：相关 = 与“反折后的另一个信号”做卷积。所以卷积会的，相关一定会；反过来，用卷积的公式算相关也完全合法。

4.4 应用：雷达测距

雷达发出 f₁(t)，目标回波是延迟了 τd 的 f₂(t−τd)。把回波与发射信号做互相关，相关峰的位置就是延迟：

R12(τ) 的峰值出现在 τ = τd , 距离 d = c·τd/2(2-42)

除 2 是因为电磁波一去一回。相关峰的尖锐程度还反映测距精度——信号带宽越大，峰越尖，分辨力越高（这一点在第 4 章频域里会再遇到）。

第 5 节　微分算子描述（选学，为第 5 章铺路）

把微分写成“算子”的形式，可以把微分方程暂时当成代数方程来搬弄，这是第 5 章引入 s 域（拉普拉斯变换）的直系前身。

5.1 微分算子 P

P 只代表微分运算，P 不是变量：

P = d/dt , Pn = dn/dtn , 1/P = ∫−∞t(·)dτ(2-43)

于是 n 阶微分方程可以写成算子方程：

(Pn + an−1Pn−1 + … + a0)·y(t) = (bmPm + … + b0)·f(t)(2-44)

5.2 算子的四条性质

① P 的正幂多项式可以因式分解（和代数多项式一样）。

② 两个正幂多项式可以交换：A(P)B(P) = B(P)A(P)。

③ 算子方程两边的公因子不能随意消去。

④ 分子分母同乘 D(P) 可以，但反过来“先作用 D(P) 再约去”一般不等。

第 ③、④ 条是最反直觉的，看反例：

Py(t) = Pf(t) ⇏ y(t) = f(t)(2-45)
P[(1/P)f(t)] = f(t) , 但 (1/P)[Pf(t)] ≠ f(t)(2-46)

前者的意思是“导数相同”只说明两者差一个常数，不能直接约掉 P；后者说明“先积分再微分”会丢掉常数项。第 5 章的拉氏变换之所以要引入初值，本质就是在补这个“丢掉的常数”。

5.3 传输算子 H(P)

把算子方程写成 A(P)y = B(P)f，就能形式上“解”出 y：

y(t) = [B(P)/A(P)]·f(t) = H(P)·f(t)(2-47)
H(P) = (bmPm + … + b0) / (Pn + an−1Pn−1 + … + a0)(2-48)

H(P) 叫传输算子，它就是第 5 章系统函数 H(s) 的“算子版”。

双网孔电路：网孔 Ⅰ 含 1 Ω、1 H、1 F，网孔 Ⅱ 含 1 F 与 2 H、1 Ω，激励 Us(t) 在网孔 Ⅰ。

列网孔方程（把 R、PL、1/PC 当阻抗）：

(1 + P + 1/P)·i1 − (1/P)·i2 = Us

−(1/P)·i1 + (2P + 1/P + 1)·i2 = 0

化成对称形式（两边同乘 P，并令变量为 (1/P)i₁、(1/P)i₂），再用克莱姆法则解得：

i1 = (2P²+P+1)/(2P³+3P²+4P+2) · Us

i2 = 1/(2P³+3P²+4P+2) · Us

结论：H₁(P) = (2P²+P+1)/(2P³+3P²+4P+2)，H₂(P) = 1/(2P³+3P²+4P+2)。

点评：这套流程与“相量法求交流电路”几乎一模一样，只是 jω 换成了 P。第 5 章把 P 换成 s，就得到系统函数——这就是为什么第 5 章可以“不算微分方程”。

第 5 章的雏形

6.1 六条核心结论

① LTI 系统的全部信息都在 h(t) 里：yzs = f * h。

② 解方程要分两路：零输入走齐次方程（初值照搬），零状态走非齐次方程（初值靠匹配）。

③ 0₋ 与 0₊ 的分水岭是冲激：右端有 δ，初值就跃变一级。

④ 卷积的本质是“分解—叠加”，图解法的作用是定限，公式法的前提是背熟九条常用式。

⑤ 相关与卷积只差一个反转：R₁₂(t) = f₁(t) * f₂(−t)。

⑥ 时域法直观但计算重；第 5 章用拉氏变换把微分变乘法，就是为了绕开这些积分。

7 自测题（含详解）

1. 已知 y″ + 4y′ + 3y = f(t)，求特征根，并写出齐次解的一般形式。

2. 方程 y″ + 3y′ + 2y = 2δ(t) + 6ε(t)，y(0₋)=1、y′(0₋)=0，求 y(0₊) 与 y′(0₊)。

3. 已知系统 h(t) = e−3tε(t)，求阶跃响应 g(t)。

4. 计算 e−tε(t) * e−2tε(t)。

5. 计算 ε(t) * e−2tε(t) 的另一种做法：说明为什么可以直接用公式 ⑧。

6. 两个矩形：f₁ 在 0~2 高 1，f₂ 在 0~1 高 1，求卷积结果的形状、底宽与峰高。

参考答案与解析

1. λ² + 4λ + 3 = 0 ⇒ λ₁ = −1，λ₂ = −3；yh = C₁e−t + C₂e−3t。

2. 右端含 2δ(t)，故最高阶 y″ 含冲激，y′ 跃变、y 连续：y(0₊) = 1，y′(0₊) = y′(0₋) + 2 = 2。

3. g(t) = ∫₀ᵗ e−3τdτ·ε(t) = (1/3)(1 − e−3t)ε(t)。

4. 用公式 ⑦（a₁=1，a₂=2）：(e−t − e−2t)/(2−1)·ε(t) = (e−t − e−2t)ε(t)。

5. 因为 ε(t) 与 e−2tε(t) 都是因果的，满足 f₁(0₋)=0，故卷积 ε 等于对另一端积分，公式 ⑧ 就是这一步的结果：(1/2)(1−e−2t)ε(t)。

6. 不等宽矩形卷积 ⇒ 梯形：下底 = 2+1 = 3，上底 = 2−1 = 1，高 = min(2,1) = 1，拐点在 ±0.5 处。
