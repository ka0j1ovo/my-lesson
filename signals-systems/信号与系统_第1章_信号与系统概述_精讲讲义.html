0 导学：这一章在讲什么

先问三个问题：机器吃什么？吐什么？中间做了什么？把一台“信号的加工机”想清楚，这门课就学完一半——吃进去的叫激励 f(t)，吐出来的叫响应 y(t)，中间那台机器就是系统。整个《信号与系统》，研究的就是这三者的关系。

f(t) → [ 系统 ] → y(t)

第一章不急着算题，它的任务是造语言：给信号起名字（分类）、定义两个“万能零件”（ε 和 δ）、约定几种动作（翻转、平移、伸缩）、再给系统立三条规矩（线性、时不变、因果）。语言造好了，第二章才开始算“输出长什么样”。

0.1 本章必须拿下的五件事

① 分类判据：确定/随机、连续/离散、周期/非周期、能量/功率、因果/反因果——每类都会问“这个信号属于哪一类”。

② 两个奇异信号：ε(t) 与 δ(t) 的定义、性质、互求关系（δ = dε/dt），以及取样、冲激偶、尺度变换三组公式。

③ 信号运算的作图：反转、平移、尺度变换的次序，以及复合变换 f(at+b) 的规范做法。

④ 系统三性质：线性的三个条件、时不变的判定、因果的判定。

⑤ LTI 的微积分特性：输入求导，输出也求导；输入积分，输出也积分。这条性质是后面卷积和微分方程解法的地基。

第 1 节　信号、消息与信息：三个词的分工

1.1 为什么先分清这三个词

教材开篇用三级递进定义这门课的研究对象（课件第 3—4 页）：消息（message）是来自外界的各种报道；信息（information）是消息中有意义的内容；信号（signal）是信息的载体，通过信号把信息传出去。

三者关系可以这样记：消息是“原材料”，信息是“有用的那部分”，信号是“装它的箱子”。工程上我们真正能测量、能运算的是信号，所以全书只跟信号打交道。

1.2 系统：信号的加工装置

信号的产生、传输和处理需要物理装置，这样的装置就叫系统。系统的基本作用只有一句话：对输入信号进行加工处理，转换成所需要的输出信号。所以画系统永远是一个方框加两个箭头：左边进 f(t)，右边出 y(t)。

课件举了两个典型例子，值得体会“同一套数学、不同的物理”：

• 弹簧系统（第 7 页）：弹簧刚度 k，下端挂质量 M。输入是拉力 f(t)，输出是长度 y(t)。拉力拉着质量块上下振荡，长度绕静长 L0 波动——这是一个二阶系统，和 RLC 电路同方程。

• 通信系统（第 8 页）：信息源 → 发送设备 → 传输信道 → 接收设备 → 受信者，五环节串联。

• 控制系统（第 8 页）：给定参数 → 运算装置 → 控制器 → 受控对象 → 输出，同时把受控对象的实际参数经测量设备反馈回运算装置——这就是闭环。

为什么要强调“反馈”？因为反馈把系统从“单向加工”变成了“自我修正”，而反馈系统的稳定性分析，正是后续《模拟集成电路设计》里运放稳定性那一套东西的源头。课件第 9—10 页专门讲了这条链路：模电里单级/两级放大器只有 1~2 个零极点，到了这门课要把每级都化到频域、用系统函数描述、判断多零极点情况，再到模电/数电里去“工程化地摆布零极点”。

为什么这门课值得学

后续课程里所有“滤波、采样、调制解调、混合信号分析”，本质都是在算信号经过系统后变成什么。

这门课提供的是通用语言：同一套 f(t)、h(t)、H(s)，既能描述电路，也能描述机械、声学、控制系统。

2.1 确定信号与随机信号

确定信号：可以用确定的时间函数表示，给定 t 就能算出唯一的值。随机信号：不能用确切函数描述，只能知道统计特性（概率分布、均值、方差），例如电子系统里的起伏热噪声、雷电干扰。

本课程只研究确定信号——不是因为随机信号不重要，而是因为随机信号要用概率论和随机过程，那是另一门课（《随机信号分析》）的内容。

2.2 连续信号与离散信号

连续时间信号：在连续时间范围 (−∞, ∞) 内有定义，简称连续信号；如果函数值也连续，常称为模拟信号。离散时间信号：仅在一些离散瞬间有定义，简称离散信号；当取值也被限定为规定数值时，常称为数字信号（狭义）。

离散信号的数学描述要抓住“等间隔”这个约定：

Tk = tk+1 − tk , 取等间隔 T 时 f(kT) 简写为 f(k)(1-1)

k 称为序号；f(k) 这种等间隔离散信号也常称为序列。

图 1-1　连续信号经等间隔采样得到离散信号（PPT 第 19 页）

序列有两种写法（课件第 18 页），本质相同：分段函数式与带箭头的集合式。集合式里箭头指向 k=0 那一位，这是约定俗成的“原点标记”。

f(k) = {…, 0, 1, 2, −1.5, 2, 0, 1, 0, …} , 箭头指 k=0(1-2)

对应 f(−1)=1、f(0)=2、f(1)=−1.5、f(2)=2、f(3)=0、f(4)=1，其余为 0。

离散与连续之间的桥梁（课件第 19—21 页）是本课程反复出现的主题：连续信号经采样变离散（f(k)=f(kT)）；离散变连续则要“保持”：

• 零阶保持：把每个样值保持一个采样周期 T，得到阶梯波。阶梯的跳变相当于引入了大量阶跃/方波成分，即高频噪声，实际电路里必须加滤波器。

• 分段线性：把相邻样值用直线连起来，得到折线。比零阶保持平滑，但需要更多硬件。

离散信号 ≠ 数字信号

· 离散说的是时间离散；数字说的是幅值也离散（量化）。

· 所以“时间离散、幅值连续”的信号是离散信号但不是数字信号；课件第 16 页右图那个方波，时间连续、幅值离散，属于“广义的数字信号”。

· 考试常在这里设陷阱：问“离散信号一定是数字信号吗？”——答：不一定。

2.3 周期信号与非周期信号

周期信号是定义在 (−∞, ∞) 上、每隔一定时间 T 按相同规律重复的信号；不具有周期性的叫非周期信号。

f(t) = f(t + mT) , m = 0, ±1, ±2, …(1-3)
T = 2π/ω (s) , ω 为角频率(1-4)

连续正弦/余弦是最典型的周期信号。

离散信号的周期用整数 N 描述：f(k) = f(k + mN)，N 为正整数。注意离散正弦 sin(Ωk) 未必是周期的——只有当 2π/Ω 为有理数时才是，这一点比连续情形容易翻车。

2.3.1 两个周期信号相加还是周期的吗？

这是本章第一个必考小题。结论：设两信号周期分别为 T1、T2，若 T1/T2 为有理数，则和信号仍是周期的，其周期为 T1 与 T2 的最小公倍数；若 T1/T2 为无理数，则和信号非周期。

例 1（课件第 24 页）判断下列信号是否周期，若是求周期

(1) f1(t) = sin 2t + cos 3t；(2) f2(t) = cos 2t + sin πt。

解 (1)：T1 = 2π/ω1 = 2π/2 = π s；T2 = 2π/ω2 = 2π/3 s。

T1/T2 = π ÷ (2π/3) = 3/2，为有理数，故 f1(t) 是周期信号，周期取最小公倍数：T = 2π s。

解 (2)：T1 = 2π/2 = π s；T2 = 2π/π = 2 s。

T1/T2 = π/2，为无理数，故 f2(t) 是非周期信号。

点评：不要把“最小公倍数”理解成“最大公约数”；也不要用数值近似去判有理——π/2 里带 π 就是无理。

一句话记住周期判定

周期之比为有理数 ⇔ 和信号周期存在，周期 = 各周期的最小公倍数。

口诀：有理才周期，无理由它去。

2.4 能量信号与功率信号

把信号 f(t) 加在 1 Ω 电阻上，瞬时功率就是 |f(t)|²，于是能量和平均功率自然定义为：

E = ∫−∞∞ |f(t)|2 dt(1-5)
P = limT→∞ (1/T) ∫−T/2T/2 |f(t)|2 dt(1-6)

能量信号：E < ∞（此时必有 P = 0），例如短暂的音频脉冲。功率信号：P < ∞（此时必有 E = ∞），例如直流供电、家用交流电。离散信号把积分换成求和：E = Σ|f(k)|²，P = lim (1/N)Σ|f(k)|²。

2.5 因果、反因果、实与复

因果信号：t<0 时 f(t)=0，相当于 t=0 才接入系统，最典型的就是阶跃信号 ε(t)。反因果信号：t≥0 时 f(t)=0（零信号除外）。此外还有一维/多维、实/复、左边/右边信号等分类，考试以因果性最常考。

复信号里最常用的是复指数信号，它是全书最重要的“基本砖块”：

f(t) = est , s = σ + jω , −∞ < t < ∞(1-7)
f(t) = eσt(cos ωt + j sin ωt)(1-8)

它的实部和虚部都是幅度随时间变化的正弦：Re[f] = eσtcos ωt，Im[f] = eσtsin ωt。所以 s 的两个参数各有明确物理意义——σ 管“包络涨落”，ω 管“振荡快慢”。

第 3 节　两个奇异信号：ε(t) 与 δ(t)

为什么需要奇异信号？ 因为现实里有两类波形用普通函数描述不了：一是“突然合上开关”的瞬间（跳变），二是“极短极强的一次冲击”（比如锤击、雷击、采样脉冲）。阶跃函数负责描述跳变，冲激函数负责描述冲击。它们不是普通函数（所以叫奇异函数），但用起来极其方便——有了它们，任何分段波形都能写成一个解析式。

3.1 阶跃函数 ε(t)

教材用“函数序列取极限”的办法定义它：先取一串越来越陡的斜坡 γₙ(t)（在 −1/n 到 1/n 之间从 0 线性升到 1，过点 (0, 1/2)），再令 n→∞，极限就是单位阶跃。

ε(t) = limn→∞ γn(t) = { 0 , t < 0 ; 1 , t > 0 }(1-9)

t=0 处的取值不影响积分，工程上通常不追究。

ε(t) 有三条必会性质：

① 表示分段常量信号：把若干个错位的阶跃叠加，就能拼出任意阶梯波。

f(t) = 2ε(t) − 3ε(t−1) + ε(t−2)(1-10)

波形：0~1 段高 2，1~2 段高 −1，t>2 后为 0。这是“用阶跃写波形”的标准动作。

② 表示作用区间（截取）：乘以一个门，就只保留门内的部分。

f(t)[ε(t−t1) − ε(t−t2)] , 只保留 t1 < t < t2 段(1-11)

③ 积分性质：阶跃的积分是斜坡。

∫−∞t ε(τ) dτ = t·ε(t)(1-12)
门函数（矩形脉冲）gτ(t)

工程上天天用的矩形脉冲，用两个阶跃一减就得到：

gτ(t) = ε(t + τ/2) − ε(t − τ/2)

幅度 1、宽度 τ、以 t=0 为中心。第二章卷积分里全是它。

3.2 冲激函数 δ(t)

单位冲激函数是狄拉克引入的奇异函数，是“强度极大、作用时间极短”的物理量的理想化模型。它用两个条件定义，缺一不可：

δ(t) = 0 (t ≠ 0) , ∫−∞∞ δ(t) dt = 1(1-13)

直观理解：高度无穷大、宽度无穷小、面积为 1 的对称窄脉冲。图形上画一根向上的箭头，旁边标 (1)，这个 (1) 表示冲激强度（面积），不是高度——因为高度是无穷大，画不出来。

它怎么来的？把上面的 γₙ(t) 求导，得到一串高 n/2、宽 2/n 的矩形脉冲 pₙ(t)，它们的面积恒为 1；n→∞ 时矩形变成“无限高无限窄”，极限就是 δ(t)。这也解释了 δ 与 ε 的关系：

δ(t) = dε(t)/dt , ε(t) = ∫−∞t δ(τ) dτ(1-14)

图 1-2　γₙ→ε(t) 与 pₙ(t)→δ(t) 的求导/积分对偶（PPT 第 50 页）

δ(t) 最大的用处是描述间断点的导数。看课件第 51 页那个方波：

f(t) = 2ε(t+1) − 2ε(t−1) ⇒ f′(t) = 2δ(t+1) − 2δ(t−1)(1-15)

波形在 t=−1 上跳 2、t=1 下跳 2，导数就是两根强度 ±2 的冲激。没有 δ 函数，这句话根本写不出来。

关于 δ(t) 的三个常见误解

· δ(t) 不是普通函数，δ(0) 没有定义，不能代入求值；它只有在积分号下、作为“取样器”时才有意义。

· 冲激强度是面积：2δ(t) 表示面积为 2，不是高度为 2。

· ε(t) 与 δ(t) 的量纲不同：ε 无量纲，δ 的量纲是 1/时间（因为它对时间积分得 1）。

3.3 冲激函数的广义函数定义（选学，但很好用）

既然 δ(0) 无定义，数学家改用“它作用在别人身上产生什么效果”来定义它。做法是：取一类性能良好的函数 φ(t) 叫检验函数，广义函数 g(t) 对每个 φ(t) 赋一个数：

Ng[φ(t)] = ∫−∞∞ g(t) φ(t) dt(1-16)

于是冲激函数就定义为“能把 φ(0) 挑出来的那个广义函数”：

∫−∞∞ δ(t) φ(t) dt = φ(0)(1-17)

这个定义的好处是可以用普通函数序列逼近 δ(t)，只要极限满足上面的赋值关系即可。课件给了两个经典逼近：高斯（钟形）函数和取样函数。

δ(t) = limb→∞ b·e−πb²t²(1-18)
δ(t) = limb→∞ sin(bt)/(πt)(1-19)

前者是一个越来越高、越来越窄的钟形曲线；后者是 sinc 型振荡，主瓣越来越高。两者面积都保持为 1，所以极限都是 δ(t)。

3.4 取样性质：δ(t) 最值钱的一条

把上面的定义式里的 φ 换成任意信号 f，就得到取样性质（也叫筛选性质）：

f(t)·δ(t) = f(0)·δ(t) , ∫−∞∞ f(t)δ(t) dt = f(0)(1-20)
f(t)·δ(t−a) = f(a)·δ(t−a) , ∫−∞∞ f(t)δ(t−a) dt = f(a)(1-21)

物理含义：冲激像一把“镊子”，从 f(t) 中把某一时刻的值夹出来。这就是采样定理、离散化的数学基础。

积分区间必须包含冲激点

· ∫−4−1 sin(t−π/4)δ(t) dt = 0，因为积分区间 [−4,−1] 里没有 t=0。

· ∫−19 sin(t−π/4)δ(t) dt = sin(−π/4) = −√2/2，区间含 t=0。

· 结论：先看冲激在不在区间内，再谈取值——这是每年必设的陷阱。

3.5 冲激偶 δ′(t) 与 n 阶导数

对 δ(t) 再求导得到冲激偶 δ′(t)。它是奇函数（一正一负两根无限靠近的冲激），作用在 f 上是“取出 −f′(0)”：

f(t)·δ′(t) = f(0)·δ′(t) − f′(0)·δ(t)(1-22)
∫−∞∞ f(t) δ′(t) dt = −f′(0)(1-23)
∫−∞∞ f(t) δ′(t−a) dt = −f′(a)(1-24)
∫−∞∞ f(t) δ(n)(t) dt = (−1)n f(n)(0)(1-25)
f·δ′ 那条公式怎么来的

从乘积求导法则出发：(f·δ)′ = f·δ′ + f′·δ。

又因为 f·δ = f(0)·δ，两边求导得 (f·δ)′ = f(0)·δ′。

代入移项：f·δ′ = f(0)·δ′ − f′·δ。两边积分即得 ∫f·δ′dt = −f′(0)。

n 阶情形用分部积分反复做，每做一次多一个负号，于是得到 (−1)ⁿ。

∫u′v dt = [uv]−∞∞ − ∫u v′ dt

3.6 冲激函数的尺度变换与奇偶性

δ(at) 与 δ(t) 差一个系数，这个系数来自“面积守恒”：横轴压缩 a 倍，纵轴必须放大 |a| 倍才能保住面积 1。

δ(at) = (1/|a|)·δ(t)(1-26)
δ(n)(at) = (1/|a|)·(1/an)·δ(n)(t)(1-27)
δ(at − t0) = (1/|a|)·δ(t − t0/a)(1-28)

取 a = −1 就得到奇偶性：

δ(−t) = δ(t)（偶函数） , δ′(−t) = −δ′(t)（奇函数）(1-29)

一般地，δ 的 n 阶导满足 δ(n)(−t) = (−1)n δ(n)(t)——偶数阶偶、奇数阶奇。

4.2 反转：以纵轴为镜

· 所以离散情形只讨论反转、平移、差分/累加，尺度变换基本不考。

4.5 复合变换：唯一可靠的做法

遇到 f(at+b) 这种“又缩又移”的式子，先化成规范形，再按固定次序作图，这是避免出错的关键：

f(at + b) = f[ a·(t + b/a) ](1-34)

规范形 a(t − t₀) 里，a 决定“缩多少”，t₀ 决定“移多少”。推荐次序有两种，任选一种但全过程只能用同一种：

① 反转 → 展缩 → 平移（推荐）：先处理负号，再处理系数，最后处理常数项。

② 平移 → 展缩 → 反转：从原波形出发先挪、再缩、最后翻。

最容易错的一句话

· 所有变换都必须是对 t 的变换，平移量要按“t 的系数”折算。

· 例如 f(2t−4) 是 f(2t) 右移 2（不是 4），因为 2t−4 = 2(t−2)。

例 7　已知 f(t) 画 f(2−t)（课件第 37 页）

设 f(t) 只在 0<t<1 内非零（上升段）。

规范形：f(2−t) = f[−(t−2)]，即“反转 + 右移 2”。

法一（先移后翻）：左移 2 得 f(t+2)，占 −2~−1；再反转得 f(−t+2)，占 1~2。

法二（先翻后移）：反转得 f(−t)，占 −1~0；再右移 2 得 f[−(t−2)]，占 1~2。

结论：两种次序结果一致，都占 1~2，且波形是原波形左右翻转后的样子。

例 8　已知 f(t) 画 f(−4−2t)（课件第 40 页）

已知 f(t)：−2<t<0 段为高 1 的方波，0<t<2 段线性降到 0。

规范形：f(−4−2t) = f[−2(t+2)]，即“反转 → 压缩 2 倍 → 左移 2”（用次序①）。

f(t) → f(−t) → f(−2t) → f[−2(t+2)] = f(−2t−4)

第 1 步反转：区间 −2~2 → −2~2（对称区间，图形左右翻）。

第 2 步压缩 2 倍：区间 −2~2 → −1~1。

第 3 步左移 2：区间 −1~1 → −3~−1。

校验：解不等式 −2 < −2t−4 < 2，得 −3 < t < −1 ✓。

点评：最后一定要用“解不等式”验算区间，这是最省时的检查手段。

例 9　反向问题：已知 f(−4−2t) 求 f(t)（课件第 42 页）

思路：把上面三步倒着走，次序变成“反转 → 展宽 → 右移”。

已知 f(−2t−4) 占 −3~−1（斜坡 −3~−2、方波 −2~−1）。

反转 → f(2t−4)，占 1~3；展宽 2 倍 → f(t−4)，占 2~6；右移 4 → f(t)，占 −2~2。

第 5 节　系统：从装置到数学模型

信号讲完了，轮到“加工机”。这一节的核心是：把物理装置翻译成方程（建模），再用方程判断系统的性质。前者靠电路/力学定律，后者靠三条定义。

5.1 系统模型与模拟框图

先把模型分两类（课件第 78 页）：

• 集中参数系统：忽略电磁辐射，电场、磁场可分别用 C、L 表示，能量传输不需要时间，电路尺寸远小于波长。集总参数电路都属于这一类。

• 分布参数系统：有电磁辐射，电磁能沿传输线连续分布，能量传输需要时间，电路尺寸与波长相近，例如微波传输系统、同轴线。

系统的状态：系统在任意时刻 t₀ 的状态，是指取该时刻最少数目的一组数，这组数连同 t₀ 以后的输入，足以确定 t>t₀ 时刻的输出。对 RLC 电路，这组数就是电容电压与电感电流（它们记着“历史”）。

解析描述就是建微分方程。以 RLC 串联电路为例：以 uS(t) 为激励、uC(t) 为响应，由 KVL 和元件的 VAR 列方程并整理：

LC·d2uC/dt2 + RC·duC/dt + uC = uS(1-35)

抽去物理含义，任何二阶系统都可以写成同一个形式：

a2·d2y/dt2 + a1·dy/dt + a0y = f(t)(1-36)

同一方程也能描述二阶机械减振系统（弹簧 k、质量 M、阻尼 C、位移 x、外力 f(t)）：

M·d2x/dt2 + C·dx/dt + k·x = f(t)(1-37)

能用相同方程描述的系统叫相似系统。这是“信号与系统”能横跨电气、机械、声学的原因：数学同构，分析方法就通用。

模拟框图是把方程“画出来”：数乘、相加、积分三种基本部件相互连接，就表征了方程里的运算关系。注意课件特意强调的一点——积分器的抗干扰性比微分器好，所以工程上框图一律用积分器搭，不直接用微分器。

麻烦：右边出现 f′，不能直接进加法器（微分器抗干扰差）。

办法：引入辅助函数 x(t)，令 x″+3x′+2x = f，这个框图好画（同例 10）。

再令 y = 4x′ + x。因为系统是 LTI 的，把第一个方程两边做同样的线性组合，恰好得到 4(x″+3x′+2x) = 4f，整理即 y″+3y′+2y = 4f′+f。

y(t) = 4x′(t) + x(t)

点评：辅助函数法是第 2 章微分方程解法的雏形，这里先混个脸熟。

5.2 线性系统：三个条件缺一不可

线性 = 齐次性 + 可加性，合起来就是“输入线性组合，输出同样线性组合”：

T[ a·f1(t) + b·f2(t) ] = a·T[f1(t)] + b·T[f2(t)](1-38)

但对动态系统（含电容、电感、记忆元件，也叫记忆系统）来说，输出不只取决于当前输入，还取决于系统的初始状态 x(0)。这时线性要拆成三条：

① 可分解性：完全响应 = 零状态响应 + 零输入响应。

y(·) = yzs(·) + yzi(·)(1-39)

② 零状态线性：初始状态为零时，系统对输入是线性的。

③ 零输入线性：输入为零时，系统对初始状态是线性的。

例 12　判断下列系统是否线性（课件第 88 页）

(1) y(t) = 3x(0) + 2f(t) + x(0)f(t) + 1。

　　yzs = 2f(t) + 1（令 x(0) = 0），yzi = 3x(0) + 1（令 f(t) = 0）。两者相加 = 3x(0) + 2f(t) + 2，与原式相差 1 − x(0)f(t)：既少了交叉项 x(0)f(t)，又多出一个常数 1，不满足可分解性 ⇒ 非线性。

更快一步的判据：线性系统必须有 T[0, 0] = 0（零输入、零状态时输出为零），而这里 f = 0、x(0) = 0 时 y = 1 ≠ 0，一步就能判非线性。

一般结论：只要表达式带一个与 f、x(0) 都无关的常数项，它在 yzi 与 yzs 里就各出现一次，相加必然多出这个常数——所以"带独立常数项"的系统一定是仿射的，不是线性的；再加上交叉项 x(0)f(t) 在分解中整个丢失，两处破绽都指向非线性。

(2) y(t) = 2x(0) + |f(t)|。

　　yzs = |f(t)|，yzi = 2x(0)，可分解 ✓。但 T[af, 0] = |af| ≠ a|f|，零状态不满足齐次性 ⇒ 非线性。

(3) y(t) = x²(0) + 2f(t)。

　　yzs = 2f(t) 线性 ✓，但 T[0, ax(0)] = a²x²(0) ≠ a·x²(0)，零输入非线性 ⇒ 非线性。

点评：这道题的价值在于展示“三条条件逐条查”的流程，哪条断了就判非线性。

例 13　一个“看起来复杂但确实线性”的系统（课件第 89 页）

y(t) = e−tx(0) + ∫0t sin(x)·f(x) dx

① 可分解：yzi(t) = e−tx(0)，yzs(t) = ∫₀ᵗ sin(x)f(x)dx ✓。

② 零状态线性：积分对 f 是线性的，a、b 提得出来 ✓。

③ 零输入线性：e−t[ax₁(0)+bx₂(0)] = a·e−tx₁(0) + b·e−tx₂(0) ✓。

结论：线性系统。注意：系数 e−t 含时间，但它是“对 x(0) 的系数”，不影响线性判定（只影响时不变性——见下一小节）。

5.3 时不变系统

时不变：输入延迟多少，零状态响应就相应延迟多少。也就是说，系统的“脾气”不随时间改变。

若 f(t) → yzs(t) , 则 f(t − td) → yzs(t − td)(1-40)
例 14　判断时不变性（课件第 92—93 页）

(1) yzs(k) = f(k)·f(k−1)。

　　令 g(k) = f(k−kd)，则 T[g] = g(k)g(k−1) = f(k−kd)f(k−kd−1) = yzs(k−kd) ✓ 时不变。

(2) yzs(t) = t·f(t)。

　　T[g] = t·f(t−td)，而 yzs(t−td) = (t−td)f(t−td)。两者不等 ⇒ 时变。

(3) yzs(t) = f(−t)。

　　T[g] = f(−t−td)，而 yzs(t−td) = f(−(t−td)) = f(−t+td)。两者不等 ⇒ 时变。

直观判据：f(·) 前面出现含 t 的变系数，或者出现反转、展缩，一律判时变。

线性与时不变是两件事

· y = t·f(t) 是线性时变：对 f 线性，但系数随时间变。

· y = f(t) + 1 是非线性时不变：常数项破坏了线性，但时间上一致。

· 两个性质要分开判，不能因为“线性”就默认“时不变”。

5.4 LTI 系统的微积分特性

线性 + 时不变 = LTI（Linear Time-Invariant），这是本课程的主战场。LTI 系统除了线性、时不变，还白送两条极好用的性质：

f(t) → yzs(t) ⇒ f′(t) → yzs′(t)(1-41)
f(t) → yzs(t) ⇒ ∫−∞t f(x)dx → ∫−∞t yzs(x)dx(1-42)

为什么成立？ 因为微分和积分本身就是 LTI 运算，LTI 系统之间可以“交换次序”。这两条性质在第 2 章求冲激响应、第 5 章做拉普拉斯变换时会被反复使用。

5.5 因果系统

因果系统：零状态响应不会出现在激励之前的系统。通俗说就是“不预知未来”。所有实际运行的系统都是因果的；非因果系统只能离线处理（比如图像处理里可以用“未来像素”）。

例 15　LTI 综合题：用三条性质拼出答案（课件第 97—99 页）

已知：某 LTI 因果连续系统，初态 x(0₋)。

　　x(0₋)=1、输入 f₁(t) 时，全响应 y₁(t) = e−t + cos πt，t>0；

　　x(0₋)=2、输入 f₂(t)=3f₁(t) 时，全响应 y₂(t) = −2e−t + 3cos πt，t>0。

求：f₃(t) = f₁′(t) + 2f₁(t−1) 时的零状态响应 yzs3(t)。

第一步（分离零输入）：设 x(0₋)=1 时 yzi1、f₁ 时 yzs1。由线性，x(0₋)=2 时 yzi2 = 2yzi1，f₂=3f₁ 时 yzs2 = 3yzs1，于是

y1 = yzi1 + yzs1 , y2 = 2yzi1 + 3yzs1

第二步（解方程）：y₂ − 2y₁ 消去 yzi1，得

yzs1(t) = (−4e−t + cos πt)·ε(t)

第三步（三条性质合用）：微分特性给 f₁′(t) → yzs1′(t)；时不变给 f₁(t−1) → yzs1(t−1)；线性把两者加权相加。

yzs1′(t) = −3δ(t) + [4e−t − π sin πt]·ε(t)

yzs3(t) = yzs1′(t) + 2·yzs1(t−1)

合并后的最终答案：yzs3(t) = −3δ(t) + [4e−t − π sin πt]ε(t) + 2[−4e−(t−1) + cos π(t−1)]ε(t−1)。

点评：这道题是第一章的“集大成者”——先靠线性把零输入剥掉，再靠微积分特性、时不变性拼答案，三个性质少一个都做不出来。

5.6 补充：稳定系统

课件第 1 章没有单独讲稳定性，但它是系统三大性质之一，而且第 2 章马上要用，这里先补一句：BIBO 稳定指“有界输入产生有界输出”。判据是冲激响应绝对可积：

这个判据第二章讲冲激响应时会重新遇到；第五章讲极点在左半平面，本质就是同一件事。

6.1 五条核心结论

① 信号是信息的载体，系统是信号的加工装置；全书研究的是 f(t) → 系统 → y(t)。

② 分类决定工具：连续/离散决定用积分还是求和，周期/非周期决定能否用傅里叶级数，能量/功率决定变换是否存在。

③ ε(t) 描述“跳变”，δ(t) 描述“冲击”；两者互为微积分，且都能把分段波形写成一个解析式。

④ 复合变换要先把自变量化成规范形 a(t−t₀)，再按“反转→展缩→平移”统一执行。

⑤ 系统三性质各有独立判据：线性看三条分解条件，时不变看“延迟能否穿透”，因果看“是否用到未来”。

1. 判断 f(t) = sin 3t + cos 5t 是否为周期信号，若是求周期。

2. 判断 f(t) = e−3tε(t) 是能量信号还是功率信号，并求其能量。

4. 已知 f(t) 为 0<t<2 内高 1 的矩形，画出 f(−3−0.5t) 并写出其非零区间。

5. 判断系统 y(t) = f(t)·cos(100t) 的线性与时不变性。

6. 判断系统 yzs(t) = f(t−2) + f(2−t) 的因果性。

参考答案与解析

1. T₁ = 2π/3，T₂ = 2π/5，T₁/T₂ = 5/3 为有理数 ⇒ 周期信号，T = 最小公倍数 = 2π（3 与 5 的最小公倍数是 15，对应 2π/15×15）。

2. E = ∫₀^∞ e−6tdt = 1/6 < ∞ ⇒ 能量信号，P = 0。

3. 原式 = −d/dt[t²+2t−1]|t=2 = −(2t+2)|t=2 = −6。

4. f(−3−0.5t) = f[−0.5(t+6)]：反转→展宽 2 倍→左移 6。原区间 0~2 → 反转 −2~0 → 展宽 −4~0 → 左移 6 得 2~6（也可解不等式 0<−3−0.5t<2 得 2<t<6 验算）。

5. 对 f 是线性的（乘一个与 f 无关的函数）；但 cos(100t) 是 t 的变系数 ⇒ 时变。这是“线性时变”的典型例子（幅度调制）。

6. f(t−2) 因果，但 f(2−t) 在 t=0 时用到 f(2)，属于未来 ⇒ 非因果。
