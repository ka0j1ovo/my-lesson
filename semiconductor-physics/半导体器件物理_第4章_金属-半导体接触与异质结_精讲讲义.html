0 导学：为什么每个器件都必须有金属接触

课件第 1 页是 Chapter 9 的标题页（杨丰媛，上海大学微电子学院），标题就写明了本章的两大主题：金属-半导体结与半导体异质结。第 7、8 章讲的 pn 结，两侧是同一种材料、只是掺杂类型不同，叫同质结（homojunction）；本章要讲的两种结，则是「材料都不一样」的两种接法，它们同样能做成二极管。

课件第 2 页用一句话点出了这一章的现实动机：任何器件都必须与外部电路连接，而连接一定要通过金属。如果这个金属-半导体界面也整流，那么器件的有用信号就会被两个额外的二极管夹住，性能全毁。所以工程上必须专门做一个「不整流、电阻极低」的接触，叫欧姆接触（ohmic contact）。换句话说：整流接触是我们要用的器件，欧姆接触是我们要付的过路费——本章前半讲前者、后半讲后者。

课件第 3 页列出 6 条学习目标，它们也正好构成本章的顺序：

① 会对金属-半导体结画能带图（平衡、正偏、反偏三种状态）；

② 掌握肖特基势垒二极管的静电特性（耗尽层宽度、界面电场、结电容）；

③ 会用理想 I–V 方程算电流；

④ 说清它与 pn 结在输运机理、开启电压、开关时间三方面的差别；

⑤ 理解欧姆接触是怎么做出来的（功函数判据 + 隧道效应）；

⑥ 了解异质结的能带对齐与二维电子气（2DEG）。

1 第一节：功函数、电子亲和能与理想能带图

1.1 先讲为什么：同一个金属，接触轻掺杂和重掺杂会得到两种完全不同的器件

课件第 5 页给出本章最重要的一张「分岔图」：同样是金属贴在硅上，结果是两种器件——

• 金属 + 重掺杂硅 ⇒ 欧姆接触：界面势垒极薄，电子直接隧穿过去，接触电阻很低，电流双向导通；

• 金属 + 轻掺杂硅 ⇒ 整流接触（肖特基二极管）：界面势垒厚，电子只能靠热激发翻越，于是单向导电。

课件同时强调：本章主要讨论金属与 n 型半导体的接触，因为这种结构在工程上最常见（源漏接触、功率整流器）。注意它与 pn 结最本质的不同——肖特基二极管的电流主体是多数载流子（n 型中是电子），而 pn 结的电流主体是少数载流子的扩散。这一条差别，后面会推出「开启电压低」和「开关速度快」两个结论。

1.2 它怎么来的（一）：三个能量标尺——功函数、电子亲和能、内建电势

要画金属-半导体接触的能带图，只需要三把尺子，课件第 6 页把它们并列在同一张图上：

• 金属功函数 φ_m（work function）：把一个电子从金属的费米能级搬到真空（静止、无动能）所需的能量，单位 eV。换成能量写法就是 eφ_m = E_vac − E_FM。

• 半导体功函数 φ_s：同样定义，eφ_s = E_vac − E_FS。它对掺杂敏感，因为掺杂会挪动 E_F。

• 电子亲和能 χ（electron affinity）：把导带底的电子搬到真空所需的能量，eχ = E_vac − E_c。χ 是材料常数，与掺杂无关——这一点非常关键，它让 ΔE_c 可以事先算出来。

三者的关系对 n 型半导体一目了然：从 E_F 到真空要跨过 E_F → E_c 一段（记为 eφ_n）和 E_c → 真空一段（eχ），所以

eφs = eχ + (Ec − EF) = eχ + eφn(4-1)

n 型半导体：功函数 = 电子亲和能 + 费米能级到导带底的距离。其中 eφ_n = kT·ln(N_c/N_d)，掺杂越高 φ_n 越小。

课件第 6 页给了两张表，做设计时直接查。表 9.1 是金属功函数：常见金属的 φ_m 从 4.26 eV（Ag）到 5.65 eV（Pt），跨度 1.4 eV——这个跨度决定了「选哪种金属就能调多高的势垒」。

1.3 它怎么来的（二）：接触瞬间，电子往哪一边跑

设 φ_m > φ_s（W、Pt、Ni 对轻掺杂硅就是这种情况）。由定义 eφ_m > eφ_s 意味着 E_vac 到 E_FM 的距离更大，所以金属的费米能级更低、半导体的费米能级更高。课件第 7 页把这幅「接触前」的图景讲得很清楚：两个 E_F 不一样高，系统不处于热平衡。

一旦接触，电子总是往能量低的地方跑：半导体里的电子流向金属。电子走了以后，半导体表面附近留下带正电的电离施主 D⁺，它们不能动，于是形成一个正的空间电荷区；金属表面则感应出等量的负电荷。这个空间电荷区产生一个指向金属的电场，把后续的电子拉住，直到两侧的费米能级被拉平为止——这就是热平衡。

结果是：半导体靠近界面的能带向上弯曲（band bending），弯出一个对电子的势垒；金属一侧的能带则是平的（金属的载流子浓度极高，几层原子就屏蔽掉了全部电场，这也是为什么能带图上金属那一侧总画成直角台阶）。能带弯曲区 = 耗尽区 = 空间电荷区，三者在本章是同义词。

1.4 它怎么来的（三）：φ_B0 与 V_bi 的能带图代数

课件第 8 页给出了本章最重要的两个式子：φ_B0 = φ_m − χ 与 V_bi = φ_B0 − φ_n。它们看似是「看图说话」，其实每一步都可以严格记账。下面把这个代数过程补全，图 4-1 就是课件第 8 页那张经典能带图。

图 4-1　理想热平衡金属-n 型半导体的能带图：左侧为接触前的两块材料，右侧为接触后的统一能带图（课件第 8 页）

φ_B0 与 V_bi 是怎么从能带图上「读」出来的

取界面为 x = 0，半导体一侧为 x > 0。整套记账只用三条规则：

· 真空能级在界面处连续：E_vac(0⁻) = E_vac(0⁺)。这是理想模型的核心假设（第 3 节会看到真实界面有一层薄氧化层，这条就不再严格）。

· 热平衡后费米能级处处水平：E_FM = E_FS = E_F。

· 电子亲和能是材料常数：E_c(0) = E_vac − eχ，与掺杂无关。

金属一侧：E_F 在真空能级下方 eφ_m 处，即 E_F = E_vac − eφ_m。把它代入界面上的 E_c(0)：

eφB0 = Ec(0) − EF = (Evac − eχ) − (Evac − eφm) = e(φm − χ)

这就是理想势垒高度（也叫肖特基势垒，Schottky barrier）：电子从金属出发、要进入半导体导带，必须爬过这么高的一道墙。注意它只由两种材料决定，与半导体的掺杂浓度无关。

再看半导体一侧。远离界面处能带已经拉平，E_c(∞) − E_F = eφ_n，其中 eφ_n = kT ln(N_c/N_d)。界面处到体内的导带总抬高量就是内建电势差：

eVbi = Ec(0) − Ec(∞) = eφB0 − eφn ⇒ Vbi = φB0 − φn

要点：φ_B0 与掺杂无关（材料属性），V_bi 与掺杂有关（掺杂越高，φ_n 越小，V_bi 越大）。这一句区别贯穿全章——它解释了为什么「换金属」调 φ_B0、「改掺杂」调 V_bi。

顺带说明：课件第 8 页把这两个量画在了同一张图上——界面处的 eφ_B0 是从金属费米能级量到界面导带底，而 eV_bi 是从界面导带底量到体内导带底。二者相差的正是 eφ_n。图中同时标出了 E_c、E_v、E_F、E_Fi 与耗尽区宽度 x_n = W，这些符号在课件第 11 页被系统整理了一遍：E₀ 为真空能级，E_FM、E_FS 为两侧费米能级，Φ_M、Φ_S 为功函数，χ 为电子亲和能，Φ_B 为势垒高度，Φ_i 为界面处的势垒（含非理想修正），W 为耗尽区宽度，x = 0 为金属/半导体界面。以后看到任何一张金属-半导体能带图，先找这 8 个符号的位置，图就读懂了一半。

1.5 设计时拿它干什么：加偏压，看谁变、谁不变

为什么这样就整流了？ 关键在于两个方向的电流由两个不同的势垒控制：

• 电子从半导体到金属，翻的是 e(V_bi ∓ V)，随偏压指数变化——正偏时飞速变大；

• 电子从金属到半导体，翻的是 eφ_B0，与偏压无关——所以反偏电流是一个不随电压增长的常数（理想情况下）。

一个随电压指数涨、一个纹丝不动，相减就得到单向导电。这正是肖特基二极管整流的物理根源：不是「一边通一边不通」，而是「一边的势垒会随电压变、另一边的不变」。

课件第 10 页给出定性的 I–V 曲线：形状与 pn 结几乎一样，都是指数规律；但载流子是多子电子，而且正偏时常规电流的方向是金属 → 半导体（与电子流方向相反）。这一点初学时容易记反：金属接正极，电流从金属流入半导体，与 pn 结「p 接正、电流 p → n」是同一个逻辑，只不过这里的 p 侧换成了金属。

【一句话记住】

φ_B0 = φ_m − χ 管「墙有多高」，只由材料定；V_bi = φ_B0 − φ_n 管「墙基抬多高」，随掺杂和偏压变。

加偏压时界面势垒不动、能带弯曲量变——这就是整流的全部秘密。

【易错提醒】

· 把 φ_m 与 χ 的单位搞混：两者都是 eV（能量），所以 φ_B0 直接相减就是伏特数。写成 eφ_B0 = eφ_m − eχ 也可以，两边同除 e。

· 以为 φ_m > φ_s 就一定整流：只对轻掺杂成立。重掺杂时势垒太薄，电子直接隧穿，整流特性消失（第 6 节）。

· 以为正偏时 φ_B0 会降低：不会。正偏降低的是半导体一侧的 e(V_bi − V_a)。金属侧那道墙的高度由材料决定，电压碰不到它。

2 第二节：肖特基势垒的静电学——耗尽层宽度、界面电场与结电容

2.1 先讲为什么：只知道「墙有多高」还不够，还要知道「墙有多厚」

第一节只算了势垒的高度 φ_B0。可是两个器件可以势垒高度相同、行为却完全不同：一个整流、一个不整流——差别在势垒的厚度。厚度决定了电子是「翻过去」（热电子发射）还是「穿过去」（隧穿），也决定了结电容有多大、开关有多快。本节就把厚度算出来。

课件第 11 页先把那张经典能带图上的所有符号标了一遍，这些符号后面反复出现，先认脸：E₀ 真空能级；E_FM / E_FS 金属与半导体的费米能级；Φ_M / Φ_S 金属与半导体的功函数；χ 电子亲和能；Φ_B 势垒高度；Φ_i 界面处的实际势垒（考虑界面层后的修正值）；W 耗尽区宽度；x = 0 界面位置。图中还画出了耗尽区里的施主离子（正电荷）以及本征费米能级 E_i 的弯曲，后者说明「能带弯曲」等价于「电势随位置变化」。

模型假设只有三条：① 金属一侧电场为零（理想导体屏蔽）；② 半导体用耗尽近似——0 < x < W 内电子被完全扫空，只剩均匀分布的施主离子 +eN_d，W 之外电中性；③ 界面处没有界面态、没有薄氧化层（本节先这样假设，第 3 节再放宽）。

2.2 它怎么来的：泊松方程两步积分

整个过程和第 2 章 p⁺n 结的推导完全同构，只是把 p⁺ 侧的耗尽宽度取成零。课件第 12 页给出起点：

dE/dx = ρ/εs = eNd/εs (0 < x < W)(4-3)

一维泊松方程。耗尽近似下电荷密度 ρ = +eN_d 是常数，这让积分变成初等运算。

E(x) = −(eNd/εs)(xn − x)(4-4)

电场在界面 x = 0 处最大、在 x = x_n 处降为零。负号表示电场由半导体指向金属（电子受力方向相反）。

从 ρ 到 W：两步积分，一步都不能少

第一步，解电场。 由 dE/dx = eN_d/ε_s 直接积分：

E(x) = (eNd/εs)x + C1

边界条件：x = x_n 处电场必须为零（中性区里没有净电荷、也就没有电场），故 C₁ = −eN_d x_n/ε_s，于是

E(x) = −(eNd/εs)(xn − x)

界面上（x = 0）电场最强：|E_max| = eN_d x_n/ε_s。这一步同时解释了课件第 12 页那句容易被跳过的话：金属内部电场为零，所以界面处必须有表面电荷来「终止」半导体里的电场线——对 n 型（耗尽层带正电）而言，金属表面感应的是负电荷，面密度 σ_M = −eN_d x_n。

第二步，解电势。 由 E = −dV/dx，把上式从 0 积到 x_n：

V(xn) − V(0) = ∫(0→xn)(eNd/εs)(xn − x)dx = eNdxn2/(2εs)

这个电势差就是两侧能带的相对抬高量，等于 V_bi + V_R（反偏时多垫了 V_R）。令它相等并解出 x_n：

xn = W = √[2εs(Vbi + VR)/(eNd)]

要点：W ∝ 1/√N_d。掺杂浓度提高 100 倍，耗尽层薄 10 倍——这就是后面「重掺杂能把势垒做薄到可以隧穿」的定量依据。

W = xn = √[2εs(Vbi + VR)/(eNd)](4-5)

肖特基势垒的耗尽层宽度。与 p⁺n 结单边突变结的公式一字不差，因为金属就是那个「无限重掺杂的 p⁺ 侧」。

|Emax| = eNdW/εs = √[2eNd(Vbi + VR)/εs](4-6)

界面处最大电场。它决定镜像力把势垒压低多少（第 3 节），也决定雪崩击穿发生在多高的反压。

2.3 例题：把 W 和 E_max 真正算一遍（课件第 13 页 例 9.1）

例 9.1　钨（W）与 N_d = 10¹⁶ cm⁻³ 的 n 型硅形成肖特基接触，求 φ_B0、V_bi、x_n 与 |E_max|。

已知：φ_m = 4.55 eV（W），χ = 4.01 eV（Si），N_c = 2.8×10¹⁹ cm⁻³，ε_s = 11.7ε₀ = 1.04×10⁻¹² F/cm，T = 300 K。

第一步，理想势垒高度：

φB0 = φm − χ = 4.55 − 4.01 = 0.54 V

第二步，费米能级到导带底的距离：

φn = (kT/e)ln(Nc/Nd) = 0.0259×ln(2.8×1019/1016) = 0.0259×7.937 = 0.206 V

第三步，内建电势差：

Vbi = φB0 − φn = 0.54 − 0.206 = 0.334 V

第四步，耗尽层宽度（V_R = 0）：

xn = √[2×1.04×10−12×0.334/(1.6×10−19×1016)] = √(4.34×10−10) = 2.08×10−5 cm

即 0.208 μm（也写成 0.208×10⁻⁴ cm）。

第五步，界面电场：

|Emax| = eNdxn/εs = 1.6×10−19×1016×2.08×10−5/1.04×10−12 = 3.2×104 V/cm

点评：W ≈ 0.2 μm、E_max ≈ 3×10⁴ V/cm，两个数都在 pn 结的典型范围内（W 零点几微米、E 10⁴—10⁵ V/cm），说明肖特基结的静电学确实就是「p⁺n 单边突变结」。另外注意 φ_n 只有 0.206 V，所以 V_bi（0.334 V）明显小于 φ_B0（0.54 V）——这正是肖特基二极管开启电压比 pn 结低的原因（第 5 节）。

2.4 它怎么用：C–V 法测势垒高度（课件第 14 页）

φ_B0 = φ_m − χ 只是理想模型的预言，实测值往往对不上（第 3 节）。所以工程上必须测量势垒高度，最常用的方法是测结电容随反偏电压的变化。课件第 14 页给出的结论是：只要把 1/C′² 对 V_R 作图，截距给 V_bi、斜率给 N_d，再由 φ_Bn = V_bi + φ_n 反推势垒高度。

这里 C′ 是单位面积的电容（F/cm²），因为肖特基结的面积 A 是已知的工艺参数，实验上量到的是总电容 C = C′·A，除以面积就得到 C′。

C′ = [eεsNd/(2(Vbi + VR))]1/2(4-7)

单位面积结电容。反偏越大，耗尽层越宽，电容越小——所以它是个压控电容（变容二极管就用这个效应）。

(1/C′)2 = 2(Vbi + VR)/(eεsNd)(4-8)

把上式平方取倒数，得到 1/C′² 与 V_R 的直线关系：斜率 2/(eε_sN_d)，电压轴截距 −V_bi。

从 C′ = dQ′/dV_R 到 1/C′²–V_R 直线

很多教材直接抛出 C′ = ε_s/W，中间那一步其实只要一行。耗尽层里单位面积的空间电荷是 Q′ = eN_d x_n，它随反偏电压变化：

dQ′ = eNddxn

把 x_n² = 2ε_s(V_bi + V_R)/(eN_d) 两边对 V_R 求导：2x_n·dx_n/dV_R = 2ε_s/(eN_d)，即 dx_n/dV_R = ε_s/(eN_d x_n)。代回定义式：

C′ = dQ′/dVR = eNd·εs/(eNdxn) = εs/xn

这一步说明：耗尽层就是一个板间距 x_n、介质为半导体（介电常数 ε_s）的平行板电容器。把 x_n 的表达式代进来：

C′ = εs/√[2εs(Vbi+VR)/(eNd)] = [eεsNd/(2(Vbi+VR))]1/2

两边平方再取倒数，就得到一条直线：

(1/C′)2 = 2(Vbi + VR)/(eεsNd) = [2/(eεsNd)]·VR + [2Vbi/(eεsNd)]

横轴 V_R、纵轴 1/C′²：斜率 = 2/(eε_sN_d) ⇒ N_d；令 1/C′² = 0 ⇒ V_R = −V_bi。这就是 C–V 法测势垒高度的全部原理，也是所有半导体参数测试仪的基本功能之一。

图 4-2　1/C′² 对 V_R 的直线：W-Si 与 W-GaAs 两个肖特基二极管，截距给出 V_bi，斜率给出 N_d（课件第 14 页，图 9.3）

课件第 14 页的图 9.3 就是这张图：W-Si 的直线陡（斜率大 ⇒ N_d 小）、W-GaAs 的直线平缓（斜率小 ⇒ N_d 大），两条线的电压轴截距都落在负值上，量出来就是各自的 V_bi。图中标注的 Intercept 就是那个截距。注意纵轴用了两种单位（Si 是 ×10¹³、GaAs 是 ×10¹²），说明两者电容差了 10 倍，主要来自面积与介电常数的差别。

φBn = Vbi + φn， φn = (kT/e)ln(Nc/Nd)(4-9)

C–V 法的最后一步：由截距得 V_bi，由斜率得 N_d，再算出 φ_n，相加即得势垒高度 φ_Bn。

补充例题　某 W/n-Si 肖特基二极管由 C–V 测得：1/C′²–V_R 直线的电压轴截距为 −0.334 V，斜率为 1.2×10¹⁵ cm⁴·F⁻²·V⁻¹。求 N_d、φ_n 与 φ_Bn，并判断金属是什么。

第一步，由斜率求掺杂。由斜率 S = 2/(eε_sN_d)：

Nd = 2/(eεsS) = 2/(1.6×10−19×1.04×10−12×1.2×1015) = 1.0×1016 cm−3

第二步，由截距读内建电势：1/C′² = 0 时 V_R = −V_bi，故 V_bi = 0.334 V。

第三步，算 φ_n 与 φ_Bn：

φn = 0.0259×ln(2.8×1019/1016) = 0.206 V， φBn = 0.334 + 0.206 = 0.54 V

第四步，反推金属：由 φ_Bn ≈ φ_m − χ 得 φ_m = 0.54 + 4.01 = 4.55 eV，正是钨（W）。

点评：这个例子说明 C–V 法为什么是「无损、快速、可量产」的标准手段——它不需要知道金属是什么，测完电容曲线就能同时得到 N_d 和 φ_Bn。反过来说，如果算出的 φ_Bn 与 φ_m − χ 差得很多，那说明界面不理想（有界面态或界面层），这正是下一节的主题。

【易错提醒】

· 把 C′ 与总电容 C 混用：斜率里的 N_d 用的是单位面积电容 C′。如果直接把测到的 pF 值代进去，N_d 会差好几个数量级。

· 截距取成正的：1/C′² = 0 对应 V_R = −V_bi，所以截距是个负电压。很多同学看着图上交点在 −0.3 V 附近，却写成 V_bi = −0.3 V。

· 以为 W 越大电容越大：反了。W 越宽，两极板离得越远，C′ = ε_s/W 越小。反偏时电容下降就是这个道理。

【一句话记住】

W = √[2ε_s(V_bi+V_R)/(eN_d)]：掺杂 ↑ ⇒ 势垒薄；反偏 ↑ ⇒ 势垒厚。C′ = ε_s/W，1/C′² 对 V_R 是一条直线。

3 第三节：三个非理想效应——镜像力、界面态与界面层

3.1 先讲为什么：实测的势垒高度总比 φ_m − χ 小，而且 GaAs 几乎不随金属变

课件第 23 页的图 9.5 是本章最「打脸」的一张图：横轴是金属功函数 φ_m，纵轴是实测势垒高度 φ_Bn。如果理想模型成立，所有点应该落在一条斜率为 1 的直线上（φ_Bn = φ_m − χ）。实际结果是：

• 硅：数据点基本沿着斜率接近 1 的直线走，理想模型还算靠谱，只是整体偏低一点；

• GaAs：数据点几乎是一条水平线——换个金属，势垒高度几乎不变！

这两个偏差来自两个不同的物理机制，课件把它们分成两节讲：① 镜像力（让势垒变低、且随反偏变化），② 界面态 + 薄界面层（让势垒高度不再由 φ_m 决定，即所谓费米能级钉扎）。记住一句话：真实势垒高度 = 金属功函数、半导体表面态、界面层三者共同决定，不能只查表。

3.2 效应一：镜像力与肖特基势垒降低

课件第 15 页提出一个纯静电学的问题：一个电子停在金属表面外 x 处，金属里的自由电子会被它排斥、重新分布，等效于在金属内部 −x 处放了一个 +e 的镜像电荷（image charge）。于是电子被自己的镜像吸引，这股力叫镜像力（image force）。这种「势垒被自己的镜像拉低」的效应叫肖特基效应（Schottky effect）。

课件第 15—17 页一步步算这个力与势能：两个电荷相距 2x，介质是半导体（介电常数 ε_s），所以库仑力是

F = −e2/[4πεs(2x)2] = −e2/(16πεsx2)(4-10)

镜像力：负号表示方向指向金属。分母里的 4 来自「距离是 2x」的平方，不是笔误。

把力对距离积分（取无穷远处势能为零），得到镜像势能。课件第 17 页写成 ∫E dx 的形式，结果一样：

Uim(x) = −e2/(16πεsx)(4-11)

镜像势能。x → 0 时趋于 −∞：越贴近金属，电子势能越低（这也是金属能「吸住」电子的原因）。

但电子并不是只受镜像力，它同时还被耗尽区的电场 E 往半导体深处推（对电子做的功是 −eEx）。课件第 18—19 页把两者叠加，得到总势能，并指出：这个函数必有一个极大值，位置在 x_m > 0，也就是新的势垒顶。

U(x) = −e2/(16πεsx) − eEx(4-12)

总势能 = 镜像势能 + 电场势能。第一项在 x→0 时拉低势能，第二项在 x 变大时拉低势能，中间必有极大值。

求最大势垒位置 x_m 与降低量 Δφ

对总势能求导并令其为零：

dU/dx = e2/(16πεsx2) − eE = 0 ⇒ e2/(16πεsxm2) = eE

解出最大势垒的位置（课件第 20 页的方框）：

xm = √[e/(16πεsE)]

把 x_m 代回 U(x)。在极值点上两项的绝对值恰好相等（都由 eEx_m 给出），所以

U(xm) = −eExm − eExm = −2eExm = −√(e3E/(4πεs))

势垒的降低量就是 |U(x_m)| 除以 e（课件第 20 页的 Δφ 方框）：

Δφ = |U(xm)|/e = √(eE/(4πεs))

于是实际有效势垒变成

φBn = φB0 − Δφ

两个必须记住的检验关系：① Δφ = 2Ex_m（差一个因子 2，验算时极好用）；② x_m 只有几纳米到几十纳米，所以「势垒顶」其实已经挪到了半导体内一点点，而不是紧贴界面。

图 4-3　镜像力与耗尽区电场叠加后的势能曲线：极大值出现在 x_m 处，势垒高度由 φ_B0 降到 φ_Bn，降低量为 Δφ = √(eE/4πε_s)（课件第 20 页）

xm = √[e/(16πεsE)]， Δφ = √(eE/(4πεs))， φBn = φB0 − Δφ(4-13)

课件第 21 页汇总的三式。注意 Δφ ∝ √E，而 E 又随反偏增大：反偏越大，势垒被压得越低。

这三个式子还解释了一个重要现象：反偏越大，Δφ 越大，反向电流就越大。因为 E ∝ √(V_bi + V_R)，所以 Δφ ∝ √E 只与 (V_bi + V_R) 的四分之一次方成正比——这是一个很弱的增长，但它让「理想饱和电流」变成了「缓慢上升的反向电流」，课件第 38 页的图 9.8 就是把这个偏差画了出来。

例 9.3（课件第 22 页）　GaAs 肖特基二极管在反偏下界面电场 E = 6.8×10⁴ V/cm，ε_s = 13.1ε₀。求 Δφ 与 x_m。

已知：ε_s = 13.1×8.85×10⁻¹⁴ = 1.16×10⁻¹² F/cm，E = 6.8×10⁴ V/cm = 6.8×10⁶ V/m。

第一步，势垒降低量：

Δφ = √[eE/(4πεs)] = √[1.6×10−19×6.8×106/(4π×1.16×10−10)] = √(7.47×10−4) = 0.027 V

第二步，最大势垒位置：

xm = √[e/(16πεsE)] = √[1.6×10−19/(16π×1.16×10−10×6.8×106)] = 2.0×10−7 cm

即 20 Å（两个纳米多一点）。

第三步，验算：Δφ = 2Ex_m = 2×6.8×10⁶×2.0×10⁻⁹ = 0.027 V，与上面一致。

点评：20 Å 只有十几个原子层厚，却足以把势垒压低 27 meV。27 meV 相当于一个 kT（25.9 meV），在指数关系里就是电流变化 e 倍——这就是为什么镜像力虽然「小」，却不能被忽略。

3.3 效应二：界面态与费米能级钉扎

回到图 9.5 的 GaAs 数据：换金属几乎不改变势垒高度。这说明有一个比 φ_m 更强的东西在「决定」势垒高度。课件第 24 页给出的模型是：金属 — 薄界面层（厚度 δ）— 半导体，而在半导体表面还分布着一层界面态（interface states）。真实界面永远不是原子级完美的：悬挂键、氧化层、金属化损伤，都会在禁带里造出一批局域能级。

课件第 25 页定义界面态密度 D_it，单位是 cm⁻²eV⁻¹（每平方厘米、每电子伏特有多少个态）。课件第 26 页进一步把它们分成两类，分界线是一个叫中性能级（neutrality level）的能量 eφ_0：

• 位于 φ_0 以下的态是施主型：空着的时候带正电（D⁰ → D⁺ + e⁻，把电子交出去）；被电子占据时中性。

• 位于 φ_0 以上的态是受主型：被电子占据时带负电（A⁰ + e⁻ → A⁻）；空着时中性。

这样一来，界面态就相当于一个「电荷水库」：费米能级在 φ_0 附近上下移动，界面态就充放电，产生电荷 Q_ss。课件第 27 页指出，Q_ss 随 E_F 相对 φ_0 的位置变化，会改变界面层的电势降，而这个电势降又反过来影响 φ_Bn——形成一个负反馈：你换金属想把势垒抬高，界面态立刻充上负电把势垒压回去。

课件第 28 页引入了超薄界面层的电势降 ΔV_ox：由于这层绝缘体分走了一部分电压，能量关系不再是简单的 φ_m = χ + φ_Bn，而要写成

eφBn = e(φm − χ) − eΔVox(4-14)

薄界面层的修正：界面层分走 ΔV_ox，所以实际势垒比 Schottky–Mott 预言低。δ 越小、ε_i 越大，ΔV_ox 越小。

把电中性条件、界面层的高斯定理、界面态电荷三件事联立，就得到课件第 29 页那个看起来很复杂的方程。它其实就是四个方程消元的结果，下面把它拆开。

(Eg − eφ0 − eφBn) = (1/eDit)√[2eεsNd(φBn − φn)] − (εi/eDitδ)[φm − (χ + φBn)](4-15)

界面态模型的电荷平衡方程（课件第 29 页）。右边两项分别是耗尽层电荷与界面层电荷的贡献，分母里的 D_it 是所有矛盾的焦点。

界面态模型的四个方程与两个极端

设界面处的薄层厚度 δ、介电常数 ε_i（相当于一个电容 C_i = ε_i/δ），界面态密度 D_it，中性能级 φ_0。四个方程：

· 电中性：Q_M + Q_ss + Q_D = 0（金属表面电荷 + 界面态电荷 + 半导体空间电荷之和为零）

· 界面层上的电压降（把薄层当平行板电容）：eΔV_ox = −Q_M·δ/ε_i

· 势垒定义：eφ_Bn = e(φ_m − χ) − eΔV_ox

· 界面态电荷（E_F 高于中性能级时受主态被填满、带负电）：Q_ss = −eD_it(E_g − eφ_0 − eφ_Bn)

把后两式代入前两式、并把结果两边同除 eD_it，就得到上面那个方程。两项的物理意义（课件第 30 页）很清楚：

· 第一项 (1/eD_it)·√[2eε_sN_d(φ_Bn − φ_n)] 就是耗尽层空间电荷 |Q_D| 除以 eD_it；

· 第二项 (ε_i/eD_itδ)·[φ_m − (χ + φ_Bn)] 就是界面层电荷除以 eD_it，其中的 ε_i/δ 正是界面层电容 C_i。

两个极端就是把 D_it 推向 0 和无穷：

· D_it → ∞：右边整体趋于 0（分母无穷大），只剩 E_g − eφ_0 − eφ_Bn = 0，即 φ_Bn = E_g/e − φ_0。势垒高度与 φ_m、χ 完全无关——费米能级被钉死了。

· D_it → 0 且 δ → 0：左边趋于 0；同时 C_i = ε_i/δ → ∞ 迫使 ΔV_ox → 0，于是 φ_Bn = φ_m − χ，回到 Schottky–Mott 极限。

情形 1（D_it → ∞）：费米能级钉扎。 课件第 31—32 页讲的就是这一支。当界面态足够多时，只要费米能级稍微偏离 φ_0，界面态就会吞掉或吐出大量电荷，把 E_F 死死按在 φ_0 附近——这叫费米能级钉扎（Fermi-level pinning）。此时

φBn = Eg/e − φ0 (Dit → ∞)(4-16)

完全钉扎极限：势垒高度由半导体的禁带宽度与中性能级决定，与金属功函数无关。这就是 GaAs 数据几乎是水平线的原因。

情形 2（D_it → 0，且忽略界面层）：Schottky–Mott 极限。 课件第 33 页指出，这时回到 φ_Bn = φ_m − χ，势垒高度完全由金属功函数决定。但现实中介于两个极端之间，所以课件给了一句非常实在的话：势垒高度最终必须由实验确定，不能只靠公式算。

φBn = φm − χ (Dit → 0，理想 Schottky–Mott 极限)(4-17)

理想极限，只对界面态极少的体系（如硅上的某些金属）近似成立。对 GaAs、InP 等，钉扎效应往往压倒它。

课件第 34 页用一张对照表把两个极端并列，并引入一个描述「钉扎程度」的参数——界面因子（interface factor）S：

S = dφB/dφm， 0 ≤ S ≤ 1(4-18)

S 衡量「换金属能改变多少势垒」：S ≈ 1 表示几乎不钉扎（理想），S ≈ 0 表示完全钉扎（换金属没用）。

【一句话记住】

两个极端夹住现实：界面态少 ⇒ 势垒随金属动（S→1）；界面态多 ⇒ 势垒被钉死（S→0）。硅在中间偏左，GaAs 在右端。

还有一个「反向」的非理想效应：镜像力让势垒变低且随反偏变化（Δφ ∝ √E）；界面态让势垒变「固执」（不随金属变）。两者方向不同，别混。

【易错提醒】

· 把 φ_0 当成费米能级：φ_0 是界面态的「中性能级」，是一个参考能量，不是 E_F 本身。E_F 会被它拉住，但两者可以不重合。

· 以为界面态只影响势垒高度：它还影响反向电流（复合电流增大）、噪声和可靠性。工艺上「界面态越少越好」是通用原则。

· 忘掉 Δφ 与温度无关、却与偏压有关：Δφ 里没有 T，但有 E，所以反偏电流会随反压缓慢上升（图 9.8）。

4 第四节：热电子发射——把电流算出来

4.1 先讲为什么：势垒这么高，电子凭什么过得去

室温下 kT = 25.9 meV，而势垒高度是 0.5—0.9 eV（差 20—35 倍）。按经典图像，电子根本翻不过去，电流应该是零。但电子服从费米-狄拉克分布：能量远高于平均值的高能尾巴虽然人少，却始终存在；而且势垒对面的「座位」是空的。这些高能电子像热发射的子弹一样越过势垒，所以叫热电子发射（thermionic emission）。

课件第 35 页给出了计算框架：电流由从半导体飞向金属的电子流 J(s→m) 与从金属飞向半导体的 J(m→s) 之差决定。两个方向都被势垒卡住——前者卡在 e(V_bi − V_a) 上，后者卡在 eφ_B0 上。计算只用到两个工具：麦克斯韦-玻尔兹曼近似（因为 φ_B ≫ kT）和速度空间里的态密度。

课件第 36 页写出最原始的积分式：把「有多少电子」乘以「它们往界面跑得多快」，再对速度积分。注意这里的能带关系只取动能的 x 分量——只有垂直于界面的速度分量能帮电子越过界面，平行于界面的两个分量不帮忙。

Js→m = e∫vxdn， dn = gc(E)fF(E)dE， ½mn*v2 = E − Ec(4-19)

热电子发射的出发点：电子流 = 电荷 × 速度 × 态密度 × 占据概率。速度与能量的关系用抛物线近似。

热电子发射积分：A*T² 是怎么冒出来的

把速度空间的态密度写成 2(m*/h)³ dv_x dv_y dv_z，占据概率用玻尔兹曼近似 exp[−(E − E_F)/kT]，其中

E = Ec + ½mn*(vx2 + vy2 + vz2)

能翻过势垒的条件是 ½m*v_x² ≥ e(V_bi − V_a)（正偏 V_a 把半导体侧的势垒削低了 eV_a），记作 v_x ≥ v_x0。于是

Js→m = e∫∫∫ vx·2(mn*/h)3exp[−(E − EF)/kT]dvxdvydvz

指数里三个速度分量完全分开，可以三次独立积分。用两个标准积分：

∫(vx0→∞)vxexp(−m vx2/2kT)dvx = (kT/m)exp(−m vx02/2kT)， ∫(−∞→∞)exp(−m vy2/2kT)dvy = (2πkT/m)1/2

把 ½m*v_x0² = e(V_bi − V_a) = e(φ_Bn − φ_n − V_a) 代入，注意 exp(−φ_n/V_t) 与 exp[−(φ_Bn − φ_n − V_a)/V_t] 相乘时 φ_n 正好抵消，只剩 φ_Bn 和 V_a：

Js→m = e·4πmn*k2T2/h3·exp(−eφBn/kT)·exp(eVa/kT)

反方向的 J(m→s) 只由金属侧的势垒 φ_B0 决定，与偏压无关（理想情形下 φ_B0 不随电压变），在 V_a = 0 时两者必须相等，所以 J(m→s) = A*T²exp(−eφ_Bn/kT)。两式相减即得净电流。

要点：① φ_n 被消掉，说明「费米能级离导带多远」不影响最终结果，只有势垒高度 φ_Bn 说了算；② 温度以 T² 的形式出现在前面、以指数出现在后面，所以温度对电流的影响远大于对电压的影响。

J = A*T2exp(−eφBn/kT)[exp(eVa/kT) − 1] = JsT[exp(eVa/kT) − 1](4-20)

肖特基二极管的理想 I–V 方程。形式与 pn 结完全相同，差别只在 J_sT 的大小（大 5—6 个数量级）。

A* = 4πe mn*k2/h3， JsT = A*T2exp(−eφBn/kT)(4-21)

有效理查森常数 A*（Richardson constant）与反向饱和电流密度 J_sT。自由电子质量时 A* = 120 A/(K²·cm²)。

A* 的数量级怎么记：把自由电子的质量代进去，A* = 4πe m₀k²/h³ = 1.20×10⁶ A/(m²·K²) = 120 A/(cm²·K²)。实际半导体要用有效质量 m_n*，所以 A* ≈ 120·(m_n*/m₀)。对硅（m_n* 约 1.08 m₀ 的态密度质量）理论上约 130，实测常在 100—120 之间——差别来自势垒降低、隧穿、界面层等非理想因素。所以 A* 也是从实验反推的，不必死记理论值。

把镜像力造成的势垒降低代进去，反向饱和电流要乘一个因子（课件第 37 页）：

JsT = A*T2exp(−eφB0/kT)·exp(eΔφ/kT)(4-22)

含肖特基效应（势垒降低）的反向饱和电流。Δφ 随反偏增大，所以反向电流不再是常数，而是随 V_R 缓慢上升。

4.2 它怎么用：解释图 9.8 里那条「不饱和」的反向电流

课件第 38 页的图 9.8 是 PtSi–Si 肖特基二极管的反向 I–V：理论曲线（只有 J_sT）是一条水平线，实验曲线却随反偏电压明显上升。差别正是 eΔφ/kT 这一项：反偏越大 ⇒ E 越大 ⇒ Δφ ∝ √E 越大 ⇒ 电流按指数上升。

这是一个很好的「非理想效应如何进入 I–V」的范例：物理上只是势垒被压低了几十毫伏，但在指数关系下就是几倍的电流。所以做功率器件时，反向漏电往往由势垒降低主导，而降低漏电的办法是提高势垒高度（换金属、改善界面）或降低界面电场（用 guard ring 之类的终端结构）。

4.3 例题：从电流反推理查森常数（课件第 39 页 例 9.4）

例 9.4　某肖特基二极管在 300 K 测得 φ_Bn = 0.67 V、J_sT = 6×10⁻⁵ A/cm²。求有效理查森常数 A*，并讨论其合理性。

解：由 J_sT = A*T²exp(−φ_Bn/V_t) 反解：

A* = JsT/[T2exp(−φBn/Vt)] = 6×10−5/[9×104×exp(−0.67/0.0259)]

其中 exp(−0.67/0.0259) = exp(−25.87) = 5.8×10⁻¹²，故

A* = 6×10−5/(9×104×5.8×10−12) = 6×10−5/(5.2×10−7) = 1.15×102 A/(K2·cm2)

即约 114 A/(K²·cm²)，与课件给出的 114 一致。

点评：114 与自由电子的 120 只差 5%，对应 m_n*/m₀ ≈ 0.95。这个值介于硅的态密度质量（1.08）与电导质量（0.26）之间，是很典型的实验值。考试如果只问「A* 的量级」，答 10² A/(K²·cm²) 即可；问「为什么不是 120」就答：有效质量取值不同 + 非理想效应修正。

【一句话记住】

J = A*T²e^(−φ_Bn/V_t)[e^(V_a/V_t) − 1]：与 pn 结同一副骨架，只是把「少子扩散」换成了「多子翻墙」。

温度进 T² 又进指数，所以结温每升高 10 ℃，反向电流大约翻一倍——这是肖特基二极管热失控的根源。

【易错提醒】

· 把 A* 当成普适常数：它含有效质量，不同半导体不同；而且同一材料的不同晶向、不同金属也会给出不同值。

· 忘了 e 与 kT 的单位：公式里用的是电压形式，指数上必须是 φ_Bn/V_t（无量纲），不能写成 eφ_Bn/kT 却把 φ_Bn 代成毫伏。

· 以为反向电流真的饱和：那只在理想模型成立时。实际器件里 Δφ 让它随反压上升，高温下更明显。

5 第五节：肖特基二极管与 pn 结二极管——同一条曲线，两种物理

5.1 先讲为什么：I–V 公式一模一样，为什么工程上还要分两种二极管

课件第 40 页指出：两者的 I–V 形式相同（都是 J_s[e^(V/V_t) − 1]），区别只在两处——J_s 的数量级和开关特性。而这两处差别又都来自同一个根源：pn 结靠少子扩散，肖特基靠多子热电子发射。课件第 41 页用一张对照图把这个根源画得很直观（图 4-4）。

图 4-4　同为二极管，输运主体不同：左为 p⁺n 结（少子扩散主导，I_R-G 可忽略），右为金属-n 型硅（多子热电子发射主导，少子复合可忽略）（课件第 41 页）

看图要抓住两点：

• 左边 p⁺n 结：正偏时 p⁺ 区的空穴（少子）扩散进 n 区，箭头标着 Dominant；而 n 区电子翻到 p⁺ 区的那条路标着 Negligible——因为 p⁺ 侧掺杂极高，电子一到就被复合掉了。整条电流靠少子注入 + 扩散维持。

• 右边金属-n 型硅：正偏时 n 区电子直接翻过 Φ_B 进入金属，标着 Dominant；而价带电子从金属流入半导体（等效于向半导体注入空穴）标着 Negligible、电流记作 I_r-g。整条电流靠多子翻墙维持。

这个区别带来的第一个可测后果：少子要存储，多子不用。pn 结正偏时 n 区里存着一堆非平衡空穴，要关断必须先把它们抽走或复合掉，这段时间叫存储时间；肖特基二极管里几乎没有少子存储，所以能做得极快（第 5.4 小节）。

5.2 算一算：J_s 差 6 个数量级意味着什么（课件第 42 页 例 9.5）

例 9.5　比较同一块硅上的肖特基二极管与 p⁺n 结：肖特基的 J_sT = 5.98×10⁻⁵ A/cm²；p⁺n 结取 N_a = 10¹⁸、N_d = 10¹⁶ cm⁻³，D_p = 10、D_n = 25 cm²/s，τ = 10⁻⁷ s。求 pn 结的 J_s。

第一步，少子扩散长度（L = √(Dτ)）：

Lp = √(10×10−7) = 1.0×10−3 cm， Ln = √(25×10−7) = 1.58×10−3 cm

第二步，两侧的平衡少子浓度（n_i = 1.5×10¹⁰ cm⁻³）：

pn0 = ni2/Nd = 2.25×1020/1016 = 2.25×104 cm−3， np0 = 2.25×1020/1018 = 225 cm−3

第三步，扩散电流两项相加：

Js = eDppn0/Lp + eDnnp0/Ln = 3.6×10−11 + 5.7×10−13 = 3.66×10−11 A/cm2

点评：与肖特基的 5.98×10⁻⁵ 相比，大了约 1.6×10⁶ 倍。这个差别的物理来源很直白：pn 结的 J_s 正比于少子浓度 p_n0 = n_i²/N_d（极小），而肖特基的 J_sT 正比于 exp(−φ_Bn/kT)（也不大，但没有 n_i² 那么小）。记住这个比值量级：肖特基的饱和电流比硅 pn 结大约 5—6 个数量级。

5.3 它怎么用（一）：开启电压为什么低一半（课件第 43—45 页）

开启电压（turn-on voltage）的工程定义：让电流达到某个实用值（比如 10 A/cm²）所需的电压。由 J = J_s·e^(V/V_t) 反解：

Von = (kT/e)·ln(J/Js)(4-23)

开启电压由饱和电流决定：J_s 越大，V_on 越小（对数关系）。肖特基的 J_s 大 6 个数量级，所以 V_on 低约 0.36 V。

课件第 43 页还把反向电流补全了：pn 结反偏时还有耗尽区产生电流 J_gen，总反向电流是两者之和。

Jgen = eniW/(2τ0)， JR = Js + Jgen(4-24)

产生电流：耗尽区里热产生的电子-空穴对被电场拉走。硅二极管在室温下 J_gen 往往远大于 J_s，是反向漏电的主体。

把本例的数代进去：p⁺n 结 W ≈ 3.4×10⁻⁵ cm（0 V 时），τ₀ = 10⁻⁷ s，则

Jgen = 1.6×10−19×1.5×1010×3.4×10−5/(2×10−7) ≈ 4×10−7 A/cm2

代入数验算：这是 p⁺n 结的实际反向电流量级，比 J_s = 3.66×10⁻¹¹ 大四个数量级——硅二极管的反向电流确实由产生电流主导。

所以反向电流的对比是：肖特基约 6×10⁻⁵ A/cm²，pn 结约 4×10⁻⁷ A/cm²——肖特基的反向漏电大两个数量级左右。这就构成了一个经典的设计权衡：要低开启电压就用肖特基，要低漏电就用 pn 结。

课件第 43 页的图 9.10 把两条正向曲线画在一起：肖特基大约 0.3 V 就明显导通，pn 结要 0.6 V 左右。课件第 46 页进一步指出这个开启电压的物理来源不同：肖特基由势垒高度 φ_Bn 决定（换金属就能调），pn 结由掺杂浓度决定（通过 V_bi = V_t ln(N_aN_d/n_i²)）。这句话是很好的考点。

例 9.6　设工作电流密度 J = 10 A/cm²，求两种二极管的正向压降。已知肖特基 J_sT = 5.98×10⁻⁵、pn 结 J_s = 3.66×10⁻¹¹ A/cm²。

5.4 它怎么用（二）：为什么它能做到皮秒级开关（课件第 46—47 页）

课件第 46—47 页点出了肖特基最值钱的特性。先看 pn 结为什么慢：正偏时大量少子被注入并存储在对面中性区，要关断必须先抽走或复合这些存储电荷，这就是存储时间（storage time），量级在纳秒。同时 pn 结还有扩散电容（diffusion capacitance）——正偏时存储电荷随电压变化，等效成一个很大的电容。

肖特基二极管没有这些问题：

• 没有少子存储——电流是多子翻墙，金属里的电子「来了就走」，不存在「存一堆少子在半导体里」这回事，所以没有存储时间；

• 没有扩散电容——只剩一个小的势垒电容（就是第 2 节算的 C′）；

• 结果：开关时间由 RC 常数决定，可以做到皮秒量级（pn 结是纳秒量级，差 2—3 个数量级）。

课件第 46 页还有一句容易被忽略但很重要的话：正偏时「价带电子从金属流入半导体」等效于「向半导体注入空穴」，也就是确实存在一点点少子电流。但它的占比极低（图 4-4 里标着 Negligible），所以不会带来可观的存储电荷。这正是「多子器件」这个词的准确含义：不是没有少子，而是少子无关紧要。

顺便说明频率上限：肖特基二极管的截止频率还受串联电阻 R_s 与结电容 C_j 限制（f_c ≈ 1/(2πR_sC_j)）。所以要高频，就得降低 R_s（重掺外延层、减小面积）和降低 C_j（减小面积、降低掺杂）——又回到第 2 节那两个公式。

【一句话记住】

肖特基：J_s 大 ⇒ 开启电压低（0.3 V）、漏电大、开关快（皮秒）；pn 结：J_s 小 ⇒ 开启电压高（0.7 V）、漏电小、开关慢（纳秒）。

一句话根源：肖特基靠多子翻墙，pn 结靠少子扩散；少子要存储，多子不用。

6 第六节：欧姆接触——把「过路费」降到零

6.1 先讲为什么：整流接触会把器件的有用信号吃掉

课件第 48 页给欧姆接触（ohmic contact）下了三条工程标准：非整流（两个方向都能通）、接触电阻很低（电压降可以忽略）、I–V 线性（电流与电压成正比，且工作电压很小）。理想欧姆接触的 I–V 就是一条过原点的直线，斜率倒数就是接触电阻。

为什么非要它？设想一个 MOSFET 的源漏：如果接触是整流的，那么无论沟道做得多好，电流都会被两个额外的肖特基势垒卡住，跨导、驱动能力全部报废。同理，激光二极管、太阳能电池、功率器件的每一个电极，都要求欧姆接触。一句话：整流接触是「有意做出来的器件」，欧姆接触是「不得不用但又必须让它不存在」的东西。

课件第 48 页把实现方式分成两类：① 非整流接触（靠功函数选对，让半导体表面积累多子，势垒消失或极低）；② 隧道接触（靠重掺杂把势垒做薄，让电子直接隧穿）。第二类才是产业界真正在用的方案。

6.2 功函数判据：让半导体表面「积累」而不是「耗尽」

第 1 节我们假设 φ_m > φ_s，结果是半导体表面耗尽、能带向上弯、形成整流势垒。现在反过来：取 φ_m < φ_s。此时金属的费米能级更高，电子从金属流向半导体，半导体表面积累电子——能带向下弯曲，表面变成一层高电导的电子积累层（accumulation layer），课件第 49 页的图 9.11 画的就是这个情形。

为什么这样就欧姆了？因为电子从半导体到金属没有势垒（能带向下弯，电子一路下坡），而从金属到半导体虽然有一个小台阶，但课件第 50 页指出：加任一种极性的电压都能导通——金属加正压时电子下坡流入金属；半导体加正压时，电子面对的「有效势垒」约等于 φ_Bn = φ_n（不是 φ_B0），而重掺杂时 φ_n 极小（只有几十毫伏），所以两个方向都畅通。

p 型半导体完全对称：取 φ_m > φ_s，电子从半导体流向金属，表面留下空穴堆积（能带向上弯），形成空穴积累层，空穴从半导体流入金属没有势垒。课件第 51 页给出了这幅图，第 52 页用一张表把两种情况并列。

6.3 它怎么来的：隧道接触——把墙做薄，让电子「穿」过去

课件第 54 页讲的是本章第二个核心机制：隧道效应（tunneling）。经典物理里电子能量低于势垒就绝对过不去，但量子力学给出一个非零的穿透概率，而且这个概率随势垒宽度指数下降。既然 W ∝ 1/√N_d，那么掺杂越重，墙越薄，隧穿概率越大。

Jt ∝ exp(−eφBn/E00)， E00 = (eħ/2)√[Nd/(εsmn*)](4-25)

隧穿电流的指数形式。E_00 叫特征能量（课件第 54 页），它正比于 √N_d：掺杂越重，E_00 越大，指数衰减越弱，隧穿越容易。

E_00 的物理意义：它衡量「势垒有多容易被穿透」。把 N_d = 10¹⁹ cm⁻³、m_n* = 0.26m₀、ε_s = 11.7ε₀ 代进去，得到 E_00 ≈ 34 meV（即 0.034 V）。于是 eφ_Bn/E_00 ≈ 0.67/0.034 ≈ 20，穿透因子约 e⁻²⁰ ≈ 2×10⁻⁹。而 N_d = 10¹⁶ 时 E_00 只有约 1 meV，同样的比值变成 600 多——隧穿完全关闭。所以「重掺杂」不是一个模糊的说法，它有明确的判据：E_00 要与 φ_Bn 可比。

W ∝ 1/√Nd ⇒ Nd ↑ ⇒ W ↓ ⇒ 隧穿概率 ↑

隧道接触的核心逻辑链：掺杂提高 100 倍，势垒薄 10 倍，隧穿电流指数上升。

例 9.7（课件第 55 页）　在 N_d = 7×10¹⁸ cm⁻³ 的 n 型硅上做接触，φ_Bn = 0.67 V。求 0 V 时的耗尽层宽度，并与例 9.1 比较。

第一步，φ_n：

φn = 0.0259×ln(2.8×1019/7×1018) = 0.0259×1.386 = 0.036 V

第二步，V_bi：V_bi = φ_Bn − φ_n = 0.67 − 0.036 = 0.634 V。

第三步，宽度：

xn = √[2×1.04×10−12×0.634/(1.6×10−19×7×1018)] = √(1.18×10−12) = 1.1×10−6 cm

即 11 nm ≈ 110 Å，只有约 40 个原子层厚。

点评：与例 9.1（N_d = 10¹⁶，W = 2080 Å）相比，掺杂只提高了 700 倍，宽度却缩小了近 19 倍。110 Å 这个厚度，电子有相当大的概率直接穿过去——这就是隧道欧姆接触的物理基础。工程上还会再往前一步：在 n-Si 表面先做一层 n⁺（10¹⁹—10²⁰ cm⁻³）再覆金属，宽度可以压到 2—3 nm。

6.4 它怎么用：比接触电阻 R_c——欧姆接触的唯一硬指标

欧姆接触好不好，用一个数说话：比接触电阻（specific contact resistance）R_c，单位 Ω·cm²。定义是 I–V 曲线在原点处的斜率的倒数（课件第 57 页）：

Rc = (∂J/∂V)−1|V=0(4-26)

比接触电阻的定义。用电流密度而不用电流，是为了把面积除掉，让不同尺寸的器件可以比较。单位 Ω·cm²。

两种机制给出两个完全不同的表达式：

Rc(热电子发射) = (kT/e)·exp(eφBn/kT)/(A*T2) = (Vt/(A*T2))exp(φBn/Vt)(4-27)

热电子发射机制：R_c 随 φ_Bn 指数上升、与掺杂几乎无关。所以低掺杂时想降 R_c，只能降低势垒。

Rc(隧穿) ∝ exp[(2√(εsmn*)/ħ)·φBn/√Nd](4-28)

隧穿机制：R_c 随 1/√N_d 指数下降。所以高掺杂时加大掺杂效果极其显著——这是欧姆接触设计的核心杠杆。

把两者的量级算一下，就知道该选哪条路。 取 φ_Bn = 0.60 V、A* = 114 A/(K²·cm²)、T = 300 K：

• 低掺杂（N_d = 10¹⁶）：只有热电子发射，R_c = (0.0259/(114×9×10⁴))·e^(0.6/0.0259) = 2.5×10⁻⁹×1.2×10¹⁰ ≈ 30 Ω·cm²。这个值太大了——一个 10 μm × 10 μm 的接触就有 3×10⁴ Ω，器件根本没法用。

• 高掺杂（N_d ≳ 10¹⁹）：隧穿主导，R_c 掉到 10⁻⁴—10⁻⁶ Ω·cm² 量级（课件第 58 页图 9.15 的实验数据）。同样面积的接触只有 0.1—1 Ω，可以接受。

两者相差 6—8 个数量级——这就是为什么所有的欧姆接触都必须重掺杂，没有例外。课件第 58 页的图 9.15 把这件事画成了一张 R_c–N_D 图：横轴 N_D 从 10¹⁷ 到 10²⁰，纵轴 R_c 跨 10 个数量级；三条理论曲线对应 φ_B = 0.85 / 0.60 / 0.40 V，实验点（PtSi–Si、Al–Si）落在曲线上。图中清楚地显示：N_D ≳ 10¹⁹ 之后曲线急剧下折，隧穿开始主导。

图 9.15 还给出一个重要的设计结论：势垒越低，曲线整体越靠下——所以「低势垒 + 重掺杂」是最优组合。这也解释了为什么 p 型欧姆接触通常比 n 型难做：可用的低功函数金属太少（Al 的 4.28 eV 对 p-Si 已经算高了）。

6.5 工程现实：为什么欧姆接触是工艺里最「玄」的一环（课件第 59 页）

课件第 59 页很诚实地列了四条实践困难，值得逐条体会：

• 良好欧姆接触 = 低势垒 ← 表面重掺杂：逻辑链是「重掺杂 → 薄势垒 → 隧穿 → 低 R_c」，但重掺杂本身有上限；

• 宽禁带材料更难：SiC、GaN 的 E_g 大，φ_Bn 也大（往往 1 eV 以上），而且受主/施主的离化能深，室温下掺不活；

• 表面掺杂受固溶度限制、分布不均匀：杂质在硅里的固溶度上限约 10²⁰—10²¹ cm⁻³，超过就析出；而且扩散/注入的 profile 不是理想的阶跃，实际势垒形状比模型复杂；

• 需要大量经验性处理：退火温度、气氛、金属层厚度、界面氧化层去除——每一个都会改变 R_c 几倍。

所以真实的工艺开发里，欧姆接触往往是「试出来」的：先按「低势垒金属 + 重掺杂」定方向，再用 TLM（传输线法）测出一组 R_c，扫退火温度找最优点。理论负责给方向，实验负责给数字。

【一句话记住】

欧姆接触两条路：① 功函数选对（积累层，φ_m < φ_s 对 n 型）；② 重掺杂到隧穿（工程主流）。R_c = (∂J/∂V)⁻¹，热电子机制 ∝ e^(φ_B/V_t)，隧穿机制 ∝ e^(φ_B/√N_d)。

【易错提醒】

· 把「接触电阻低」当成「没有电阻」：欧姆接触仍有 R_c，只是小。功率器件里它仍会贡献可观的导通损耗。

· 以为 φ_m < φ_s 就一定是欧姆：还要看掺杂。若掺杂很低，即使能带下弯，电流仍受限于热电子发射，R_c 依然很大。

· 把 R_c 的单位写成 Ω：它是比接触电阻，单位 Ω·cm²，乘以面积（除以面积）才是实际的接触电阻。

7 第七节：半导体异质结——换材料换出的新自由度

7.1 先讲为什么：同质结只有一个可调参数（掺杂），异质结多了一个（材料）

课件第 60 页定义：异质结（heterojunction）是两种不同半导体材料形成的结。同质结只能靠掺杂调 E_F 的位置，而异质结还能靠禁带宽度不同造出能带台阶，于是可以做出同质结根本做不到的事：把电子和提供电子的杂质在空间上分开（第 7.6 小节）。

课件把异质结按界面过渡的陡峭程度分两类：突变异质结（abrupt，界面在几个原子层内完成过渡，用 MBE/MOCVD 生长）和缓变异质结（graded，组分 x 随位置连续变化，例如 GaAs–AlₓGa₁₋ₓAs）。还特别强调：两种材料的晶格常数必须匹配良好，失配会在界面产生位错和大量界面态，这些缺陷会成为复合中心和非辐射复合通道，把器件性能（尤其是发光效率）全部吃掉。这条约束解释了为什么外延生长要「晶格匹配」：GaAs 与 AlAs 的晶格常数只差 0.16%，所以 GaAs/AlGaAs 可以任意比例互溶而不产生失配位错。

7.4 理想突变异质结的能带图与内建电势的分配

课件第 63 页给出了理想突变异质结的建模准则——理想电子亲和能准则（electron affinity rule）：

• 真空能级在界面处连续（和金属-半导体接触同一条假设）；

• 导带的 ΔE_c 与价带的 ΔE_v 在界面处保持不变，与偏压、掺杂无关——它们是材料常数，不能被「调」。

接触前，两块材料的 E_c、E_v 各按自己的 χ 与 E_g 排在真空能级下方；接触后，费米能级被拉平，两侧各自发生能带弯曲，弯曲量分别记为 eV_bin（窄禁带侧）与 eV_biP（宽禁带侧）。

图 4-5　理想突变异质结（n-Ge/P-GaAs）：左为接触前，右为热平衡后。真空能级连续、ΔE_c 与 ΔE_v 固定，两侧各自弯曲 eV_bin 与 eV_biP（课件第 63 页）

从图上可以直接读出（课件第 64 页）：

eVbi = eVbiP + eVbin(4-30)

总内建电势差等于两侧弯曲量之和——和 pn 结一样，只是这里两侧的材料不同、介电常数与掺杂也不同。

为什么内建电势要「按电容分配」

界面两侧必须满足电中性：窄禁带侧的空间电荷等于宽禁带侧的空间电荷（等量异号）。设两侧耗尽宽度为 x_n 与 x_p：

eNdnxn = eNaPxp

两侧的电势降分别由各自的泊松方程给出（与单边突变结同构）：

Vbin = eNdnxn2/(2εsn)， VbiP = eNaPxp2/(2εsP)

两式相加并利用电荷相等，就得到总量关系 eV_bi = eV_biP + eV_bin。换句话说：内建电势按「谁更轻掺杂、谁的介电常数更小」来分配，轻掺杂一侧分到更多的电压降、更宽的耗尽区。这与 pn 结的单边突变结完全同一个逻辑。

与 pn 结的唯一区别：价带与导带在界面处是跳变的（有 ΔE_c、ΔE_v），不像 pn 结那样连续。这个跳变不影响静电学的记账，却决定了载流子的输运——它是「墙」也是「阱」。

课件第 64 页还标出了 x = −x_n、x = 0、x = x_p 三个位置，说明空间电荷区确实横跨界面。这一点与金属-半导体结不同：后者只有半导体一侧有空间电荷（金属是理想导体，屏蔽长度只有原子尺度）。

7.5 二维电子气：本章最漂亮的一段物理

课件第 65 页从 nN 型异质结（N-AlGaAs / n-GaAs）出发。关键事实是：AlGaAs 的禁带比 GaAs 宽，所以它的导带底 E_c 更高。当两者接触后，电子会从 AlGaAs 流向 GaAs（因为 GaAs 一侧的导带更低），直到费米能级拉平为止。结果是：AlGaAs 里留下带正电的离化施主 D⁺，GaAs 界面附近则堆积了一层电子。

课件第 66 页（图 4-6）画的正是这个界面附近的能带：GaAs 一侧的导带向下弯曲，弯出一个势阱（potential well）。电子掉进这个能量低谷以后，往左走会遇到 AlGaAs 的 ΔE_c（一道墙），往右走会发现 GaAs 深处的导带逐渐升高（一个坡），两边都被挡住，于是只能待在界面附近很薄的一层里。这个「被限制在界面附近、只能沿界面自由运动」的电子系统，就叫二维电子气（two-dimensional electron gas, 2DEG）。

图 4-6　N-AlGaAs/n-GaAs 界面处的导带弯曲：GaAs 一侧形成电子势阱（灰色区域），电子被 ΔE_c 与能带升高夹在界面附近；AlGaAs 中留下 D⁺（课件第 66 页）

为什么会「量子化」？ 因为电子在 z 方向（垂直于界面）被关在一个宽度只有十几纳米的势阱里，这个尺度与电子的德布罗意波长可比，于是 z 方向的能量不再连续，而是一组分立能级 E_0、E_1、…；而在 x、y 方向（平行于界面）电子仍然自由，波矢 k_x、k_y 连续。课件第 67—68 页用三角势阱近似把这件事模型化：把弯曲的导带近似成一条斜线。

V(z) = eEz (z > 0)， V(z) = ∞ (z < 0)(4-31)

三角势阱模型：z > 0 一侧是均匀电场 E 造成的线性势，z < 0 一侧是无限高势垒（AlGaAs 的 ΔE_c 近似）。

解这个势阱里的薛定谔方程（课件第 69 页）：

−(ħ2/2mn*)d2ψ/dz2 + V(z)ψ = Eψ(4-32)

一维薛定谔方程。解是 Airy 函数，能级是一组分立值 E_0、E_1、…，称为子带（subband）。

E = Ei + ħ2(kx2 + ky2)/(2mn*)(4-33)

总能量 = z 方向的量子化能级 E_i + x-y 平面内的连续动能。这就是「二维」的含义：一个方向量子化、两个方向自由。

三角势阱的能级有一组近似解（Airy 函数的前几阶），课件没给公式，这里补上以便估算：

Ei ≈ (ħ2/2mn*)1/3·[(3π/2)eE(i + 3/4)]2/3， i = 0, 1, 2…

三角势阱的子带能级（Airy/WKB 近似）。E 为界面电场，i 为子带序号。

不必记这个式子，但要记住它的两条推论：① E_i 与 E 的三分之二次方成正比，电场越强、能级越高、间距越大；② E_1/E_0 ≈ 1.7—1.9，所以子带间距是几十毫电子伏。对 GaAs（m* = 0.067m₀）、E = 5×10⁴ V/cm，可算出 E_0 ≈ 55 meV、E_1 ≈ 99 meV——与室温 kT = 25.9 meV 相比，E_0 已经有好几个 kT，E_1 又明显高于 E_0，所以 300 K 下主要是最低子带被占据。

课件第 70 页进一步给出电子的空间分布：n(z) ∝ |ψ_0(z)|²，而 ψ_0 必须在 z = 0 处为零（无限高势垒的边界条件），所以电子的峰值不在界面上，而是在界面以内几纳米处，然后向 GaAs 内部指数衰减。这解释了一个实验事实：2DEG 的电子其实生活在 AlGaAs/GaAs 界面靠 GaAs 一侧的一薄层里，离界面有几个纳米的距离——这个距离对后面的「调制掺杂」至关重要。

顺便给一个有用的数：二维系统的态密度是常数（与能量无关），每个子带为

N2D = mn*/(πħ2) ≈ 2.8×1013 cm−2eV−1 (GaAs)(4-34)

二维态密度：台阶状，每个子带贡献一个常数。它比三维的 √(E−E_c) 简单得多，这是二维系统的标志性特征。

用它可以估面密度：n_s ≈ N_2D·(E_F − E_0)。取 n_s = 10¹² cm⁻²，得 E_F − E_0 ≈ 0.036 eV——与前面算的 E_0 ≈ 55 meV 同一量级，自洽。记住 n_s 的典型值：10¹²—10¹³ cm⁻²，比三维掺杂浓度（10¹⁸ cm⁻³）乘上厚度（10 nm）得到的 10¹² cm⁻² 正好相当。

7.6 调制掺杂与 HEMT：把「提供电子的人」和「跑电子的路」分开

2DEG 真正的价值不在「二维」，而在「空间分离」。课件第 71 页讲调制掺杂（modulation doping）：把硅（施主）掺在 AlGaAs 里，让 GaAs 保持本征或轻掺杂。施主电离（D⁰ → D⁺ + e⁻）放出的电子转移到 GaAs 的势阱里，而 D⁺ 离子留在 AlGaAs 中——两者被界面分开了。

为什么要分开？因为离化杂质散射（ionized impurity scattering）是半导体里最强的散射机制之一：电子每经过一个带电离子，轨道就被库仑力偏折一次，迁移率下降。课件第 72 页指出：电子与 D⁺ 在空间上分离以后，库仑作用被大幅削弱，μ_n 大幅提高。用这种结构做的场效应管叫 HEMT（高电子迁移率晶体管，high electron mobility transistor）。

课件第 73 页给出器件层面的表达式：

Js = qnsμnEx(4-35)

2DEG 的电流密度：面电荷密度 n_s 乘以迁移率再乘以横向电场。注意这里的 n_s 是面密度（cm⁻²），所以 J_s 是「单位宽度的电流」。

要提高电流，只有两条路：提高 n_s（多掺施主、加大 ΔE_c）或提高 μ_n（减少散射）。调制掺杂的妙处是：它让这两件事不再互相矛盾。课件第 74 页把整条逻辑链串了起来：

ΔEc → 电子转移 → 三角势阱 → z 方向量子化 → 2DEG → 电子与离化杂质分离 → μn ↑

2DEG 的完整因果链。每一步都能在能带图上指出来——这是本章最值得记住的一条链。

但矛盾并没有完全消失。 课件第 75—76 页指出一个更实际的问题：如果为了 n_s 大而直接把 GaAs 重掺，那么 N_D⁺ 也随之增大，库仑散射增强，μ_n 反而下降——n_s 与 μ_n 互相打架。解决办法是插入一层未掺杂的 AlGaAs 间隔层（spacer），结构变成：

掺杂 AlGaAs ｜ 未掺杂 AlGaAs（spacer，厚度 ds）｜ 未掺杂 GaAs（沟道）

调制掺杂的标准外延结构。spacer 把施主离子与 2DEG 在空间上再推开一段距离。

课件第 77 页给出结论：spacer 越厚（d_s ↑），电子与 D⁺ 的平均距离越大，散射越弱，μ_n 越高。这叫远程掺杂（remote doping）或调制掺杂效应。当然 d_s 也不能无限加厚——太厚了 n_s 会下降（电子转移不过来），所以实际器件有一个最优的 d_s（通常几纳米到十几纳米）。这是一个典型的「两个反向趋势取最优」的工程问题，也是 HEMT 设计的核心参数之一。

7.7 渐变异质结：spacer 与 graded layer 不是一回事

课件第 78—79 页讲第三种结构：渐变异质结（graded heterojunction）。AlₓGa₁₋ₓAs 的 x 决定 E_g 与 E_c：x 越大，禁带越宽、导带越高。如果让 x 随位置连续变化 x = x(z)，那么 E_c(z) 也连续变化，界面不再是台阶，而是一段斜坡。这种做法可以平滑势垒、调节势阱形状与波函数分布。

课件第 79 页特别强调两者的区别，这是一个很好的概念题：

• spacer（间隔层）的作用是空间分离——把提供电子的施主与传输电子的沟道在物理位置上推开，降低离化杂质散射；

• graded layer（渐变层）的作用是平滑能带——通过让组分 x 连续变化来调整 E_c(z) 的形状，从而改变势阱深度、子带能级与波函数的分布。

两者常常同时使用：既用 spacer 降低散射，又用渐变层优化势阱形状。但它们解决的问题完全不同，不能混为一谈。

课件第 80 页做一个收束：2DEG 的电流仍然是 J_s = qn_sμ_nE_∥（E_∥ 是沿沟道方向的电场），而调制掺杂让它同时拿到「高 n_s」和「高 μ_n」，于是带来大电流能力、高速度、高频率、低噪声四个好处。本质只有一句话：把「提供电子的杂质」和「传输电子的通道」分开。这句话是整章的「技术眼」——前面所有的能带图、量子化、散射，都是为了实现这一句。

【一句话记住】

异质结三件事：ΔE_c = e(χ_n − χ_P) 定台阶；台阶造势阱；势阱关电子 ⇒ 2DEG。再把施主挪远一点 ⇒ 高迁移率 ⇒ HEMT。

【易错提醒】

· 把 ΔE_c 与 ΔE_v 搞反：ΔE_c 由电子亲和能之差决定（不是禁带差）；禁带差要在 ΔE_c、ΔE_v 之间分配。

· 以为 2DEG 就在界面上：波函数在界面处为零，峰值在 GaAs 内部几纳米处。

· 把 spacer 与 graded layer 混为一谈：前者分离电荷、降散射；后者平滑能带、调势阱。

· 忽略晶格匹配：失配超过 1% 就会产生位错，界面态密度暴涨，2DEG 迁移率反而下降。

8 全章总结与速查

课件第 81 页用五句话总结了全章，这里把它展开成可以复述的版本：

① 金属-半导体接触的两种命运，由一个势垒高度决定：φ_B0 = φ_m − χ。势垒高而厚 ⇒ 整流（肖特基）；势垒薄到可以隧穿（重掺杂）⇒ 欧姆。

② 肖特基二极管的 I–V 与 pn 结同形不同因：都写成 J_s[e^(V/V_t) − 1]，但 J_s 差 5—6 个数量级，因为它靠多子热电子发射，而 pn 结靠少子扩散。

③ 非理想效应必须记住两个：镜像力把势垒压低 Δφ = √(eE/4πε_s) 且随反偏变化；界面态把费米能级钉扎（φ_Bn → E_g/e − φ_0），使势垒不再随金属功函数变。

④ 欧姆接触的本质是「让势垒薄」：比接触电阻 R_c 在隧穿机制下随 1/√N_d 指数下降，所以所有欧姆接触都必须重掺杂。

⑤ 异质结的价值是把能带「剪」出台阶：ΔE_c 造势阱、势阱关电子成 2DEG、再把施主挪进 spacer，就得到高迁移率——这就是 HEMT。

课件第 82 页给了一张「整流 / 欧姆」的判据总表，它是全章最值得背下来的一页。注意四个象限的对称性：n 型要 φ_m > φ_s 才整流，p 型刚好相反——因为 p 型的多子是空穴，能带弯曲的方向要反过来看。

8.2 核心结论（背下来）

① 整流与否只看势垒「高不高、厚不厚」：高而厚 ⇒ 热电子发射受限 ⇒ 整流；薄 ⇒ 隧穿 ⇒ 欧姆。

② φ_B0 由材料定、V_bi 由掺杂定、偏压只改 V_bi。这句话能解释本章 80% 的定性题；而所有能带图的记账规则也只有三条：真空能级连续、E_F 拉平、χ 是常数。

③ 肖特基的 J_s 比 pn 结大 5—6 个数量级，所以开启电压低约 0.35 V、反向漏电大两个数量级。

④ 肖特基是「多子器件」：没有少子存储、没有扩散电容，开关时间做到皮秒级。

⑤ 两个非理想效应方向不同：镜像力让势垒变低（且随反偏变化）；界面态让势垒「钉死」（不随金属变）。

⑥ 欧姆接触必须重掺杂：R_c 在隧穿区随 1/√N_d 指数下降，这是唯一有效的杠杆。

⑦ 异质结的杀手锏是空间分离：把提供电子的施主与传输电子的沟道分开，μ_n 大幅提高。

⑧ 量级必须记住：W ~ 0.1 μm（10¹⁶）到 10 nm（10¹⁹）；E_max ~ 10⁴—10⁵ V/cm；J_sT ~ 10⁻⁵ A/cm²；R_c ~ 30 Ω·cm²（低掺杂）到 10⁻⁴ Ω·cm²（重掺杂）；2DEG 的 n_s ~ 10¹² cm⁻²。

9 自测题（含详解）

1. 铂（φ_m = 5.65 eV）与 N_d = 10¹⁶ cm⁻³ 的 n 型硅形成肖特基接触。求 φ_B0、φ_n、V_bi，并判断它属于整流还是欧姆接触。

2. 承上题，若把硅换成 GaAs（χ = 4.07 eV、ε_s = 13.1ε₀），理想模型预言的 φ_B0 是多少？为什么实测值通常不随金属改变？

3. 某肖特基二极管在反偏 5 V 时界面电场为 1.5×10⁵ V/cm，硅的 ε_s = 1.04×10⁻¹² F/cm。求镜像力造成的势垒降低 Δφ 与最大势垒位置 x_m。

4. 判断题：肖特基二极管的反向电流随反偏电压增大而增大，是因为势垒高度 φ_B0 被反偏压降低了。

5. 为什么同样面积下，肖特基二极管的开关速度可以比 pn 结快 2—3 个数量级？如果只看势垒电容，两者差不多，差别在哪里？

6. 要在 n 型 SiC（E_g = 3.2 eV）上做欧姆接触，为什么比在 n 型 Si 上难？给出两条可行的技术路线。

7. Al₀.₃Ga₀.₇As/GaAs 异质结中，AlGaAs 的 E_g = 1.80 eV、χ = 3.74 eV，GaAs 的 E_g = 1.42 eV、χ = 4.07 eV。求 ΔE_c 与 ΔE_v，并说明电子会往哪一侧转移。

参考答案

1. φ_B0 = 5.65 − 4.01 = 1.64 V；φ_n = 0.0259×ln(2.8×10¹⁹/10¹⁶) = 0.206 V；V_bi = 1.64 − 0.206 = 1.43 V。φ_m > φ_s（5.65 > 4.01 + 0.206 = 4.22），半导体表面耗尽，属于整流接触。注意 Pt 的势垒高达 1.64 V，这正是 PtSi 肖特基二极管反向漏电很小的原因。

2. 理想模型：φ_B0 = 5.65 − 4.07 = 1.58 V。但 GaAs 的界面态密度很大，费米能级被钉扎在中性能级附近，φ_Bn ≈ E_g/e − φ_0 ≈ 0.8—0.9 V，与金属功函数几乎无关（图 9.5 中 GaAs 的点几乎水平）。所以「换个金属调势垒」在 GaAs 上基本无效。

3. Δφ = √(eE/4πε_s) = √(1.6×10⁻¹⁹×1.5×10⁷/(4π×1.04×10⁻¹⁰)) = √(1.84×10⁻³) = 0.043 V；x_m = Δφ/(2E) = 0.043/(2×1.5×10⁷) = 1.4×10⁻⁹ m = 1.4 nm（即 14 Å）。验算：Δφ = 2Ex_m = 2×1.5×10⁷×1.4×10⁻⁹ = 0.042 V ✓。

4. 错。φ_B0 由材料决定，反偏改变不了它。反偏电流上升的真正原因是镜像力把有效势垒 φ_Bn = φ_B0 − Δφ 压低了，而 Δφ = √(eE/4πε_s) 随反偏电场增大。也就是说：降的不是 φ_B0，而是「减去 Δφ 之后的有效值」。

5. 差别在存储电荷的性质。pn 结正偏时中性区里存着大量非平衡少子，关断时必须先抽走或复合（存储时间，纳秒级），同时还有扩散电容；肖特基是多子器件，金属侧电子「来了就走」，没有少子存储，也没有扩散电容，只剩小的势垒电容，开关时间由 RC 决定，可到皮秒级。

6. 难点有两层：① SiC 的 E_g 大，φ_Bn 往往在 1 eV 以上，热电子发射的 R_c 极大；② 受主/施主离化能深，室温下掺杂难以全部电离，做不出足够重的掺杂，势垒压不薄。路线：① 高温离子注入 + 高温退火做出 10¹⁹—10²⁰ cm⁻³ 的重掺杂层，靠隧穿；② 用低功函数金属或插入薄界面层（如 Ti 加薄 SiN、或激光退火形成硅化物）降低有效势垒。

7. ΔE_c = e(χ_GaAs − χ_AlGaAs) = 4.07 − 3.74 = 0.33 eV（宽禁带一侧的导带更高）；ΔE_g = 1.80 − 1.42 = 0.38 eV，故 ΔE_v = 0.38 − 0.33 = 0.05 eV。GaAs 的导带底比 AlGaAs 低 0.33 eV，所以电子从 AlGaAs 转移到 GaAs，在 GaAs 界面形成势阱。这也说明这个组分下能带台阶主要在导带（0.33 对 0.05），非常适合做 n 沟道 HEMT。
