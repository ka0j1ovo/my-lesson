0 导学：一块硅片上的两个掺杂区，凭什么撑起整门课

课件第 4 页开门见山：PN 结是几乎所有半导体器件的基本单元。除金属-半导体接触外，结型器件都由 PN 结构成——二极管就是一个 PN 结；BJT 是两个背靠背的 PN 结；JFET 用反偏 PN 结的耗尽层去夹窄导电沟道；太阳能电池、LED、激光二极管的核心也是一块 PN 结。所以这门课后面每一个器件方程，最终都会落到本章的某一行公式上。

本章只有 59 页，却是全书公式密度最高的一章。它的逻辑其实极简：先讲清楚空间电荷区是怎么来的（定性），再用一条一维泊松方程把它全部算出来（定量）。后面第二节到第六节，无非是把同一个解在不同边界条件下反复使用：零偏、反偏、单边结、击穿。抓住这一点，三十多个公式其实只有三四个源头。

0.3 两条基本假设：不成立的话，全章公式都要重写

课件第 8 页把全章的前提压成两条。这两条不是数学技巧，而是物理条件——一旦不满足，后面所有解析式都得换掉。

第一条：玻尔兹曼近似成立（非简并掺杂）。 掺杂浓度不能高到让 E_F 进入能带。重掺杂到简并时，杂质能级互相重叠形成杂质带，材料的行为接近金属，费米分布必须原样保留，载流子浓度只能用费米-狄拉克积分算，指数公式全部失效。硅的经验界限大约在 10¹⁸ cm⁻³ 量级。

第二条：杂质完全电离（温度不能太低）。 室温下硅中的施主、受主基本全部电离，于是一定有 n 区的 n₀ ≈ N_D、p 区的 p₀ ≈ N_A，并且处处满足 n₀p₀ = n_i²。低温（比如 77 K）下杂质冻结，载流子由杂质电离能决定，本章所有结果都不适用。

这两条的直接后果，是空间电荷区里的电荷密度可以写成 ±eN 这样的常数。泊松方程因此退化成「二阶导数等于常数」，两次积分就能手算——这就是为什么 PN 结能有一个漂亮的解析理论，而 MOSFET 的短沟道效应只能靠数值仿真。

为什么第三条假设（突变结）放到第一节才讲

突变结不是物理假设，而是几何模型：它假定掺杂浓度在界面处从 N_A 直接跳成 N_D。真实的扩散结、离子注入结都有梯度，但突变结让 ρ(x) 变成分段常数，方程才解得动。

它只影响 ρ(x) 的形状，不影响上面两条「玻尔兹曼 + 完全电离」的地位，所以单独放到第一节讲。带 * 的 7.5 节要处理的正是这个模型失效的情形。

【一句话记住】

两条假设一到位，PN 结就变成一道纯静电学题：已知电荷分布求电场，已知电场求电势，两次积分加几个边界条件，答案唯一。

1 第一节：空间电荷区与内建电势——结自己给自己加了一个电压

1.1 先讲为什么：pn 结是什么，为什么要用突变结去近似它

结构上，pn 结简单得不像一个器件：同一块单晶，一边掺受主成 p 区，紧邻的一边掺施主成 n 区，两个区的交界面叫冶金结（metallurgical junction）（p004）。它不是把两块材料粘起来——粘起来会留一层氧化膜和大量界面态，器件就毁了。真实做法是在同一片硅上先扩硼、再扩磷（或离子注入），让掺杂类型在某个深度翻转，晶体结构始终连续。整块单晶、只有掺杂在变，这是 pn 结能工作的前提。

课件第 5 页给出突变结（abrupt junction）假设：各区内部掺杂均匀，界面处浓度从 N_A 直接跳到 N_D。真实结的掺杂是渐变的（扩散结近似余误差函数分布），但突变结有三点好处：

• 泊松方程里的 ρ 是分段常数，两次积分就得到解析解，看得见每一项的物理意义；

• 结论只依赖 N_A、N_D 两个数，便于看清「谁多谁少」的规律；

• 后面 7.5 节的非均匀掺杂，正是在这个模型上做修正，先有零阶模型才好谈修正。

什么时候突变结假设会失灵？当耗尽层宽度 W 与掺杂梯度的特征长度可比时。高压器件的 W 可达几十微米，此时线性缓变结模型更准。本章只做突变结，所有「W 与浓度无关地跳变」的结论都要记住这个前提。

1.2 它怎么来的：扩散、离子、内电场，三步走

两块掺杂不同的半导体一接触，界面两侧立刻出现巨大的浓度梯度：n 区电子浓度比 p 区高十几个数量级，p 区空穴比 n 区高十几个数量级。有梯度就有扩散：电子从 n 区扩散进 p 区，空穴从 p 区扩散进 n 区（p005）。

但载流子不能无限扩散下去。每走掉一个载流子，就在原地留下一个不能动的离子：p 区走掉一个空穴，留下一个带负电的受主离子 A⁻；n 区走掉一个电子，留下一个带正电的施主离子 D⁺（p007）。于是界面附近出现一层净负电荷、一层净正电荷——这就是空间电荷区（space charge region）。这一层里可动的载流子几乎被清空，所以又叫耗尽区（depletion region）。

电荷产生电场。正电荷在 n 侧、负电荷在 p 侧，电场线由正指向负，即由 n 指向 p，这就是内建电场（built-in field）。它的方向恰好反对扩散：电子想往 p 区跑，电场把它往 n 区推；空穴想往 n 区跑，电场把它往 p 区推。当扩散力与电场力大小相等、方向相反时，净电流为零，系统达到热平衡。

图 2-1　P 型与 N 型接合后，界面附近留下不能移动的负离子与正离子，形成空间电荷区与内电场（课件第 7 页）

这里有一个极易被误解的细节（p006）：空间电荷区的边缘仍然存在多子浓度梯度，所以扩散力从来没有消失。恰恰因为扩散力还在，才必须有一个电场去抵消它。凡是「耗尽区里没有载流子所以没有扩散」的说法都是错的——没有的是可动载流子，不是浓度梯度；热平衡的意思是两种力打平，不是两种力都不存在。

【易错提醒】

· 整个 pn 结是电中性的：p 区负电荷总量 = n 区正电荷总量。「局部带电、整体中性」是同一句话的两面（p007），不要只记住前四个字。

· 耗尽区不是「空无一物」，里面有大量固定离子；正是这些离子提供电场。把它想成「被抽真空」是理解后面所有公式的最大障碍。

· 内建电场不是外加的，也没有「内建电压推动电流」这回事：热平衡下它只维持平衡，对外不输出功率。用万用表量不到 V_bi，能测的只是它的变化（第五节的 C–V 截距）。

1.3 费米能级为什么必须水平：能带弯曲与 V_bi 的几何意义

第 1 章讲过，热平衡的判据是整个系统只有一个费米能级。接触前，p 区的 E_F 靠近价带、n 区的 E_F 靠近导带；接触后二者必须拉平，于是能带在结区发生弯曲（p010）。弯曲量用电子能量表示是 eV_bi，用伏特表示就是内建电势差（built-in potential）V_bi。注意这个弯曲是能带整体的平移：E_c、E_v、E_Fi 三条线平行地弯，弯曲前后它们之间的间距（即 E_g 与 n_i）不变。

图 2-2　热平衡下的能带图：E_F 在整块材料中水平，能带在空间电荷区弯曲 eV_bi，两侧分别弯曲 eφ_Fp 与 e|φ_Fn|（课件第 9 页）

课件第 9 页左右两张小图其实在说同一件事：掺杂越重，E_F 离对应的带边越近。N_A 越大，p 区的 E_F 越贴近 E_v，|φ_Fp| 越大；N_D 越大，n 区的 E_F 越贴近 E_c，|φ_Fn| 越大。这两句话在后面变成了 V_bi 公式里的两个对数项。

第 11 页给了一个非常漂亮的几何论证，值得单独记下来：同一种材料里，E_Fi 到 E_c 与到 E_v 的距离处处相同（因为 N_c、N_v、n_i 只与材料和温度有关，与位置无关）。所以两块材料接触后，E_Fi 在 p 区与 n 区的落差，就等于 E_F 相对两侧 E_Fi 的偏移之和。用符号写出来，就是全章第一个公式：

eVbi = eφFp + e|φFn| ⇒ Vbi = |φFp| + |φFn|(2-1)

φ_Fp、φ_Fn 定义为 (E_Fi − E_F)/e：p 区 E_F 在 E_Fi 之下 ⇒ φ_Fp > 0；n 区 E_F 在 E_Fi 之上 ⇒ φ_Fn < 0。所以 V_bi 是两者绝对值之和。

这个式子的价值在于：它把「能带图上量一段距离」变成「算两个由掺杂决定的数」。接下来只剩一件事——把 N_A、N_D 翻译成 φ_Fp、φ_Fn。

1.4 它怎么来的：从 n₀ = N_D 推到 V_bi 公式（课件跳过的四步）

课件第 12、13 页给出结果，中间只写了「两式相除」。这四步其实很值得自己推一遍，因为它用到的技巧（同除本征式、取对数、把两个 ln 合并）在本章后面反复出现。

把 N_D、N_A 换成 φ_Fn、φ_Fp，再合成 V_bi

第一步：同一个 n₀ 写两遍。 在 n 区，电子浓度既可以用导带态密度写，也可以用本征浓度写：

n0 = Nc exp[−(Ec − EF)/kT], ni = Nc exp[−(Ec − EFi)/kT]

两式相除，N_c 与 E_c 一起消掉，只剩费米能级相对 E_Fi 的位置：

n0/ni = exp[(EF − EFi)/kT] ⇒ n0 = ni exp[(EF − EFi)/kT]

第二步：代入完全电离。 n 区 n₀ ≈ N_D，两边取自然对数，解出 φ_Fn：

ND/ni = exp[(EF − EFi)/kT] ⇒ φFn = (EFi − EF)/e = −(kT/e) ln(ND/ni)

φ_Fn 是负的：n 区的 E_F 在 E_Fi 之上，而定义式是 E_Fi − E_F。符号不要吞掉。

第三步：p 区照抄一遍。 把 n₀ 换成 p₀、N_c 换成 N_v、E_c 换成 E_v，指数里的符号自然反过来：

p0 = NA = ni exp[(EFi − EF)/kT] ⇒ φFp = (EFi − EF)/e = +(kT/e) ln(NA/ni)

第四步：相加。 两个绝对值相加，两个 ln 合并成一个 ln——分子相乘、分母平方：

Vbi = (kT/e)[ln(ND/ni) + ln(NA/ni)] = (kT/e) ln(NAND/ni2)

要点：全过程只用了玻尔兹曼近似与完全电离这两条假设，没有别的近似。所以只要材料非简并、杂质全电离，这个式子就是严格的。

n0 = ni exp[(EF − EFi)/kT](2-2)

n 区的电子浓度用费米能级相对本征能级的位置表示；p 区对称地有 p₀ = n_i exp[(E_Fi − E_F)/kT]。

φFn = −(kT/e) ln(ND/ni), φFp = +(kT/e) ln(NA/ni)(2-3)

两个费米势。N_D 越大，φ_Fn 越负（E_F 越靠近 E_c）；N_A 越大，φ_Fp 越正（E_F 越靠近 E_v）。

Vbi = |φFn| + |φFp| = (kT/e) ln(NAND/ni2)(2-4)

本章第一个核心公式。注意 N_A、N_D 都在对数里、相乘，所以两侧掺杂互换不改变 V_bi——它只认「掺杂有多重」，不认「哪边更重」。

Vt = kT/e, Vbi = Vt ln(NAND/ni2)(2-5)

V_t 叫热电压（thermal voltage），300 K 时为 0.0259 V。它是本章所有指数式与对数式的天然标尺：60 mV 对应 e 倍。

数量级感是这一节最该带走的东西：V_bi 里是对数，掺杂浓度变化 10 倍，V_bi 只变 (kT/e)·ln10 ≈ 59.6 mV。硅的 V_bi 通常在 0.6—0.9 V 之间，几乎不随掺杂大幅变动。这个「迟钝」极其重要：它意味着后面很多地方可以把 V_bi 当常数，甚至在与几伏的反偏电压相加时直接忽略，误差也只有百分之几。掺杂真正决定的是 W、C、V_B，不是 V_bi——这个分工是本章最容易搞混的地方。

【易错提醒】

· 符号约定陷阱。 Neamen 教材里 n 区写 φ_Fn = +(kT/e)ln(N_D/n_i)，本讲义与课件统一写成 (E_Fi − E_F)/e，n 区为负。两种写法只差一个负号，V_bi 用绝对值相加，结果完全一样。看题时先确认用的是哪一种。

· 公式里的 n_i 是本征浓度，不是掺杂浓度。把 n_i 写成 N_D 会让 ln 里的量纲变成 1，数值也会大错。

· V_bi 是热平衡下的量；它不能直接测量、不能对外做功。能测的是它的变化——第五节的 1/C²–V 截距。

NAND/ni2 = (2×1017)(1×1015)/(1.5×1010)2 = 2×1032/2.25×1020 = 8.89×1011

2 第二节：解泊松方程——把电荷分布变成电场和电势

2.1 先讲为什么：只知道「有电场」，还算不出电场

上一节是定性图像：有正负离子、有电场、有电势差。要把它变成能算的公式，必须请出静电学的基本方程——泊松方程（Poisson equation）。它把「电荷在哪里」翻译成「电场长什么样」，是所有半导体器件解析模型的地基：MOS 的阈值电压、BJT 的耗尽电容、JFET 的夹断电压，全是它的变体。

为什么可以只用一维？因为结面在横向是均匀的（器件横向尺寸远大于结深），所有物理量只随 x 变化。三维方程退化成一维常微分方程，而 ρ 又是分段常数，两次积分就完事——这是本章唯一需要动笔的数学。整章的技术难度就集中在这一节，过了这里，后面全是代数。

d2φ/dx2 = −ρ/εs = −dE/dx(2-6)

一维泊松方程。ε_s 是材料介电常数，ρ 是净电荷体密度（C/cm³），E 是电场，φ 是电势。由 E = −dφ/dx 可得 dE/dx = ρ/ε_s。

符号约定必须一开始就钉死：电场是电势的负梯度 E = −dφ/dx，所以 dE/dx = ρ/ε_s。后面所有正负号都从这里长出来；写错一个符号，电场方向就反了，紧接着「电场由 n 指向 p」这句话也会跟着错。本章统一取 x 轴由 p 指向 n，冶金结在 x = 0。

按突变结假设，整个器件被分成三段：两个中性区（ρ = 0）和中间的空间电荷区（ρ = ±eN）。每一段都是常系数方程，解出来是二次函数（φ）与一次函数（E）。三段怎么接起来，由边界条件决定。

2.2 它怎么来的（一）：从 ρ 积到 E，两个积分常数怎么定

把 dE/dx = ρ/ε_s 两边对 x 积一次：

E(x) = (1/εs)∫ρ(x)dx + C

不定积分出一个常数 C。p 区和 n 区的 ρ 不同，必须分开积，各自出一个常数。

这两个常数不是由公式本身定出来的，而是由边界条件定的。这一步课件写得很快，但它恰恰是初学者最容易漏的地方：没有边界条件，电场可以整体平移任意一个常数，电势差就无从谈起。课件第 16、17 页分别给出 p 区与 n 区的积分结果，第 18 页再用「电场在冶金结处连续」把两个常数锁在一起。

两次积分 + 三个边界条件，解出 E(x) 与 N_Ax_p = N_Dx_n

p 侧（−x_p < x < 0）： ρ = −eN_A，积分得

E(x) = −(eNA/εs)x + C1

边界条件一：中性 p 区电场为零，而电场在 x = −x_p 处必须连续，所以 E(−x_p) = 0：

0 = (eNA/εs)xp + C1 ⇒ C1 = −(eNA/εs)xp

E(x) = −(eNA/εs)(x + xp), −xp ≤ x ≤ 0

n 侧（0 < x < x_n）： ρ = +eN_D，积分得

E(x) = (eND/εs)x + C2

边界条件二：E(x_n) = 0：

0 = (eND/εs)xn + C2 ⇒ C2 = −(eND/εs)xn

E(x) = −(eND/εs)(xn − x), 0 ≤ x ≤ xn

边界条件三：冶金结处电场连续。 两侧同为硅，电位移 D = ε_sE 连续，所以 E 连续。把 x = 0 分别代入两段：

−(eNA/εs)xp = −(eND/εs)xn ⇒ NAxp = NDxn

要点：最后一个式子不是额外假设，而是解出来的第三个条件。它等价于「p 侧负电荷总量 = n 侧正电荷总量」，所以又叫电中性条件。整个空间电荷区对外不显电性，只是内部劈成了正负两层。

E(x) = −(eNA/εs)(x + xp), −xp ≤ x ≤ 0(2-7)

p 侧电场：在 x = −x_p 处为 0，到冶金结处降到最负（即模最大）。负号表示电场指向 −x，也就是由 n 指向 p。

E(x) = −(eND/εs)(xn − x), 0 ≤ x ≤ xn(2-8)

n 侧电场：在 x = 0 处接上前一段的最大值，在 x = x_n 处回到 0。两段都是 x 的线性函数。

NAxp = NDxn(2-9)

电中性条件，也叫电荷平衡方程。它决定了耗尽区在两侧怎么分配：掺杂重的一侧分得薄。

|Emax| = eNDxn/εs = eNAxp/εs(2-10)

最大电场在冶金结处（x = 0）。两条直线的交点就在这里，因为 ρ 在那里变号。

电场形状的读法是这一节的精华：E 是 x 的线性函数，斜率是 ∓eN/ε_s。掺杂重的一侧斜率大、延伸短；掺杂轻的一侧斜率小、延伸长。最大电场一定在冶金结处——那里是电荷变号的地方，也是三角形的顶点。记住这个三角形，第六节的击穿、第五节的电容都要靠它。

图 2-3　均匀掺杂 pn 结的电场：两段直线组成 V 形（绝对值），顶点在冶金结，底边是 W（课件第 18 页）

【易错提醒】

· E 在 x = 0 处连续，但 dE/dx 在那里不连续（因为 ρ 跳变）。不要指望电场的导数连续。

· E_max 是负值（电场指向 −x）。写公式时保留负号，讨论大小时说 |E_max|；两者混用会导致后面 V_bi 的正负号出错。

· 中性区 E = 0 是近似：严格说中性区有很小的电场以驱动少子漂移，量级可忽略。这条近似是后面所有 W(V) 公式的基础——整个外加电压都降在耗尽层上。

2.3 它怎么来的（二）：从 E 积到 φ，两个积分常数与电势零点

有了 E，再用 E = −dφ/dx 积一次就得到电势（p019）。这一次要多做两个决定：电势零点放在哪里，以及两段之间的常数怎么接。这两件事合起来才给出 V_bi 的表达式（p020），缺一不可。

定零点、接连续、取总差：三步得到 φ(x) 与 V_bi

先定零点。 电势的绝对值没有意义，只有差值有意义。取 p 侧边界为零电位：φ(−x_p) = 0。这只是选了一个参考高度，不改变任何物理量。

p 侧： dφ/dx = −E = (eN_A/ε_s)(x + x_p)，积分得

φ(x) = (eNA/2εs)(x + xp)2 + C3

代入 φ(−x_p) = 0，二次项为零，故 C₃ = 0：

φ(x) = (eNA/2εs)(x + xp)2, −xp ≤ x ≤ 0

n 侧： dφ/dx = −E = (eN_D/ε_s)(x_n − x)，积分得

φ(x) = (eND/εs)(xnx − x2/2) + C4

第二个常数由 x = 0 处电势连续定。 把 x = 0 代入 p 侧得 φ(0) = eN_Ax_p²/(2ε_s)，于是：

C4 = (eNA/2εs)xp2

φ(x) = (eND/εs)(xnx − x2/2) + (eNA/2εs)xp2, 0 ≤ x ≤ xn

最后取总差。 在 x = x_n 处减去 x = −x_p 处的值（后者为 0）：

Vbi = φ(xn) = (eND/2εs)xn2 + (eNA/2εs)xp2

要点：φ 在两段里都是 x 的二次函数，所以在结区是一条抛物线；而电子的势能是 E = −eφ，所以能带的弯曲形状就是这条抛物线的镜像。能带在结区不是直线下降，是抛物线下降——这一点在四联图的第四栏一眼就能看出来。

φ(x) = (eNA/2εs)(x + xp)2, −xp ≤ x ≤ 0(2-11)

p 侧电势：在 x = −x_p 处为 0，在 x = 0 处升到 eN_Ax_p²/(2ε_s)。开口向上的抛物线。

φ(x) = (eND/εs)(xnx − x2/2) + (eNA/2εs)xp2, 0 ≤ x ≤ xn(2-12)

n 侧电势：斜率在 x = 0 处与前一段连续（电场连续），但二阶导数变号（电荷变号），所以这里有拐点。

Vbi = (e/2εs)(NDxn2 + NAxp2)(2-13)

把两段电势差加起来。这是第三个必须记住的 V_bi 表达式——它把 V_bi 与几何尺寸 x_n、x_p 直接连起来，下一节解 W 就靠它。

两个二次函数在冶金结处斜率连续（电场连续），但二阶导数变号（电荷变号），所以 φ 曲线在那里有一个拐点。能带图上对应的现象是：弯曲在空间电荷区里是「渐变的」，出了空间电荷区立刻变成水平线（E = 0）。这个「抛物线 + 两头水平」的形状，是判断一张能带图画得对不对的最快标准。

2.4 设计/解题时拿它干什么：用三角形面积一分钟验算

电势差还有一个更省事的算法：电场对距离的积分就是电势差，而 E–x 图（取绝对值）是一个三角形，面积 = 底 × 高 ÷ 2：

Vbi = ∫0W|E|dx = (1/2)|Emax|W(2-14)

面积法。积分区间取整个空间电荷区（区外 E = 0，不影响积分），所以电势差就是三角形面积。它只用 E_max 与 W 两个量，是本章最快的验算工具。

这个式子在例 2.2 里会立刻派上用场：我们会用它反查前面一长串公式算得对不对。更重要的是它能一眼看出一个设计权衡：同样的 V_bi，W 越宽，E_max 越低。这句话直接解释了第六节「为什么轻掺杂能耐受更高反压」——把同样的电压摊到更宽的距离上，峰值电场自然就低。

为什么三角形面积恰好等于电势差

电势差定义是 V = −∫E dx，取绝对值就是 |E| 曲线下的面积。

E 在结区是两条直线：从 −x_p 处的 0 线性升到冶金结的 |E_max|，再线性降回 x_n 处的 0。所以面积就是底 W、高 |E_max| 的三角形，即 ½|E_max|W。

反过来用：已知 W 与 V，可以直接写 |E_max| = 2V/W，不必碰 N_A、N_D。课件第 29 页的 E_max 公式就有这个形式，第四节会用到。

【一句话记住】

ρ 积一次得 E（常数靠 E = 0 的边界定），E 再积一次得 φ（常数靠 φ 连续定）；三角形面积 = V_bi 是最快的验算。

3 第三节：耗尽层宽度——把两个方程联立起来

3.1 先讲为什么：W 是器件设计的第一个参数

耗尽层宽度 W 一身兼四职：决定结电容（第五节）、决定击穿电压（第六节）、决定串联电阻、还决定载流子穿过结区的时间（影响频率特性）。所以「W 等于多少」是本章第一个真正的设计公式，也是后面所有器件章节反复引用的量。

定义很直白：W = x_n + x_p，即空间电荷区从冶金结向两侧延伸的距离之和（p021）。课件第 21 页用三张图讲它的形成过程，这三步值得记成一条时间线：

① 接触前：p 区、n 区各自独立，各有自己的 E_F，界面处没有净电荷。

② 接触瞬间：多子开始向对面扩散，界面两侧留下未被中和的离子，空间电荷区开始长出来。

③ 达到热平衡：离子层厚度刚好让内建电场完全抵消扩散，E_F 拉平，能带弯曲 eV_bi。

这三步在第 24 页用更规范的语言重讲了一遍，第 25 页再把它画成载流子、电荷、电场、电势四条曲线（四联图）。本节先解出 W 的公式，再用那两张图把结果「看」一遍。

3.2 它怎么来的：两个方程、两个未知数（课件跳过的消元）

手里正好有两个方程：一个是电中性条件，一个是电势差表达式。

NAxp = NDxn

方程一：电中性条件。

Vbi = (e/2εs)(NDxn2 + NAxp2)

方程二：总电势差。

未知数也是两个：x_n 与 x_p。课件第 22 页直接给出结果，中间消元的几步才是最该练的——考试里真正要你做的往往就是这个消元，而不是背公式。

五步解出 x_n、x_p、W

第一步：用电中性条件把 x_p 表示成 x_n。

xp = (ND/NA)xn

第二步：代入 V_bi 式，把 x_n² 提出来。 注意 x_p² 会带出 (N_D/N_A)²，与前面的 N_A 相乘正好消掉一个 N_A：

Vbi = (e/2εs)[NDxn2 + NA(ND/NA)2xn2] = (e/2εs)NDxn2(1 + ND/NA)

= (eNDxn2/2εs) · (NA + ND)/NA

第三步：解出 x_n。 把系数搬到左边：

xn2 = (2εsVbi/e) · NA/[ND(NA + ND)]

第四步：x_p 完全对称。 把上式里的 N_A 与 N_D 互换即可（因为两个方程对调 N_A、N_D 后形式不变）：

xp2 = (2εsVbi/e) · ND/[NA(NA + ND)]

第五步：相加得 W。 先提公因子：W = x_n + x_p = x_n(1 + N_D/N_A) = x_n(N_A + N_D)/N_A，两边平方：

W2 = (2εsVbi/e) · (NA + ND)/(NAND)

要点：三个式子的根号里都是「2ε_s × 电压 / e」乘一个只由掺杂比决定的无量纲因子。所以电压进平方根、掺杂进反平方根——这两个依赖关系比公式本身更值得记。

xn = {2εsVbi/e · NA/[ND(NA + ND)]}1/2(2-15)

n 侧扩展宽度。N_A 越大（p 区越重），x_n 越大——耗尽区向轻掺杂侧延伸。

xp = {2εsVbi/e · ND/[NA(NA + ND)]}1/2(2-16)

p 侧扩展宽度。与 x_n 完全对称，交换 N_A、N_D 即可。

W = xn + xp = {2εsVbi/e · (NA + ND)/(NAND)}1/2(2-17)

零偏耗尽层宽度。反偏时把 V_bi 换成 V_bi + V_R 即可（第四节）。这是全章被引用最多的公式。

这三个式子的依赖关系值得单独强调三遍：

• W ∝ √V：电压翻 4 倍，W 翻 2 倍。所以高压器件的耗尽层不会无限变宽。

• W ∝ 1/√N：两侧掺杂同时降 10 倍，W 涨约 √10 ≈ 3.2 倍。

• 掺杂比决定分配：N_A/N_D = 10 时，x_n/x_p = 10，薄的那一侧只有总宽度的 1/11。

3.3 例 2.2：课件里的标准算例（p023）

3.4 单边突变结：一个掺杂远大于另一个

实际器件几乎都是单边结：p⁺n 或 pn⁺，一侧重掺杂到 10¹⁸—10²⁰ cm⁻³，另一侧是 10¹⁴—10¹⁶ cm⁻³ 的漂移区。此时 N_A ≫ N_D，公式会大幅简化（p034）：

• 由 N_Ax_p = N_Dx_n 得 x_p = (N_D/N_A)x_n ≪ x_n：空间电荷区几乎全部落在轻掺杂一侧；

• W ≈ x_n，三个公式退化成一个，只含一个掺杂浓度：

W ≈ {2εsVbi/(eND)}1/2 （p+n 结，NA ≫ ND）(2-18)

单边结的耗尽层宽度。pn⁺ 结把 N_D 换成 N_A 即可。注意：只剩轻掺杂侧的那个浓度。

这条性质是整个功率器件设计的基础：耐压由轻掺杂的漂移区承担，重掺杂区只负责提供载流子。第六节的击穿电压公式里只出现 N_B（低掺杂侧浓度），根子就在这里。同理，第五节单边结的电容也只看 N_B——「谁是轻的那一边，谁说了算」，这句话会贯穿全章。

【易错提醒】

· 「单边结」不是「只有一边有电荷」：两侧电荷总量仍然相等（N_Ax_p = N_Dx_n），只是重掺杂侧的厚度被压得极小。

· W 公式里的 V 在零偏时是 V_bi，反偏时是 V_bi + V_R，别漏掉 V_bi。低压（几伏）时 V_bi 占比很大，忽略它会有 20% 以上的误差。

· 单位：用 cm 制时 ε_s 取 F/cm、N 取 cm⁻³、e 取 C，算出来的 W 单位是 cm，记得乘 10⁴ 换成 μm。这一步错，答案会差四个数量级。

3.5 把结果看一遍：三段形成与四联图

课件第 24 页用三帧图把「三阶段」重讲了一遍，重点从「怎么形成」转到「能量怎么变」：

① 接触前 E_Fp ≠ E_Fn，两边的费米能级高低不同，能带各自水平。

② 接触后多子扩散，界面留下离化受主 A⁻ 与离化施主 D⁺，电荷分离产生电场。

③ 热平衡时 J_drift + J_diffusion = 0，E_F 拉平为一条水平线，能带弯曲量恰好是 eV_bi。

第 25 页的四联图是全章最值得盯着看的一张图。四条曲线共用同一个 x 轴，从上到下依次是：载流子浓度（对数坐标）、净电荷 Q、电场 E、电势 V。

图 2-4　均匀掺杂 pn 结的四联图：载流子浓度（对数）、电荷、电场、电势共用同一横坐标（课件第 25 页）

读这张图的四个要点：

• 载流子浓度用对数坐标，所以在空间电荷区里呈直线下降——这正是玻尔兹曼分布 exp(−eV/kT) 的直接体现。如果纵轴换成线性坐标，这两条曲线会变成几乎垂直的悬崖。

• 电荷是方波：p 侧一片负、n 侧一片正，面积必须相等（电中性），高度比就是 N_A : N_D。

• 电场是三角形：顶点在冶金结，两侧斜率不同（因为 N_A ≠ N_D），底边就是 W。

• 电势是抛物线形的台阶：从中性 p 区的水平，经结区的弯曲，到中性 n 区的水平，总升高 ΔV = V_bi。

这四条曲线是一套的：Q 的积分（面积）给出 E，E 的积分（面积）给出 V。任何一个环节画错，后面必然对不上。做题时若怀疑自己算错，先检查「Q 的两块面积是否相等」——这是最快的自检点。

【一句话记住】

W 与电压是平方根关系，与掺杂是反平方根关系；单边结的 W 只认轻掺杂那一侧。

4 第四节：加反偏压——把势垒举高、把耗尽区拉宽

4.1 先讲为什么：反偏才是二极管工作的主战场

正偏下结导通、电流指数上升；反偏下结几乎不导电，只流过微安级的漏电流。而器件的耐压、结电容、开关速度全都在反偏状态下定义。所以这一节要回答三个问题：加一个反向电压 V_R 之后，势垒变成多少、W 变成多少、E_max 变成多少。

反偏的接法是p 区接低电位、n 区接高电位（p026）。这使外加电场与内建电场同向，势垒从 eV_bi 升高到 e(V_bi + V_R)。注意是「同向叠加」而不是「抵消」——很多人把反偏想成「把内建电场削弱」，方向完全想反了。

此时系统不再热平衡：p 区的费米能级与 n 区的费米能级被拉开 eV_R，整块材料不再有统一的 E_F（p026）。严格的描述要用准费米能级（quasi-Fermi level，旧称 imref），分别记作 E_Fp 与 E_Fn。好消息是：本章所有静电学结论（W、E、C）只依赖总电势差，不需要准费米能级——这是本章可以「只做静电学」的原因，也是它与第 3 章（二极管电流）的分界线。

Vtotal = Vbi + VR(2-19)

反偏下的总势垒高度。正偏时写成 V_bi − V_F（本章不讨论正偏）。注意 V_R 是外加电压的绝对值。

4.2 它怎么来的：为什么 W 一定变大

课件第 27 页给了一条非常干净的推理链，值得逐句背下来：

① 中性区的电场近似为零，所以外加电压几乎全部降在空间电荷区上；

② 电场线必须起于正电荷、止于负电荷（高斯定理）；电势差变大意味着 E–x 图下的面积变大；

③ 面积变大而斜率（由掺杂决定）不变 ⇒ 三角形必须变宽 ⇒ 电荷量增加 ⇒ W 增大。

换一种说法：要把势垒举高，就得在两边多暴露出一些离子；多暴露离子就是把边界往外推。所以反偏 = 耗尽层变宽 = 结电容变小 = 结电阻变大。这三件事是同一个原因的三个结果。

数学上只需要一件事：把 V_bi 换成 V_total = V_bi + V_R。前面所有零偏公式原样成立，包括 x_n、x_p、W、E_max 与三角形面积关系。这是本章最省力的地方——零偏解的每一个式子，只要做一次代换就得到反偏解。

W = {2εs(Vbi + VR)/e · (NA + ND)/(NAND)}1/2(2-20)

反偏耗尽层宽度。与零偏式只差 V_bi → V_bi + V_R。因为开平方，电压涨 4 倍 W 才涨 2 倍。

再补充一句容易被忽略的物理：反向电流并不是零，而是由少子漂移产生的饱和电流（第 3 章讲二极管时展开）。本节只关心静电学——W 与 E 怎么变；至于这个 W 里流过多少电流，是下一章的事。

4.3 例 2.3：同一个结加 5 V 反偏（p028）

题　用例 2.2 的结（N_A = 10¹⁶，N_D = 10¹⁵ cm⁻³，V_bi = 0.635 V），加 V_R = 5 V，求 W 与 |E_max|。

解：先算总势垒：

Vtotal = 5 + 0.635 = 5.635 V

用比例法最快——除了电压，公式里其它因子都没变，所以 W 与 √V 成正比：

W(5V) = W(0) × (5.635/0.635)1/2 = 0.951 × 2.979 = 2.83 μm

峰值电场同样按 √V 放大，也可以直接用三角形面积法：

|Emax| = 2Vtotal/W = 2 × 5.635/2.83×10-4 = 3.98×104 V/cm

校验：1.34×104 × 2.979 = 3.99×104 V/cm ✓

点评：电压加了 8.9 倍，W 只涨 3 倍，E_max 也涨 3 倍。两者都按 √V 增长：好处是高压器件的耗尽层不会失控地变宽；坏处是 E_max 一直在涨，反偏不可能无限加——它迟早撞上临界电场，这就是第六节的击穿。

|Emax| = {2e(Vbi + VR)/εs · NAND/(NA + ND)}1/2(2-21)

反偏峰值电场（一般突变结）。它是把 W 代进 E_max = 2V/W 得到的，两条路等价。

|Emax| = 2(Vbi + VR)/W(2-22)

峰值电场的面积法写法，最省事。设计时常用它：只要知道 W 和电压，不必碰掺杂浓度。

|Emax| ≈ {2e(Vbi + VR)ND/εs}1/2 （p+n 结）(2-23)

单边结的峰值电场，只含低掺杂侧浓度。注意它随 √V 增长、随 √N_B 增长——这两个依赖在第六节会直接变成击穿电压的表达式。

4.4 设计时拿它干什么：给定耐压反推掺杂（p030）

工程问题常常反过来问：要在 25 V 下工作、峰值电场不超过 2.5×10⁵ V/cm，低掺杂侧最多能掺多少？这就是课件第 30 页的例 7.4。它的思路是把 E_max 的平方形式当成方程解 N_D。

题　p⁺n 硅单边结，重掺杂侧 N_A = 2×10¹⁷ cm⁻³，要求 V_R = 25 V 时 |E_max| = 2.5×10⁵ V/cm，忽略 V_bi，求 N_D 的最大值。

解：把 |E_max|² = 2eV_R N_A N_D/[ε_s(N_A + N_D)] 两边乘开，整理成 N_D 的一次方程：

εs|Emax|2(NA + ND) = 2eVRNAND

ND = εs|Emax|2NA/(2eVRNA − εs|Emax|2)

先算两个中间量：

εs|Emax|2 = 1.036×10-12 × (2.5×105)2 = 0.0648

2eVRNA = 2 × 1.6×10-19 × 25 × 2×1017 = 1.60

代入：

ND = 0.0648 × 2×1017/(1.60 − 0.0648) = 1.296×1016/1.535 = 8.43×1015 cm-3

再算近似值做对比：若直接认为 N_A + N_D ≈ N_A（即 N_A ≫ N_D），分母里的 0.0648 可以扔掉：

ND ≈ εs|Emax|2/(2eVR) = 0.0648/8×10-18 = 8.09×1015 cm-3

点评：两个结果差 4%，说明「N_A ≫ N_D」在 20 倍掺杂比时已经够用，但要做精确设计就得用完整式。N_D 必须取小于等于 8.43×10¹⁵：掺杂越轻，同样电压下电场越低、耐压越高。再往下压会牺牲导通电阻（漂移区电阻 ∝ 1/N_D），这就是功率器件最核心的 trade-off。

顺便做一次跨节校验。第六节会证明单边结的击穿电压是 V_B = ε_sE_crit²/(2eN_B)。把 N_B = 8.43×10¹⁵、E_crit = 2.5×10⁵ V/cm 代进去：

VB = 0.0648/(2 × 1.6×10-19 × 8.43×1015) = 24.0 V(2-24)

与例 2.4 要求的 25 V 基本一致，差的 1 V 正是被忽略的 V_bi。同一个设计点用两套公式得到同一个答案，说明本章的公式是自洽的一整套。

【一句话记住】

反偏只做一件事：把 V_bi 换成 V_bi + V_R；W 与 E_max 都按 √V 长，电容按 1/√V 缩。

5 第五节：势垒电容——反偏结就是一个电压控制的可变电容

5.1 先讲为什么：电荷随电压变，就是电容

反偏下，结两侧的电荷量随电压变化：电压增大，边界外推，暴露出来的离子更多。有电荷随电压变化，就有电容。这个电容叫势垒电容（barrier capacitance），也叫耗尽电容（depletion capacitance），记作 C_j（单位面积记作 C′）。

物理图像（p031 的图 7.9）：把空间电荷区看成平板电容的介质，两侧的离子层看成两块极板。加 dV_R 后，n 侧边界从 x_n 移到 x_n + dx_n，多暴露出 eN_D dx_n 的正电荷；p 侧对称地多出负电荷。极板间距就是 W，而 W 随电压变——所以这是一个压控可变电容。变容二极管（varactor）就是靠这个效应工作的：用反偏电压调电容，从而调谐振频率。

C′ = dQ′/dVR(2-25)

势垒电容的定义（单位面积）。Q′ 是单位面积上 n 侧暴露的正电荷量（C/cm²），取大小，不带符号。

必须区分另一个电容：正偏时还有扩散电容（diffusion capacitance），它来自中性区存储的少子电荷，正比于正向电流。两者物理来源完全不同：势垒电容是「离子层间距变化」，扩散电容是「储存电荷的充放电」。第 3 章讲二极管交流模型时会把两者合起来，这里先记清楚势垒电容的来历。

5.2 它怎么来的：从 dQ′/dV_R 推到 ε_s/W（课件跳过求导）

课件第 32 页直接给出 C′ = ε_s/W，中间的求导跳过了。补齐它只需要对 x_n(V_R) 求一次导，再用一个「凑分母」的技巧把结果认成 W——这一步是全章最漂亮的一个代数巧合。

三步求导，第四步靠凑出 W

第一步：写出 Q′。 n 侧暴露的正电荷 = 电荷密度 × 厚度：

Q′ = eNDxn

第二步：对电压求导。 ε_s、N_D 与电压无关，只有 x_n 随电压变：

C′ = dQ′/dVR = eND(dxn/dVR)

第三步：求出 dx_n/dV_R。 把 x_n² 的表达式两边对 V_R 求导，注意 V_total = V_bi + V_R，所以 dV_total/dV_R = 1：

xn2 = (2εsVtotal/e) · NA/[ND(NA + ND)]

2xn(dxn/dVR) = (2εs/e) · NA/[ND(NA + ND)]

dxn/dVR = (εs/e) · NA/[ND(NA + ND)xn]

代回第二步，e 与 N_D 相继消掉：

C′ = eND × (εs/e) · NA/[ND(NA + ND)xn] = εsNA/[(NA + ND)xn]

第四步：认出分母就是 W。 由 W = x_n + x_p = x_n + (N_D/N_A)x_n = x_n(N_A + N_D)/N_A，所以

C′ = εs/W

要点：反偏结的电容与平行板电容同形，只是极板间距 W 是电压的函数。这就是为什么所有教材都用「平行板」来类比它——不是近似，是真的同形。

dQ′ = eNDdxn = eNAdxp(2-26)

电压变化 dV_R 时两侧新增的暴露电荷。两侧必须相等（电中性），所以 eN_Ddx_n = eN_Adx_p，这等价于对 N_Ax_p = N_Dx_n 求微分。

C′ = {eεsNAND/[2(Vbi + VR)(NA + ND)]}1/2(2-27)

一般突变结的势垒电容（显式写法）。把 W(V_R) 代回 C′ = ε_s/W 就得到它。分母里有 √V，所以电压越大电容越小。

C′ = εs/W(2-28)

本章最简洁的公式，也是最重要的一个：电容只由 W 决定。记住它，等于同时记住了「反偏调宽 W 就调小了 C」。

还有一条更快的路可以互相印证：由 Q′ = eN_Dx_n 与 W ∝ √V 可以直接得到 C′ ∝ 1/√V，再与 ε_s/W 对照，量纲与比例都对。两条路结果相同，说明求导没有漏项。顺便记住这个比例关系：C′ ∝ 1/√(V_bi + V_R)，这是变容二极管的核心特性曲线。

5.3 例 2.5：算一个具体电容（p033）

题　例 2.2 的结（N_A = 10¹⁶，N_D = 10¹⁵ cm⁻³，V_bi = 0.635 V），V_R = 5 V，结面积 A = 1×10⁻⁴ cm²，求 C′ 与 C。

解：W 已经在例 2.3 里算过：W = 2.83×10⁻⁴ cm。直接除：

C′ = εs/W = 1.036×10-12/2.83×10-4 = 3.66×10-9 F/cm2

乘面积得到总电容：

C = C′A = 3.66×10-9 × 1×10-4 = 3.66×10-13 F = 0.366 pF

点评：0.37 pF 是很小的电容。配 50 Ω 的源阻抗，时间常数 τ = RC ≈ 18 ps，对大多数电路都不是瓶颈；但功率二极管的面积可以到 1 cm²，C 就到 nF 量级，开关速度立刻成问题。这就是为什么高频器件必须做小面积，而功率器件必须忍受大电容。

顺便核对量级：本节所有例题的 C′ 都落在 10⁻⁹—10⁻⁸ F/cm²（即 1—10 nF/mm²），乘上典型的结面积后是 0.1—10 pF。如果算出 pF 以外的量级（比如法拉），一定是单位换算错了。

5.4 单边结：C–V 曲线变成一条直线（p034、p035）

把单边结的 W 代进 C′ = ε_s/W，得到只含低掺杂侧浓度的式子：

C′ ≈ {eεsND/[2(Vbi + VR)]}1/2 （p+n 结）(2-29)

单边结的势垒电容。课件第 35 页把这个式子的 N_A 划掉、N_D 圈起来，强调的就是「只认低掺杂侧」。

把它平方再取倒数，右边就变成 V_R 的一次函数：

(1/C′)2 = 2(Vbi + VR)/(eεsND)(2-30)

C–V 法的基本关系：1/C′² 与 V_R 成线性。斜率和截距各自携带一个参数，这就是它能用来测掺杂的原因。

也就是说，1/C′² 对 V_R 作图是一条直线（p035）。这条直线的两个特征量把材料参数全暴露了：

• 斜率 = 2/(eε_sN_D)：只要知道 ε_s，就能算出低掺杂侧浓度 N_D；

• 截距（1/C′² = 0 处）= −V_bi：直线外推到横轴的交点给出内建电势；

• 线性本身就是「突变结」的判据：若实测曲线弯曲，说明掺杂不是均匀的（对应 7.5 节的非均匀结，斜率会随电压变）。

ND = 2/(eεs · slope), Vbi = |intercept|(2-31)

从实测直线的斜率与截距反解两个参数。斜率的单位是 (F/cm²)⁻²·V⁻¹，代入时别混。

这就是 C–V 法测掺杂的原理，也是半导体工艺线上最常用的表征手段之一。它的好处是几乎不需要额外加工：只要有一个二极管和一个电容表，扫一遍反偏电压就能得到掺杂剖面。工业上的扩散电阻/外延层浓度验收，很多就是靠这一条直线。

5.5 例 2.6：从一条直线反推两个浓度（p036）

题　p⁺n 硅二极管，300 K 下测得 1/C′²–V_R 直线：横轴截距 −0.725 V（即 V_bi = 0.725 V），斜率 6.15×10¹⁵ (F/cm²)⁻²·V⁻¹。求 N_D 与 N_A。

解：先由斜率求低掺杂侧的 N_D：

ND = 2/(eεs × slope) = 2/(1.6×10-19 × 1.036×10-12 × 6.15×1015) = 2/(1.019×10-15) = 1.96×1015 cm-3

再由 V_bi 反解重掺杂侧的 N_A（注意这一步用的是 V_bi 的对数关系）：

NA = (ni2/ND) exp(Vbi/Vt) = (2.25×1020/1.96×1015) × exp(0.725/0.0259)

= 1.15×105 × 1.43×1012 = 1.64×1017 cm-3

点评：两个浓度差 84 倍，确实满足单边结假设（N_A ≫ N_D），自洽。

更值得注意的是精度分工：N_D 直接来自斜率，是线性拟合，比较准；N_A 来自截距经过指数放大，而截距本身是外推出来的，误差会被 exp 放大成几倍。所以 C–V 法测轻掺杂侧很准，测重掺杂侧只能给个数量级——这个「谁准谁不准」的分工，实验报告里经常被考。

【考点提示】

· 必考：给斜率求 N_D、给截距求 V_bi，两个方向都要会。

· 陷阱一：横轴若是 V_R（反偏取正），截距就是负的 −V_bi；有的教材把横轴取成 −V_R，直线变成下降的，坐标轴反了别慌，先看清横轴定义。

· 陷阱二：C′ 是单位面积电容（F/cm²），不是总电容。用总电容 C 作纵轴时，斜率的数值要乘 A²。

· 陷阱三：斜率单位是 (F/cm²)⁻²·V⁻¹ = cm⁴·F⁻²·V⁻¹，很多人在这里丢量纲。

【一句话记住】

反偏结 = 平行板电容，极板间距 W；1/C² 对 V 是直线，斜率给浓度、截距给 V_bi。

6 第六节：击穿——反偏电压的极限在哪里

6.1 先讲为什么：反偏不可能无限加大

课件第 37 页先做了一个对比：正偏使空间电荷区变窄、反偏使它变宽（p037）。接着提问：反偏电压能无限增大吗？ 答案是能加到某个值，再往上就崩了。当反向电压达到 V_B 时，反向电流会突然急剧增大，这个现象叫击穿（breakdown）（p038）。

击穿由两种机制引起：齐纳效应（Zener effect）与雪崩效应（avalanche effect）。两者都发生在强电场下，但物理过程完全不同——一个是量子隧穿，一个是碰撞电离。本节先把两种机制讲清，再把它们统一到「临界电场」这一个参数上，最后给出击穿电压的公式。

先破除一个常见误解（p050）：击穿不等于损坏。击穿是可逆的，只要外电路把电流限制住，电压撤掉后结就恢复；真正烧坏器件的是击穿后的大电流乘大电压产生的功耗发热。稳压二极管（齐纳二极管）正是故意工作在击穿区来提供稳定电压的。

6.2 掺杂决定耗尽区的宽窄：两种极端

击穿机制由谁决定？由耗尽区有多宽、电场有多集中决定，而这两件事又由掺杂决定。课件用两页把两个极端摆出来：

• 重掺杂（p039）：载流子多、复合快、离子密度高，所以同样电压下耗尽区被压得很窄、电场很陡；

• 轻掺杂（p040）：自由载流子少、复合慢，耗尽区被拉得很宽，电场被「摊薄」。

这两页其实在说同一件事的两面：掺杂越重，W 越窄，同样电压下 E 越高，越容易击穿。由 E_max = 2V/W 就能看出来：W 小，E 就大。所以「窄」是所有低压、低耐压器件的共同特征。

6.3 齐纳击穿：能带陡到可以让电子「穿过去」

重掺杂时 W 只有几纳米到几十纳米。这么薄的一层里要降掉整个势垒，电场就极强（10⁶ V/cm 量级）。能带图上看（p041）：p 侧价带与 n 侧导带在空间上被拉得非常近，中间只隔着一层很薄的禁带。

量子力学允许电子直接隧穿（tunneling）过去：不需要被热激发到导带，直接从 p 侧价带穿过禁带进入 n 侧导带，形成反向电流。这就是齐纳击穿。因为隧穿概率对势垒厚度是指数敏感的，所以齐纳击穿电压对掺杂极其敏感，而且只出现在低压范围（硅通常 < 5 V）。

齐纳击穿的电压随温度升高而下降

温度升高时晶格振动加剧、等效带隙略减、隧穿距离略短，隧穿概率增大，于是同样电流所需的电压下降——齐纳击穿的温度系数是负的（约 −2 mV/K）。

雪崩击穿正好相反（正温度系数，约 +2 mV/K），因为温度升高使声子散射增强、载流子平均自由程变短、更难积累到电离所需的能量。

工程上把 5—6 V 的稳压管做成两种机制混合，使两者温度系数相互抵消，得到接近零温度系数的基准源。这就是为什么「5.6 V 稳压管」在精密电路里特别常见。

6.4 雪崩击穿：一个载流子滚出一串载流子

轻掺杂时 W 很宽，电场没那么集中，但载流子在长距离里被加速得更久，动能可以超过禁带宽度。它撞上晶格原子时，能把价带电子撞到导带，产生一个新的电子-空穴对；新产生的两个载流子继续被加速、继续碰撞，一对变两对、两对变四对……这就是雪崩倍增（avalanche multiplication）（p042）。对大多数 pn 结，雪崩效应是主要的击穿机制。

定量描述需要两个量：电离率 α（单位长度上产生电子-空穴对的数目，单位 cm⁻¹）与倍增因子 M_n（p043）。课件第 43 页给出这两个量的定义，第 44 页把它们积成击穿条件：

In(W) = MnIn0(2-32)

倍增因子的定义。I_n0 是进入耗尽区的原始电子电流，I_n(W) 是流出的电流。M_n = 1 表示没有倍增；M_n → ∞ 表示击穿。

电流在耗尽区里沿途增长，增长率正比于当地的电子电流与空穴电流之和——因为电子和空穴都能电离，都能生出新的电子-空穴对：

dIn/dx = Inαn + Ipαp(2-33)

电流的沿途增长方程。α_n 是电子电离率、α_p 是空穴电离率，两者同量级（硅中空穴略低）。

为什么雪崩击穿的条件是 ∫αdx = 1

简化： 设两种电离率相等 α_n = α_p = α。这个假设在硅里不完全成立，但足以看清机制，而且结论的形式不变。

总电流守恒： 稳态下没有电荷积累，总电流 I = I_n + I_p 处处相等。于是

dIn/dx = α(In + Ip) = αI

从 0 积到 W： 左边是电子电流从入口到出口的增量，右边把常数 I 提到积分号外：

In(W) − In(0) = I∫0Wα dx

代入定义： I_n(0) = I_n0，I_n(W) = M_nI_n0；且倍增后总电流几乎全部由电子流承担，即 I ≈ M_nI_n0：

(Mn − 1)In0 = MnIn0∫0Wα dx ⇒ 1 − 1/Mn = ∫0Wα dx

取击穿极限： 击穿意味着即使没有原始注入也有电流，即 M_n → ∞，左边趋于 1：

∫0Wα dx = 1

物理意义：一个载流子穿过耗尽区的路上，平均刚好产生一个「接班人」。这时链式反应自持，电流只受外电路限制。这个积分叫电离积分，它等于 1 就是雪崩击穿判据。注意它只依赖电场分布（即 W 与掺杂），与外加电流无关——所以 V_B 是一个材料与结构参数，不是工作点参数。

1 − 1/Mn = ∫0Wα dx(2-34)

倍增因子与电离积分的关系。M_n 随电压上升而增大，因为 E 增大 ⇒ α 指数增大 ⇒ 积分增大。

∫0Wα dx = 1(2-35)

雪崩击穿判据（电离积分等于 1）。等价于 M_n → ∞。

6.5 临界电场：把两种机制统一到一个数上

不管是哪种机制，击穿发生的直接条件都能写成一句话：最大电场达到材料的临界电场 E_crit。

|Emax| = Ecrit(2-36)

击穿判据的统一写法。E_crit 是材料参数，与掺杂弱相关（图 2-6）。课件第 45 页把这句话作为击穿的定义。

课件第 45 页的图给出 E_crit 与低掺杂侧浓度 N_B 的关系：N_B 越大，E_crit 越高（大约从 3×10⁵ 升到 2×10⁶ V/cm）；当 N_B ≳ 10¹⁸ cm⁻³ 时，曲线对应的机制从碰撞电离（雪崩）转为隧穿（齐纳）（p046）。原因是那时 W 已经窄到几十纳米，局部电场极强，载流子还没来得及加速就被电场直接「拽」过禁带了。

图 2-6　击穿临界电场随低掺杂侧浓度的变化：左侧为雪崩（碰撞电离）区，N_B ≳ 10¹⁸ 转为隧穿（齐纳）（课件第 45 页）

有了 E_crit，击穿电压就能算出来。单边结的峰值电场与电压的关系是（忽略 V_bi，因为它相对 V_B 很小）：

|Emax| = {2eVRNB/εs}1/2

单边结的峰值电场，N_B 是低掺杂侧浓度。它随 √V 增长，所以电压越高电场越接近临界值。

令 |E_max| = E_crit、V_R = V_B，两边平方解出 V_B（课件第 47 页）：

VB = εsEcrit2/(2eNB)(2-37)

击穿电压。N_B 是单边结低掺杂侧的浓度。这个式子说明 V_B 与 N_B 成反比——掺杂越轻，耐压越高。

这个式子有一个非常重要的读法：V_B 里只出现 N_B，不出现重掺杂侧的浓度。所以设计耐压时只需要管好漂移区的掺杂，重掺杂衬底怎么掺都不影响耐压（它只影响串联电阻）。这就是为什么功率 MOSFET 的耐压层叫「漂移区」——它就是那个 N_B。

【考点提示】

· 判断机制的顺序：先看掺杂浓度 → 再看 W → 最后看 V_B 大小。三者必须一致，不一致说明记错了其中一条。

· 常见错误：说「齐纳击穿是击穿，雪崩是另一回事」。两者都是击穿，宏观表现都是反向电流陡增，只是微观机制不同。

· 温度系数：齐纳为负、雪崩为正。这个结论常被拿来考「为什么 5.6 V 稳压管温度系数最小」。

· V_B 只由低掺杂侧决定——这是单边结最重要的一条结论，选择题里经常用「重掺杂侧浓度翻倍，V_B 变不变」来设陷阱。

【一句话记住】

重掺杂窄结隧穿（齐纳、低压），轻掺杂宽结碰撞（雪崩、高压）；击穿可逆，烧毁靠散热。

7 第七节：全章总结与速查

7.1 八条必须记住的结论（p051、p052）

课件用两页做总结：第 51 页收回零偏（均匀掺杂结与耗尽区），第 52 页收回反偏与击穿。本讲义把它扩成八条，每条都对应一个能算的式子。

① 空间电荷区 = 净空间电荷 + 无可动载流子；电场由 n 指向 p，量级由掺杂与电压共同决定（p051）。

② 零偏下的电势差就是 V_bi：它维持热平衡、阻止多子继续扩散，对外不输出功率（p051）。

③ V_bi 只与掺杂的对数有关：硅在 0.6—0.9 V，掺杂差 10 倍只变 60 mV。做题时不要期待它有大变化。

④ E 与 φ 是泊松方程的两次积分：常数由 E = 0 的边界与 φ 连续定；三角形面积 = V_bi 是最快验算。

⑤ W 与 √V 成正比、与 √N 成反比；掺杂比决定 W 在两侧的分配，单边结只认轻掺杂侧。

⑥ 反偏只做一次代换：V_bi → V_bi + V_R；W 与 E_max 都按 √V 增，C′ 按 1/√V 减（p052）。

⑦ C′ = ε_s/W：反偏结就是极板间距可变的平行板电容；1/C²–V 直线的斜率给掺杂、截距给 V_bi。

⑧ 反偏足够大时发生雪崩击穿；V_B 是掺杂的函数，单边结中只取决于低掺杂侧（p052）。

7.5 课件留下的思考题：若 n 区重掺杂会怎样？（p058）

课件第 58 页在总结单边结之后留了一个问题：如果 n 区重掺杂，会怎样？ 这不是随口一问，它考的正是本章最核心的一句判断——「单边结到底哪一边说话」。

若 n 区重掺杂，会怎样？

先给结论：结就从 p⁺n 变成 pn⁺，空间电荷区几乎全部落在 p 区，所有「只认低掺杂侧」的公式里的 N_B 一律换成 N_A。

逐条推（每一步都只用本章公式）：

· 电中性条件仍是 N_Ax_p = N_Dx_n，但 N_D ≫ N_A ⇒ x_n = (N_A/N_D)x_p ≪ x_p，n 侧几乎不扩展；

· W ≈ x_p ≈ √[2ε_s(V_bi+V_R)/(eN_A)]，只由 p 侧浓度决定；

· 峰值电场仍是 eN_Ax_p/ε_s，位置仍在冶金结；

· 结电容 C′ = ε_s/W 只认 N_A，C–V 直线的斜率给出的是 N_A 而不是 N_D；

· 击穿电压 V_B = ε_sE_crit²/(2eN_A)，耐压由 p 侧决定。

一句话：单边结里「谁是轻掺杂，谁说了算」；重掺杂那一侧只负责提供载流子，不参与耐压、不参与电容。如果两侧都重掺杂，W 被压到几十纳米，击穿机制就变成齐纳隧穿，V_B 掉到几伏——这正是稳压管的设计思路。

【一句话记住】

零偏看 V_bi，反偏看 √V，电容看 W，击穿看 N_B——而 N_B 永远是掺杂轻的那一边。

2. 判断题：反偏电压增大时，耗尽层变宽，所以结电容增大。

3. 为什么最大电场一定出现在冶金结处，而不在空间电荷区的边缘？

4. 某硅 pn 结的 V_bi = 0.8 V，零偏耗尽层宽度 W = 2 μm。用面积法求 |E_max|。

5. 某 p⁺n 结的 1/C′²–V_R 直线斜率为 1×10¹⁵ (F/cm²)⁻²·V⁻¹，求低掺杂侧浓度 N_D。

6. 用本章的两个公式说明：为什么轻掺杂结的击穿电压更高？

参考答案

1. 先算 ln 里的量：N_AN_D/n_i² = 1×10³³/2.25×10²⁰ = 4.44×10¹²，ln = 29.12。故 V_bi = 0.0259 × 29.12 = 0.754 V。

　　W：2ε_sV_bi/e = 2×1.036×10⁻¹²×0.754/1.6×10⁻¹⁹ = 9.76×10⁶ cm⁻¹；(N_A+N_D)/(N_AN_D) = 1.1×10¹⁷/1×10³³ = 1.1×10⁻¹⁶ cm³；W² = 1.074×10⁻⁹ cm² ⇒ W = 0.328 μm。

　　|E_max| = 2V_bi/W = 2×0.754/3.28×10⁻⁵ = 4.60×10⁴ V/cm；C′ = ε_s/W = 1.036×10⁻¹²/3.28×10⁻⁵ = 3.16×10⁻⁸ F/cm²（约 3.2 nF/mm²，量级正常）。

2. 错。W 变大，而 C′ = ε_s/W，所以电容减小。直观理解：极板被拉开了。这条「反偏 ⇒ 电容变小」是变容二极管与所有结电容模型的基础。

3. 因为电场是 ρ 的积分：在 −x_p 到 0 之间 ρ 为负，E 从 0 线性变到最负；越过 x = 0 后 ρ 变正，E 的斜率变号，于是 E 开始回升。E 的极值点出现在 ρ 变号的地方，也就是冶金结。两侧掺杂不同只改变斜率，不改变「极值在结处」这个结论。

4. 面积法：V_bi = ½|E_max|W ⇒ |E_max| = 2V_bi/W = 2×0.8/2×10⁻⁴ = 8.0×10³ V/cm。注意 W 要先换成 cm。

5. N_D = 2/(eε_s·slope) = 2/(1.6×10⁻¹⁹ × 1.036×10⁻¹² × 1×10¹⁵) = 2/(1.658×10⁻¹⁶) = 1.21×10¹⁶ cm⁻³。这个浓度对应的击穿电压约 60 V（按表 2-7 的趋势内插），符合中压器件的典型值。

6. 两条路都通向同一结论：①由 W = √[2ε_sV/(eN_B)]，N_B 越小 W 越宽；而 |E_max| = 2V/W，同样的电压摊到更宽的距离上，峰值电场更低，要达到 E_crit 就得加更大的电压。②由 V_B = ε_sE_crit²/(2eN_B)，V_B 与 N_B 成反比，直接看出轻掺杂耐压高。代价是漂移区电阻变大（导通损耗增加），这就是功率器件的核心 trade-off。
