1 第一节：为什么是硅——半导体材料与晶体结构

1.1 先讲为什么：电导率差 24 个数量级，靠什么区分

课件第 12 页给了一把电导率标尺：铜、铝这类导体在 10⁶ S/cm 量级，SiO₂ 这类绝缘体在 10⁻¹⁶—10⁻¹⁸ S/cm 量级，而硅、锗落在 10⁻⁶—10⁰ S/cm 之间。半导体的定义不是电导率中等，而是电导率可以被外加条件大幅改变——温度升高改变几个数量级、掺入百万分之一的杂质又改变几个数量级。能被调，才有器件。

材料分两大类：元素半导体（IV 族：C、Si、Ge、Sn）与化合物半导体（III 族 + V 族，如 GaAs、GaN、InP、SiC）。元素半导体工艺简单、成本低；化合物半导体禁带可调、迁移率高，适合光电器件与高频高压器件。

为什么硅统治了集成电路

不是因为它电学性能最好——GaAs 的迁移率高得多。硅赢在三点：

· 能长出一层完美的 SiO₂：热氧化生成的二氧化硅致密、绝缘、与硅界面缺陷少，这是 MOS 栅极的前提；

· 单晶成本低、晶圆大：直拉法可以拉出 300 mm 直径、缺陷极少的单晶；

· 禁带 1.12 eV 恰到好处：室温下 n_i 只有 1.5×10¹⁰ cm⁻³，掺到 10¹⁶ 就能让杂质完全主导导电；同时 1.12 eV 又能在 125 ℃ 下保持器件不漏电。

1.2 它怎么来的：单晶、共价键与晶面

半导体器件必须用单晶：整个晶圆内原子排列周期一致，电子才有确定的能带结构。硅是金刚石型结构——每个硅原子与最近的 4 个硅原子形成 4 个共价键，每个共价键由两个自旋相反的电子占据。8 个价电子填满 4 个键，正好把价带填满，这就是下一节「为什么纯硅在 0 K 是绝缘体」的根源。

晶面用密勒指数 (hkl) 标记：三个数字是晶面法线在三个晶轴上截距的倒数。硅的金刚石结构里，不同晶面的原子面密度不同、每个表面原子的悬挂键数也不同，于是氧化速率、界面态密度、湿法腐蚀速率全都不一样——晶向因此不是一个几何记号，而是工艺配方里的一个参数。下一小节专门讲这件事的工程后果。

1.3 晶面与工艺：为什么 CMOS 用 (100)、MEMS 用 (111)

上一小节说「(100) 是标准衬底」，但没说为什么。要回答这个问题，得先数一数三个低指数面上的原子：(100) 面每个表面原子有 2 个悬挂键，面内原子密度 6.8×10¹⁴ cm⁻²；(111) 面每个原子只有 1 个悬挂键，面内原子密度 7.8×10¹⁴ cm⁻²（三者中最高）；(110) 面也是每个原子 1 个悬挂键，面密度 9.6×10¹⁴ cm⁻²。悬挂键越多、面密度越高，表面能越大，表面越「活泼」——氧化更快、腐蚀更快、也更容易吸附杂质。同样一块硅，换一个晶面切，等于换了一套表面化学

CMOS 选 (100) 的三个理由。 第一，SiO₂/Si 界面态密度最低：热氧化后 (100) 面上约 10¹⁰ cm⁻²eV⁻¹，而 (111) 面要高一个数量级；界面态会俘获载流子、散射沟道电子、使阈值电压漂移。第二，电子迁移率最高：(100) 面约为 (111) 面的 2 倍，而 CMOS 的速度主要由 NMOS 决定。第三，热氧化速率适中、氧化层致密，工艺窗口宽。代价是 (100) 面的空穴迁移率并非最高（(110) 面约高 1.5—2 倍），所以先进工艺会把 PMOS 的沟道转到 (110) 侧壁——这就是 FinFET 里的「晶向混搭」。

MEMS 选 (111) 的原因完全不同：它要的是「刻不动」。 各向异性湿法腐蚀（KOH、TMAH）对三个面的腐蚀速率差别极大，KOH 在 80 ℃ 下大约是 (110) : (100) : (111) ≈ 150 : 100 : 1。于是在 (100) 硅片上开一个矩形窗口，腐蚀会自动停在与表面成 54.74° 的 {111} 面上——这个角正是 (100) 与 (111) 的夹角，满足 tan θ = √2。结果就是标准的 V 形槽，以及靠腐蚀时间控制的悬空薄膜。54.74° 这个数不是设计出来的，是晶体几何给定的。工程上把 {111} 面叫「刻蚀自停止面」（etch-stop plane），压力传感器的膜片、加速度计的梳齿、喷墨头的腔体，都靠它一次成型、不需要光刻对准。反过来说，设计 MEMS 版图时图形边必须沿 ⟨110⟩ 方向对齐，否则刻出来的腔体是斜的、侧壁是一层层台阶而不是光滑的 {111} 面。

晶向对迁移率的影响可以一句话说完：同一材料不同晶面的表面粗糙度与界面态不同，表面迁移率可以差 2 倍以上；体迁移率各向异性则来自能带的各向异性（硅的电子在六个等价谷里分布，沿不同晶向的导电有效质量不同）。所以「迁移率是材料常数」这句话只在体材料里近似成立，到了 MOS 沟道里，它是晶向、应变、界面的函数。

【一句话记住】

晶向不是标签，是工艺参数：(100) 买低界面态与高电子迁移率，(111) 买「腐蚀刻不动」。

1.4 合金半导体与带隙工程：把 E_g 变成可调旋钮

到这里为止，E_g 一直被当成一个材料常数：硅就是 1.12 eV，没有商量余地。可是三元合金可以把两种二元化合物按任意比例混合，E_g 随组分连续变化——这等于给设计者装了一个旋钮。为什么非要这个旋钮？因为单一材料只能提供一种带隙：要做 850 nm 的激光器，需要 1.42 eV 的直接带隙；要做异质结发射区，需要比基区更宽的带隙；要做 1.55 μm 的光通信探测器，需要 0.8 eV 的带隙。硅的 1.12 eV 一个都满足不了。

以最经典的 Al_xGa_{1−x}As 为例。GaAs 的 E_g = 1.424 eV、直接带隙；AlAs 的 E_g = 2.16 eV、间接带隙。两者完全互溶，带隙随 x 近似线性上升，但只在 x < 0.45 时保持直接带隙：

Eg(AlxGa1−xAs) = 1.424 + 1.247x （x ≤ 0.45，直接带隙）(1-1)

线性插值（Vegard 定律）的近似式，单位 eV。x = 0.3 时 E_g = 1.80 eV，对应 690 nm 红光。

Eg = 1.9 + 0.125x + 0.143x2 （x > 0.45，间接带隙）(1-2)

x 超过 0.45 后导带底从 Γ 谷转到 X 谷，带隙变间接，发光效率骤降。两段曲线在 x ≈ 0.45、E_g ≈ 1.98 eV 处交接。

0.45 这个临界点是怎么来的：加 Al 会把 Γ 谷和 X 谷一起往上抬，但 Γ 谷抬得快、X 谷抬得慢，两条曲线在 x ≈ 0.45 相交。交点左边导带底在 Γ 点（直接），右边在 X 点（间接）。所以 AlGaAs 的发光器件一律把组分卡在 x < 0.45 这一侧：850 nm 的光纤通信激光器用 x ≈ 0.08—0.12，红光 LED 用 x ≈ 0.35—0.45。一旦越过 0.45，材料还是好材料，只是不再发光了——这是「带隙可调」的边界，也是「直接/间接带隙」这个概念的工程价值（§2.3 会解释为什么间接带隙不发光）。

SiGe 是另一条路线：不靠化学组分调带隙，靠应变调。 硅和锗可以任意比例互溶，但晶格常数差 4.2%，在硅上外延 SiGe 时，只要膜薄于临界厚度，晶格就被强行压成与硅一致——这叫应变（strain）。压应变让价带的重空穴带与轻空穴带分裂，带隙缩小 0.1—0.2 eV（Ge 含量越高缩得越多），同时空穴迁移率显著提高。工程上有两个直接用途：① SiGe HBT：基区 Ge 组分从发射区一侧到集电区一侧渐变（0 → 20%），带隙渐变产生一个内建电场，把电子「推」过基区，基区渡越时间缩短、截止频率提高；② 应变硅 PMOS：用 SiGe 源漏把沟道压应变，空穴迁移率提高 50% 以上。这两项都是纯硅做不到、也不需要换衬底的「能带工程」。

一句话说明「带隙可调」为什么是异质结与光电器件的前提：异质结的全部功能都来自两种材料之间的能带偏移 ΔE_c、ΔE_v——没有能带差，就没有单边注入（BJT 的发射效率）、没有二维电子气（HEMT）、没有量子阱（激光器）、没有「对电子是势垒、对空穴是陷阱」的选择性。而 ΔE_c、ΔE_v 只能靠改变组分（或应变）来设计。所以「合金」不是材料学的小花样，它是第 4 章异质结、第 5 章光电器件的入场券；到了那里，E_g 会从一个常数变成设计变量 x。

设计异质结的顺序也因此被卡死：先挑晶格匹配的材料对，再在匹配的范围内调组分定带隙。AlGaAs/GaAs 的失配小于 0.2%，所以这对组合成了异质结的教科书范例；GaN 与蓝宝石失配 16%，只能靠低温缓冲层硬撑，这也是蓝光 LED 花了二十年才做出来的原因之一。

合金的意义：把 E_g 从常数变成函数 E_g(x)，器件设计从此多了一个自由度；但直接带隙的窗口只有 x<0.45。

1.5 设计时拿它干什么：三个常数定生死

同一套器件方程里，材料只通过三个常数出现：E_g（决定 n_i 和光吸收波长）、m*（决定态密度和迁移率）、ε_s（决定耗尽层宽度和电容）。做设计时，先查这三个数，再代公式，量级就不会错。

Eg = Ec − Ev(1-3)

禁带宽度：导带底与价带顶的能量差，单位 eV。硅 1.12 eV，对应光子波长 λ(μm) ≈ 1.24/E_g(eV) ≈ 1.1 μm。

【一句话记住】

材料三常数：E_g 管能不能导电，m* 管有多少座位，ε_s 管电场能压多宽

2 第二节：从光电效应到能带——电子为什么只能坐在特定能量上

2.1 先讲为什么：经典物理算不出半导体的电阻

如果电子是经典小球，金属的比热、电阻随温度的变化都算不对。课件第 14 页从光电效应切入：用单色光照射金属，只有当光的频率高于某个阈值 ν₀ 时才有电子逸出，且逸出电子的最大动能只与频率有关、与光强无关。这说明能量是一份一份给的——光子能量 E = hν，电子吸收一份光子的能量后，先付出逸出功 φ，剩下的才变成动能。

E = hν， Tmax = hν − φ， ν0 = φ/h(1-4)

h = 6.625×10⁻³⁴ J·s = 4.135×10⁻¹⁵ eV·s；φ 为逸出功（work function），单位 eV。

把同样的能量量子化思路搬到晶体里，就得到能带：原子靠近时，原本分立的能级因相互作用而分裂、展宽成一段段允许的能量区间（能带），段与段之间是禁止电子存在的禁区（禁带）。对硅，价带被 8 个成键电子填满，导带全空。

2.3 E-k 关系与本征激发：从能带形状到电子-空穴对

能带图只画了能量轴，把波矢 k 藏了起来。可周期性势场里解出来的能量是函数 E(k)，同一段能带里不同的 k 对应不同的能量。价带顶都在 k = 0（Γ 点），导带底的位置却分两种：GaAs 的导带底也在 Γ 点，叫直接带隙（direct bandgap）；硅的导带底在 X 方向（k ≠ 0）、锗的在 L 方向，叫间接带隙（indirect bandgap）。能带图上两者都是一条 1 eV 多的缝、看不出区别，E-k 图上一眼就能分开。

区别为什么重要？因为电子跃迁要同时满足能量守恒与动量守恒。光子有动量，但小得可怜：

k光子 = 2π/λ ≈ 6×104 cm−1 ≪ π/a ≈ 108 cm−1(1-5)

光子动量比能带的动量尺度小四个数量级，所以光学跃迁在 E-k 图上可以当成一条竖线（Δk ≈ 0）。

于是直接带隙材料里，导带底的电子与价带顶的空穴正好同 k，一步复合就发光；间接带隙材料里，导带电子 k ≠ 0，要复合必须请声子补上动量（Δk ≈ π/a），这是二阶过程，概率小两三个数量级，多出来的动量最终变成热。硅做不了 LED 的全部原因就在这里——不是杂质多，是能带对称性不对。硅的辐射复合只占 10⁻⁵ 左右，而 GaAs 的 LED 内量子效率可以做到 90% 以上；把硅提纯到 9N 也没用。同一件事也解释了厚度：硅在带边附近的吸收系数只有 10²—10³ cm⁻¹（晶硅电池因此要做 180 μm 厚），GaAs、InGaAs 有 10⁴ cm⁻¹，1—2 μm 就够。效率与厚度都不是工艺选择，是 E-k 图决定的。

再看本征激发。 上一节说纯硅在 0 K 时价带全满、导带全空，是绝缘体；室温下它却能微弱导电，差的只有一个温度：价带电子从晶格热振动里借到一份能量、跳过 E_g 进入导带，同时在价带留下一个空穴。这叫本征激发（intrinsic excitation），产生的一对载流子叫电子-空穴对（EHP）。课件第 15—16 页把两种情形并排画了出来：0 K 时每个共价键都完整，导带「完全为空」、价带「完全占满」；T > 0 K 时一根键断了，电子跑到导带、断键处留下空穴。课件的结论只有一句：T > 0 K 时部分电子被热激发到导带，形成自由电子和空穴，因此半导体能导电。

图 1-1　T > 0 K 时共价键断裂、电子跃迁到导带并留下空穴（课件第 16 页，图 3.13）

激发需要的最低能量是 E_g，而室温的 kT = 0.0259 eV 比硅的 1.12 eV 小 43 倍。按经典能量均分根本激不动，但电子服从费米-狄拉克统计，高能尾巴上总有一小部分电子拥有超过 E_g 的能量。对本征硅，E_c − E_F ≈ 0.56 eV，这一比例约为 exp(−21.6) ≈ 4×10⁻¹⁰——小得难以想象，可硅原子有 5×10²² cm⁻³，乘起来仍有 10¹⁰ cm⁻³ 量级的载流子。「指数小 × 基数大」是半导体浓度的全部秘密。

ni ∝ exp(−Eg/2kT)， Eg/kT = 1.12/0.0259 ≈ 43(1-6)

本征激发的概率因子。指数上是 E_g/2kT 而不是 E_g/kT：一次激发产生两个载流子，各分一半（严格推导见 §4.3）。

激发与复合同时进行：导带电子迟早掉回价带与空穴复合（辐射复合放光子，非辐射复合放热），热平衡时两个速率相等，n、p 稳定在 n_i。温度升高，激发率指数上升，平衡点上移——n_i 不是「材料里天然有多少电子」，而是「激发与复合两个速率打平时的那个浓度」。它只由 E_g 和温度决定，与掺杂、尺寸无关；当 n_i 被温度抬到接近掺杂浓度时，材料本征化、器件失效（§4.6 会算这个温度），这就是所有器件最高工作温度的物理来源。

【一句话记住】

直接带隙一步发光、间接带隙请声子发热；本征激发一次生一对，概率 exp(−E_g/2kT)。

2.4 空穴：把少了一个电子当成一个带正电的粒子

价带本来是满的。满带不导电，因为电子无处可去。一旦某个键上少了一个电子，价带里就出现一个空态；邻近的价电子跳进来填补，空态就移动到了新位置。空态的移动等价于一个带正电、有效质量为正的粒子在移动，这个准粒子就叫空穴（hole）。课件第 17 页用三帧图把这个过程画得很清楚。

· 空穴不是真的正电荷粒子，它是价带中未被占据的量子态的集体行为；但在输运方程里，完全可以当作电荷 +e、质量 m_p* 的粒子来处理。

· 空穴浓度 p 数的是价带里空着的座位，不是正离子的数量——离子是不动的，不参与导电。

3 第三节：态密度与费米-狄拉克分布——数座位、算入住率

3.1 先讲为什么：知道能带位置，还不知道里面有多少电子

能带图只告诉我们哪些能量允许电子存在，没告诉我们某个能量上有多少个位置，更没告诉我们这些位置坐满了没有。这两件事必须分开算：

① 态密度 g(E)：单位体积、单位能量范围内有多少个允许的量子态——也就是这一排有多少个座位。

② 占据概率 f(E)：一个座位被电子占据的概率——也就是上座率。

两者相乘再对能量积分，才得到真正的载流子浓度。课件第 25 页用「空圆 = 空座位、实心蓝圆 = 已坐」的三栏图把这个区分讲透了。

3.2 有效质量：能带的弯曲程度决定了「座位」有多密

上一小节把导带底近似成抛物线 E − E_c = ħ²k²/(2m_n*)，直接用一个叫有效质量（effective mass）的参数，没解释它是什么、为什么能这么写。这一步必须补上，因为有效质量是本章唯一一个「把量子力学翻译成经典力学」的桥梁：有了它，电子在晶体里的运动可以完全按牛顿第二定律算，只是把真空质量换成 m*。而且它同时决定三件事——态密度（有多少座位）、迁移率（跑得多快）、以及器件的极限速度。可以说，第 1 章后面的所有数字，都挂在 m* 这一个参数上。

它怎么来的：从 E-k 关系出发。把能带在极值附近做泰勒展开，一次项为零（极值点），二次项系数就是曲率。把 E(k) 展开式与经典动能 ħ²k²/(2m*) 对照，立刻读出有效质量的定义：

E(k) = Ec + ħ2k2/(2mn*)， mn* = ħ2/(d2E/dk2)(1-7)

抛物线能带近似与有效质量的定义。ħ = 1.055×10⁻³⁴ J·s；曲率 d²E/dk² 越大，m* 越小。

这个定义的物理含义要反复念：曲率越大（能带越陡），有效质量越小，电子越「轻」，越容易被电场加速。注意 m* 有三个反直觉的性质：它可以是各向异性的（不同 k 方向曲率不同，硅的纵向与横向质量就差了 5 倍）；它可以比 m₀ 大（硅的 1.08 m₀）也可以比 m₀ 小（GaAs 的 0.067 m₀）；它甚至可以是负的——而负质量正是空穴概念的入口。

为什么空穴的有效质量为正。 价带顶是能带的极大值，那里 d²E/dk² < 0，直接套上式会得到负质量。负质量在经典力学里意味着「加速度与力反向」，很难用。于是换一套描述：把价带顶附近看成「满海的平面」，少了一个电子 = 多了一个带正电、质量为 −m* 的粒子，定义：

mp* = −ħ2/(d2E/dk2) > 0 （在 Ev 处取值）(1-8)

空穴有效质量。它是一个「折算质量」：把价带顶的负曲率与电子的负电荷一起翻号，换来一个正质量、正电荷的准粒子。

负号把两个负号（负曲率、负电荷）一起吸收掉，剩下的空穴就变成「电荷 +e、质量为正」的普通粒子。所以空穴的有效质量为正，不是物理上真有这么一个粒子，而是我们选了让它「好算」的符号约定。数值上它由价带顶的曲率决定，和电子质量没有固定的大小关系：硅的 m_p* = 0.56 m₀，约为电子（1.08 m₀）的一半；GaAs 的 m_p* = 0.48 m₀，却是电子（0.067 m₀）的七倍。「空穴比电子重」这句话只在 GaAs 这类材料里成立，不能当通则。

GaAs 的 m* 为什么只有 0.067 m₀。 GaAs 是直接带隙，导带底在 Γ 点，E-k 曲线在极小值附近非常陡（曲率大）；硅是间接带隙，导带底在 X 方向，曲率小。曲线越陡 ⇒ 曲率越大 ⇒ m* 越小。数值上：GaAs 0.067 m₀、Si 1.08 m₀（态密度有效质量）、Ge 0.56 m₀，相差 16 倍。这个差别带来两个直接后果：

• 态密度小：N_c 正比于 m* 的 3/2 次方。GaAs 的 N_c 只有 4.7×10¹⁷ cm⁻³，比硅的 2.8×10¹⁹ 小 60 倍。同样掺 10¹⁶，GaAs 的 E_F 会离导带远得多——这直接改变了它的结电容与开启电压。

• 迁移率高：μ = eτ/m*。质量小，同样的电场下加速度大，迁移率高。GaAs 的 μ_n = 8500 cm²/V·s，是硅的 6 倍多。注意只有 6 倍而不是 16 倍，因为散射时间 τ 也变了（GaAs 的极性光学声子散射更强）。

Nc = 2.5×1019(mn*/m0)3/2 cm−3 （300 K）(1-9)

有效态密度的实用形式。以 m* = m₀ 时的 2.5×10¹⁹ 为基准，按 3/2 次方缩放。硅 1.08 → 2.8×10¹⁹。

μ = eτ/m*(1-10)

迁移率与有效质量的关系（Drude 形式）。m* 小、散射时间 τ 长，迁移率就高；两个因素要一起看。

硅的 1.08 m₀ 为什么比单个谷的 0.19 m₀ 大这么多？ 因为硅的导带底有 6 个等价的谷（Δ 谷），每个谷各有各向异性的质量（纵向 0.916 m₀、横向 0.19 m₀）；统计上要把谷数与各向异性一起平均：谷数贡献 6 的 2/3 次方，各向异性贡献 (m_l m_t²) 的 1/3 次方，合起来 m_d* ≈ 1.08 m₀。所以有效质量不是电子变重了，而是「多个谷 + 各向异性」被压成了一个等效参数。

小算例　由 N_c 反算有效质量。已知 300 K 硅的 N_c = 2.8×10¹⁹ cm⁻³，求 m_n*/m₀；再用同一方法估算 GaAs（N_c = 4.7×10¹⁷ cm⁻³）的有效质量。

解：由 N_c ∝ (m*)^{3/2}，以 m* = m₀ 时的 N_c0 = 2.5×10¹⁹ cm⁻³ 为基准，两边相除再开 3/2 次方：

mn*/m0 = (Nc/2.5×1019)2/3

硅：2.8/2.5 = 1.12，再取 0.667 次方得 1.079，即 1.08 m₀ ✓

GaAs：0.47/25 = 0.0188，取对数 ln 0.0188 = −3.974，乘 0.667 得 −2.650，取指数得 0.0706，即 0.071 m₀ ✓

点评：与教材值 0.067 差 6%，因为 GaAs 的 N_c 用了更精确的 4.7×10¹⁷（含谷数与质量修正）。这个方法只用来做量级核对，不能代替查表。反过来更有用：看到 N_c 就能反推 m*，看到 m* 就能估 N_c，两者只差一个 3/2 次方。比如 N_c 小 60 倍，m* 就只有 60 的 2/3 次方、约 15 倍——这正是 GaAs 与硅的差距。

【易错提醒】

· 有效质量不是「电子真的变重/变轻」，它是能带曲率的等效参数。同一个材料里，态密度有效质量与导电有效质量数值不同，算 N_c 用前者、算迁移率用后者，不能混。

· 空穴质量取正号是符号约定的结果。写 m_p* = ħ²/(d²E/dk²) 而忘了负号，会得到一个负质量，后面的公式全反。

· m* 与温度弱相关（E_g 随温度变、曲率也变），但工程上当作常数。真正随温度剧烈变化的是 n_i，不是 m*。

【一句话记住】

能带越陡，有效质量越小：m* = ħ²/曲率。小 m* ⇒ 座位少（N_c 小）但跑得快（μ 高）。

3.3 态密度：抛物线形的座位表

把晶体的薛定谔方程在周期性势场中求解，得到能量 E 与波矢 k 的关系（E-k 关系，即能带结构）。对三维半导体，导带底附近可近似为抛物线：E − E_c = ħ²k²/(2m_n*)。在此之上数 k 空间里有多少个允许的 k 值，就得到态密度。

gc(E) = 4π(2mn*)3/2/h3 · √(E − Ec)， E ≥ Ec(1-11)

导带态密度：从 E_c 处为 0 开始按 √(E−E_c) 上升。m_n* 为电子有效质量（硅 1.08 m₀），h 为普朗克常数。

gv(E) = 4π(2mp*)3/2/h3 · √(Ev − E)， E ≤ Ev(1-12)

价带态密度：从 E_v 处为 0 开始，向低能量方向按 √(E_v−E) 上升（越往深处座位越多）。

两个公式只差一个符号方向：导带的座位向上长得快，价带的座位向下长得快，因为电子能量越高越自由，空穴能量越低（即电子能量越高）越自由。禁带内 g(E) = 0——那里根本没有座位。

【易错提醒】

· 态密度与温度无关（严格说只通过有效质量的温度修正弱相关），它只由材料和能带结构决定。温度改变的是占据概率，不是座位数。

· g(E)dE 的单位是 cm⁻³——它已经是单位体积的量，不用再乘体积。

3.4 费米-狄拉克分布：一个座位只能坐一个人

电子是费米子，服从两条铁律：全同粒子不可区分、每个量子态最多容纳一个电子（自旋相反算两个不同态）。从这两条出发做统计，得到占据概率：

fF(E) = 1/{1 + exp[(E − EF)/kT]}(1-13)

费米-狄拉克分布函数。E_F 为费米能级（化学势），k = 8.62×10⁻⁵ eV/K，kT = 0.0259 eV（300 K）。

这个函数只有两个参数：温度 T 和费米能级 E_F。它的形状极其重要：

• T → 0 K 时是阶跃函数：E < E_F 全部占据（f = 1），E > E_F 全部空着（f = 0）。E_F 就是最后一排坐满的位置。

• T > 0 K 时在 E_F 附近变圆滑：热能 kT 把台阶抹开，过渡区宽度约为几个 kT。

• 无论温度多少，f(E_F) 恒等于 1/2：把 E = E_F 代入，指数项为 exp(0) = 1，故 f = 1/(1+1) = 1/2。这是最常考的一个点。

fF(EF) = 1/[1 + exp(0)] = 1/2

费米能级处的占据概率恒为 50%，与温度无关——这是判断费米能级在哪的最快方法。

图 1-4　不同温度下的费米分布：所有曲线都过 (E_F, 1/2)，温度越高越平缓（课件第 38 页）

为什么 f(E_F) 一定是 1/2

这一步没有近似，纯代数：

fF(EF) = 1/{1 + exp[(EF − EF)/kT]} = 1/(1 + e0) = 1/2

所以只要知道 E_F 的位置，就知道哪个能量有一半概率被占据。反过来，实验中测到 f = 1/2 的能量点，那就是 E_F。

课件第 31 页特别提醒了一句容易被忽略的话：费米能级不一定对应一个真实存在的能级。它只是一个统计学的参考水位，完全可以落在禁带里——而半导体在室温下正是这种情况（E_F 位于禁带中，所以导带里 f 很小、价带里 1−f 很小，载流子才少）。

3.5 玻尔兹曼近似：把分布函数变成指数

当 E − E_F ≫ kT（比如比 E_F 高 3 个 kT 以上）时，exp[(E−E_F)/kT] ≫ 1，分母里的 1 可以忽略：

fF(E) ≈ exp[−(E − EF)/kT]， 当 E − EF ≫ kT(1-14)

玻尔兹曼近似（非简并条件）。它把费米分布退化成玻尔兹曼分布，后面所有载流子浓度公式都靠它变简单。

近似带来的误差：当 E − E_F = 3kT 时，f 的真实值与近似值相差约 5%；4kT 时约 2%。工程上要求掺杂浓度低于 N_c 的 1/10 左右（对硅约 10¹⁸ cm⁻³ 以下），近似就足够好。超过这个掺杂浓度叫简并，费米能级进入导带，玻尔兹曼近似失效，必须用费米积分——这正是重掺杂发射区、欧姆接触里发生的事。

【一句话记住】

非简并看 3kT：E 比 E_F 高 3kT 以上，就可以放心用指数近似

3.6 量级核对：座位有 10²¹ 个，为什么只坐 10¹⁰ 个人

到这里三个公式都齐了：g_c(E)、f_F(E)、n₀ = ∫g_c f_F dE。但把它们代进具体数字之前，很多人会对「10²¹」和「10¹⁰」这两个数相差 11 个数量级感到不安——是不是公式写错了？这一小节专门做一次量级核对，把差距一笔一笔算清楚。做完之后，你会对「半导体为什么是半导体」有一个数字化的感觉。

第一步，数座位。 把 m_n* = 1.08 m₀、ħ、h 代进 g_c 的系数，并注意把能量单位从 J 换成 eV，得到硅在 300 K 的数值形式：

gc(E) = 7.6×1021√(E − Ec) cm−3eV−1 （Si，300 K，E 以 eV 计）(1-15)

导带态密度的数值形式。E_c 上方 0.1 eV 处 g_c = 2.4×10²¹ cm⁻³eV⁻¹，与自测题 1 的答案一致。

这个系数说明：在 E_c 上方 1 eV 处，每 eV 有 7.6×10²¹ 个座位。可电子实际只会占据带边以上几个 kT 的范围，所以要看的是「窗口内的座位数」——把 g_c 从 E_c 积到 E_c + 3kT（3kT = 0.0777 eV）：

∫E_cE_c+3kT gc dE = (2/3) × 7.6×1021 × (0.0777)3/2 ≈ 1.1×1020 cm−3(1-16)

导带底以上 3kT 窗口内的总座位数。√x 的积分给出 2/3 这个因子。

即 10²⁰ 个座位——这个数接近硅原子密度 5×10²² 的 1/500，完全合理：每个原子贡献几个价电子，能带展开成 10 eV 量级，摊到每 eV 就是 10²¹ 量级。座位数没有问题，它就该这么大。

第二步，算上座率。 本征硅的费米能级在禁带中央附近，E_c − E_F ≈ 0.56 eV。代入玻尔兹曼因子：

exp[−(Ec − EF)/kT] = exp(−0.56/0.0259) = exp(−21.6) = 4.1×10−10(1-17)

本征硅的上座率。21.6 个 kT 的势差，换来 10 个数量级的抑制——这就是「半导体」三个字的定量含义。

于是 n₀ = N_c × 4.1×10⁻¹⁰ = 2.8×10¹⁹ × 4.1×10⁻¹⁰ = 1.1×10¹⁰ cm⁻³，与 n_i = 1.5×10¹⁰ 同量级（差的那一点来自有效质量与带隙参数的取整，§4.4 的易错框已经说明）。座位 10²⁰、上座率 10⁻¹⁰、人数 10¹⁰：三个数字严丝合缝。

所以差距不是来自「态密度算大了」，而是全部来自费米分布的指数因子。这也顺便解释了为什么掺杂能如此有效地改变导电性：掺杂不改变座位数（g_c、N_c 与掺杂无关），它只挪动 E_F。E_F 上移 60 meV，指数因子就变 10 倍，载流子浓度就变 10 倍。从「数座位」到「挪水位」，这就是第三节与第五节的接力点。

图 1-5　载流子浓度 = 态密度 × 占据概率，图中阴影面积就是 n₀ 与 p₀（课件第 47 页）

课件第 47 页这张图是全章最好的一张总结图。左侧 E 轴上有两条抛物线 g_c(E)、g_v(E)，中间是费米分布 f_F(E)（虚线）与 1 − f_F(E)；右侧的两块阴影是乘积 g_c f_F 与 g_v(1 − f_F)，阴影的面积就是 n₀ 与 p₀。看图能读出两点：① 座位曲线很「胖」，但乘上指数衰减的 f 后只有靠近带边的一薄层有贡献，所以 n₀ 几乎完全由 E_c − E_F 决定；② E_F 上下移动时两块阴影一个变大一个变小、乘积不变——这就是 n₀p₀ = n_i² 的几何含义。

最后给一把「换算尺」：300 K 下，E_F 相对带边每移动 59.6 mV，载流子浓度变 10 倍；移动 0.1 eV 变约 47 倍；移动 0.2 eV 变约 2200 倍；移动 0.3 eV 变约 10⁵ 倍。这几个数在后面的 PN 结、BJT 里会反复用到，建议直接背下来——它比公式好用，因为不用按计算器。座位 10²¹/eV、上座率 10⁻¹⁰、人数 10¹⁰：三个数量级一乘，半导体的「半」就出来了。

3.7 简并与非简并：玻尔兹曼近似什么时候会坏

前面所有浓度公式都建立在玻尔兹曼近似 f ≈ exp[−(E−E_F)/kT] 上。这个近似不是永远成立：它要求 E − E_F ≫ kT。如果掺杂很重，E_F 被推到导带附近甚至进入导带，那么导带底附近 E − E_F 只有几个 kT、甚至为负，分母里的 1 就不能再丢——这时必须用精确的费米分布，积分变成费米-狄拉克积分，只能数值求解。这种状态叫简并（degenerate），材料叫简并半导体。

为什么要在意？因为现代器件里每一个「好」性能几乎都靠重掺杂：MOS 的源漏、BJT 的发射区、二极管的欧姆接触，掺杂都在 10¹⁹—10²¹ cm⁻³，全部是简并的。用非简并公式去算这些区域，误差可以到几倍甚至一个数量级；而发射区少子浓度算错一倍，BJT 的电流增益就错一倍。所以这不是数学洁癖，是必须过的关。

定量判据。 要求近似误差小于约 5%，需要 E − E_F ≥ 3kT。取导带底 E = E_c，得到第一条判据：

Ec − EF ≥ 3kT （非简并判据，300 K 时约 0.078 eV）(1-18)

玻尔兹曼近似的适用条件。3kT 处误差约 5%，4kT 处约 2%；工程上取 3kT 已经够用。

把 n₀ = N_c exp[−(E_c−E_F)/kT] 代进去，就得到一条只用掺杂表示的等价判据：

n0 ≤ Nce−3 ≈ 0.05Nc （等价写法，硅约 1.4×10¹⁸ cm⁻³）(1-19)

把 3kT 判据翻译成浓度判据。硅 300 K：0.05 × 2.8×10¹⁹ = 1.4×10¹⁸ cm⁻³。

教材里更常引用的是宽松版 N_D ≤ 0.1N_c ≈ 2.8×10¹⁸ cm⁻³——它对应 2.3kT，误差约 10%。两个版本都对，差别只在「允许多大误差」。工程上把 10¹⁸ cm⁻³ 当作硅的经验分界线：低于它按非简并算，高于它必须警惕；到 10¹⁹ 以上则一律用费米积分。注意判据里的 N_c 是「该温度下」的 N_c：温度升高 N_c 变大，判据随之放宽。

精确的写法是费米-狄拉克积分。定义 η = (E_F − E_c)/kT，则电子浓度写成：

简并区的精确表达式。F_{1/2} 为 1/2 阶费米积分；η ≪ −3 时退化为 e^η（即玻尔兹曼近似）。

1/2 阶费米积分 F(η) 的形状是关键：η 很负时按 e^η 指数增长（座位远没坐满），η 过零后增长明显变慢（带底座位开始被占满，泡利阻塞起作用），η 很大时改按 η 的 3/2 次方（幂律）增长。「增长变慢」正是简并的标志：再多的掺杂也不能让载流子按指数增长，因为带底的座位已经坐满了——重掺杂发射区、接触区的电阻不能无限降低，根本原因就在这里。

重掺杂的两个必然后果

发射区：BJT 的发射区掺杂到 10²⁰ 以上，E_F 深入导带，必须用费米积分算 n₀；同时重掺杂会让禁带有效变窄（带隙收缩，bandgap narrowing，简称 BGN），相当于 n_i 变大、少子浓度变高，于是发射效率下降。所以发射区不是越重越好，工程上卡在 10²⁰ 附近是有原因的。

欧姆接触：金属-半导体接触要「欧姆」，最现实的办法是把半导体一侧重掺杂到简并（>10¹⁹），让耗尽层薄到几 nm，载流子直接隧穿而不是翻越势垒——接触电阻因此降几个数量级。这就是为什么所有芯片的接触孔下面都要打一层 n⁺ 或 p⁺。

【易错提醒】

· 简并不等于「载流子多到像金属」。简并只是说 E_F 进了能带、玻尔兹曼近似失效；载流子仍是 10¹⁹—10²⁰，比金属的 10²² 少两个数量级，电阻率仍比金属高几个数量级。

· 用 n₀ = N_c exp[−(E_c−E_F)/kT] 反算简并区的 E_F，会得到偏大的距离（几十 meV 的误差）；要报 E_F 就必须用费米积分。

· 判据里的 N_c 是「该温度下」的 N_c，不是 300 K 的常数。温度升高 N_c 变大，同一条 N_D 会从简并退回非简并。

【一句话记住】

E_c 到 E_F 不到 3kT，就别说「非简并」；硅的分界线在 10¹⁸ cm⁻³ 量级，10¹⁹ 以上一律用费米积分。

4 第四节：平衡载流子浓度——本章的核心公式

4.1 先讲为什么：所有器件参数都要用 n₀ 和 p₀

PN 结的内建电势里有 ln(N_A N_D/n_i²)；二极管的反向饱和电流里有 n_p0 = n_i²/N_A；MOS 阈值电压里有 φ_F = (kT/q)ln(N_A/n_i)。这些量的共同源头，就是本节要算的 n₀ 和 p₀。

4.2 它怎么来的：从积分到指数式，只差一步近似

载流子浓度 = 态密度 × 占据概率，对整个能带积分：

n0 = ∫E_{c}∞ gc(E) fF(E) dE， p0 = ∫−∞E_{v} gv(E)[1 − fF(E)] dE(1-21)

注意空穴用的是未被占据的概率 1−f：价带里空着的座位才是空穴。

这两个积分没有解析解。做两步处理：第一，用玻尔兹曼近似把 f 换成指数；第二，把 g(E) 的平方根形式和指数一起积分，结果全部收敛到两个只与温度有关的常数——有效态密度 N_c 和 N_v：

Nc = 2(2π mn* kT/h2)3/2， Nv = 2(2π mp* kT/h2)3/2(1-22)

有效态密度：把随能量变化的座位数积分成一个等效的总座位数，单位 cm⁻³。300 K 硅：N_c = 2.8×10¹⁹，N_v = 1.04×10¹⁹。

n0 = Nc exp[−(Ec − EF)/kT]， p0 = Nv exp[−(EF − Ev)/kT](1-23)

本章最重要的两个式子。指数里是费米能级离带边多远：E_F 越靠近 E_c，电子越多；越靠近 E_v，空穴越多。

从积分到指数式（PPT 跳过的一步）

以电子为例，把 g_c 与玻尔兹曼近似的 f 代入：

n0 = ∫E_{c}∞ 4π(2mn*)3/2/h3 √(E−Ec) · exp[−(E−EF)/kT] dE

令 x = (E−E_c)/kT，则 √(E−E_c) = √(kT)·√x，dE = kT dx，指数拆成 exp[−(E_c−E_F)/kT]·exp(−x)：

n0 = 4π(2mn*)3/2/h3 · (kT)3/2 exp[−(Ec−EF)/kT] · ∫0∞ √x e−x dx

而 ∫₀^∞ √x e^(−x) dx = √π/2。把它并进前面的常数，正好得到 N_c 的表达式，于是 n₀ = N_c exp[−(E_c−E_F)/kT]。

要点：这个积分之所以能分离变量，是因为用了玻尔兹曼近似；一旦用精确的费米分布，积分就变成费米-狄拉克积分，只能数值求解。

注意 n₀ 与 p₀ 的乘积里，E_F 被消掉了：

n0 p0 = Nc Nv exp[−(Ec − Ev)/kT] = Nc Nv exp(−Eg/kT)(1-24)

E_c − E_v ≡ E_g。这个乘积只与材料和温度有关，与掺杂、与 E_F 都无关——这就是质量作用定律。

4.3 本征载流子浓度 n_i：不掺杂时自然有多少

本征（intrinsic）半导体指纯净、无杂质、无缺陷的单晶。热激发每产生一个导带电子，就在价带留下一个空穴，所以 n = p ≡ n_i。代入质量作用定律：

ni = √(Nc Nv) exp(−Eg/2kT)(1-25)

本征浓度。室温硅 n_i = 1.5×10¹⁰ cm⁻³；GaAs 1.8×10⁶；Ge 2.4×10¹³。注意指数上是 E_g/2kT，不是 E_g/kT。

n0 p0 = ni2(1-26)

质量作用定律的最简形式：无论怎么掺杂，平衡态下电子与空穴浓度的乘积恒等于 n_i²。

n_i 对温度极其敏感：N_c、N_v ∝ T^{3/2}，而指数项 exp(−E_g/2kT) 主导。硅从 300 K 升到 350 K，n_i 大约涨 28 倍；升到 400 K 涨得更多。这就是为什么高温下掺杂决定的导电性会被本征激发淹没——器件有最高工作温度。

ni ∝ T3/2 exp(−Eg/2kT)

温度依赖：指数项是主角，T^{3/2} 只是配角。E_g 越大，n_i 越小，器件越耐高温。

为什么宽禁带材料能做高温、高压器件

SiC（E_g = 3.2 eV）、GaN（3.4 eV）的 n_i 比硅小十几个数量级，本征激发要到几百度才起来；同时它们的临界击穿电场比硅高一个数量级，同样耐压下耗尽层可以做得更薄、掺杂更高，器件更小、导通电阻更低。

代价是：宽禁带材料的欧姆接触难做（势垒高）、迁移率往往较低、工艺成本高。

4.4 例题：三个必会的手算

题 1　已知硅在 300 K 掺入 N_D = 10¹⁶ cm⁻³ 的磷，求 n₀、p₀ 以及 E_c − E_F。

解：室温下施主完全电离，且 N_D ≫ n_i，故多子浓度由掺杂决定：n₀ ≈ N_D = 10¹⁶ cm⁻³。

由质量作用定律求少子：

p0 = ni2/n0 = (1.5×1010)2/1016 = 2.25×104 cm−3

由 n₀ = N_c exp[−(E_c−E_F)/kT] 反解：

Ec − EF = kT ln(Nc/n0) = 0.0259 × ln(2.8×1019/1016) = 0.0259 × 7.94 = 0.206 eV

点评：E_F 在 E_c 下方 0.206 eV，仍深在禁带内（E_g = 1.12 eV），说明非简并假设成立，用玻尔兹曼近似是自洽的。另外注意 p₀ 只有 2×10⁴ cm⁻³——比 n₀ 小 12 个数量级，多子近似完全够用。

题 2　同上一块硅，温度升到 350 K，估算 n_i 变成多少？此时掺杂还管用吗？

解：用比例式消掉未知常数：

ni(350)/ni(300) = (350/300)3/2 exp[−(Eg/2k)(1/350 − 1/300)]

其中 E_g/2k = 1.12/(2×8.617×10⁻⁵) = 6499 K，指数部分为 exp[−6499×(−4.762×10⁻⁴)] = exp(3.095) = 22.1；温度因子 (1.1667)^{3/2} = 1.26，故比值约 27.9。

ni(350) ≈ 1.5×1010 × 27.9 ≈ 4.2×1011 cm−3

点评：n_i 仍远小于 10¹⁶，掺杂依然主导，器件工作正常。经验判据是 n_i 接近掺杂浓度时器件失效；硅功率器件的 150—175 ℃ 上限就是这么来的（那时 n_i 已到 10¹³—10¹⁴，接近轻掺杂漂移区的浓度）。

题 3　一块硅样品测得 E_F 位于 E_i 上方 0.30 eV，它是 n 型还是 p 型？多子浓度多少？

解：E_F 高于本征能级 E_i ⇒ 电子多于空穴 ⇒ n 型。由 n₀ = n_i exp[(E_F−E_i)/kT]：

n0 = 1.5×1010 × exp(0.30/0.0259) = 1.5×1010 × 1.06×105 ≈ 1.6×1015 cm−3

点评：E_F 每上升 0.0259 V（一个 kT），载流子浓度就乘 e ≈ 2.718。所以费米能级移动 60 mV、浓度变 10 倍——这条经验在后面的 PN 结、BJT 里反复用到（60 mV/decade）。

【易错提醒】

· 把 n_i² = N_cN_v exp(−E_g/kT) 写成 exp(−E_g/2kT)，漏掉平方 —— 记住：乘积是 E_g，开方才是 E_g/2。

· 用 N_c、N_v、E_g = 1.12 反算 n_i，会得到约 7×10⁹ cm⁻³，与实测 1.5×10¹⁰ 差一倍。这不是你算错，而是教材参数取整（真实有效质量与带隙的温度修正所致）。做题时若题目给了 n_i，就用给的 n_i。

· n₀p₀ = n_i² 只在热平衡下成立；加偏压后有过剩载流子，乘积会大于 n_i²（这正是二极管能发光、能复合的原因）。

4.5 例题：三个进阶手算

前三个例题都是「由掺杂算浓度」。真实工作里更多是反过来的：由电学测量反推掺杂、比较两种材料、检验近似是否成立。下面三个题各练一种，都是后面章节的常用动作。

题 4（反算掺杂）　300 K 硅样品，由电容-电压测量得到 E_c − E_F = 0.20 eV。求电子浓度与施主浓度（假设完全电离，n₀ ≈ N_D）。

解：先确认非简并条件：0.20 eV / 0.0259 eV = 7.7 个 kT，远大于 3kT，玻尔兹曼近似可用。由 n₀ = N_c exp[−(E_c−E_F)/kT]：

n0 = 2.8×1019 × exp(−0.20/0.0259) = 2.8×1019 × exp(−7.72)

exp(−7.72) = 4.43×10−4 ⇒ n0 = 1.24×1016 cm−3

完全电离且 n₀ ≫ n_i，故 N_D ≈ n₀ = 1.2×10¹⁶ cm⁻³。

验算：p₀ = n_i²/n₀ = 2.25×10²⁰/1.24×10¹⁶ = 1.8×10⁴ cm⁻³，比 n₀ 小 12 个数量级，多子近似成立；再代回 E_c − E_F = kT ln(N_c/n₀) = 0.0259 × ln(2.26×10³) = 0.20 eV ✓

点评：这就是工艺线上「用 C-V 反推掺杂」的标准流程。关键是先判断能不能用非简并公式——7.7kT 安全；如果测到 E_c − E_F 只有 0.05 eV（1.9kT），就必须改用费米积分，否则 N_D 会算小一半。

题 5（材料对比）　用 n_i = √(N_cN_v) exp(−E_g/2kT) 估算 300 K 下 Ge（E_g = 0.66 eV）与 GaAs（E_g = 1.42 eV）的 n_i 之比，并解释为什么 Ge 器件漏电大。

解：写成比值，公共常数（√、k、T、h）全部消掉，只剩两项：

ni(Ge)/ni(GaAs) = [√(NcNv)]Ge/[√(NcNv)]GaAs × exp[(Eg(GaAs) − Eg(Ge))/2kT]

第一项用 N_c、N_v 的数值：Ge 为 1.04×10¹⁹ 与 6.0×10¹⁸，乘积开方得 7.9×10¹⁸；GaAs 为 4.7×10¹⁷ 与 7.0×10¹⁸，乘积开方得 1.8×10¹⁸。两者之比 7.9/1.8 = 4.4。

第二项只有带隙差：E_g 差 = 1.42 − 0.66 = 0.76 eV，除以 2kT = 0.0518 eV：

exp(0.76/0.0518) = exp(14.67) = 2.34×106

两项相乘：

ni(Ge)/ni(GaAs) = 4.4 × 2.34×106 ≈ 1.0×107

取 GaAs 的 1.8×10⁶ cm⁻³，得 n_i(Ge) ≈ 1.8×10¹³ cm⁻³，与实测 2.4×10¹³ 同量级 ✓

点评：反向饱和电流 J_s ∝ n_i²，所以同样掺杂下 Ge 二极管的漏电是 GaAs 的 (10⁷)² = 10¹⁴ 倍。这就是 Ge 晶体管在 1950 年代被硅取代的直接原因：窄带隙让漏电随温度爆炸，60 ℃ 就没法用了。反过来，窄带隙正是 Ge 的优点——红外探测、SiGe 应变工程、硅光探测器都靠它。窄带隙做探测、宽带隙做功率，GaAs/GaN/SiC 的分工就来自这条指数。

题 6（电中性）　n 型硅 N_D = 10¹⁴ cm⁻³。用严格电中性方程 n₀ = N_D + p₀ 证明多子近似成立，并求 p₀/n₀ 的比值。

解：把 p₀ = n_i²/n₀ 代入电中性方程，得到关于 n₀ 的一元二次方程：

n02 − NDn0 − ni2 = 0 ⇒ n0 = [ND + √(ND2 + 4ni2)]/2

代入 N_D = 10¹⁴、n_i² = 2.25×10²⁰（故 4n_i² = 9.0×10²⁰，而 N_D² = 10²⁸）：

√(1028 + 9×1020) ≈ 1014[1 + (9×1020)/(2×1028)] = 1014(1 + 4.5×10−8)

n0 ≈ 1014(1 + 2.25×10−8) cm−3， p0 = ni2/n0 = 2.25×106 cm−3

p0/n0 = 2.25×106/1014 = 2.25×10−8

点评：少子比多子小 8 个数量级。把 p₀ 从电中性方程里丢掉，相对误差是 2.25×10⁻⁸——比任何工艺误差都小 6 个数量级，所以 N_D ≫ n_i 时多子近似永远安全。

什么时候不安全？ 当 N_D 接近 n_i 时。取 N_D = 2×10¹⁰：n₀ = (2×10¹⁰ + √(4×10²⁰ + 9×10²⁰))/2 = 2.80×10¹⁰，p₀ = 8.0×10⁹，p₀/n₀ = 0.29——少子和多子同量级，n₀ ≈ N_D 完全不成立。所以判据是 N_D ≫ n_i，工程上要求 N_D > 100n_i（即 > 1.5×10¹²，任何实际掺杂都满足）。这也从另一面说明了 §4.3 的「本征化」：当温度把 n_i 抬到和 N_D 一样高时，掺杂就不再能定义材料类型了。

4.6 费米能级往哪走：掺杂与温度的两个方向

前面所有计算都用同一个套路：先知道 E_F，再算 n₀。可实际工作中常常反过来——工艺给了掺杂，E_F 自己会跑到一个位置；而且这个位置随温度变，器件参数（V_bi、阈值电压、J_s）就跟着变。所以必须掌握 E_F 的「走向」：掺杂让它动，温度让它动，两者方向往往相反。

掺杂的作用方向。 掺入施主等于往导带里加电子，费米能级必须上移（更靠近 E_c）才能容纳更多电子；掺入受主则 E_F 下移。定量关系由 n₀ = n_i exp[(E_F−E_i)/kT] 直接反解得到：

EF − Ei = kT ln(n0/ni) ≈ kT ln(ND/ni) （n 型，ND ≫ ni）(1-27)

费米能级相对本征能级的位置。等号右边为正 ⇒ n 型；为负 ⇒ p 型（p 型把 N_D 换成 N_A 并取负号）。

这条式子是本章最实用的「导航仪」：知道掺杂和温度，就能立刻说出 E_F 在 E_i 上方还是下方、离多远。它同时给出三条快速判据：

① 符号判据：E_F > E_i ⇒ n 型；E_F < E_i ⇒ p 型；E_F = E_i ⇒ 本征。因为 E_F 高于本征能级就意味着电子比空穴多（n₀ = n_i e^{Δ/kT} > n_i > p₀）。

② 距离判据：E_F 离 E_c 越近，掺杂越重。对硅，E_c − E_F ≈ 0.20 eV 对应约 10¹⁶，0.10 eV 对应约 6×10¹⁷，进入导带（< 0 eV）就是简并。反过来，0.4 eV 以上对应 10¹⁴ 以下的轻掺杂。

③ 温度判据：温度升高，n_i 指数增大，E_F 向 E_i 靠拢；当 n_i 与 N_D 可比时 E_F ≈ E_i，材料本征化。判据是 n_i(T) 接近 N_D，而不是某个固定温度。

为什么温度升高 E_F 会向 E_i 靠拢？ 把 E_F − E_i = kT ln(N_D/n_i) 看成两项的乘积：前面的 kT 随 T 线性增大（把 E_F 推离 E_i），后面的 ln(N_D/n_i) 随 T 指数减小（把 E_F 拉回 E_i）。指数项永远赢，所以总效果是拉回。直觉上：温度越高，热激发越猛，掺杂提供的那些电子相对就不重要了，费米能级退回到「本征水位」。把 n_i(T) 的表达式代进去，可以看得更清楚：

EF(T) − Ei(T) = kT ln[ND/ni(T)]， ni(T) ∝ T3/2exp(−Eg/2kT)(1-28)

温度依赖的显式形式。n_i 的指数增长主导，所以括号里的值随 T 迅速变小，E_F 单调地靠近 E_i。

定性曲线：以 N_D = 10¹⁶ cm⁻³ 的 n 型硅为例，把 E_F 画成温度的函数（纵轴 E_F 相对 E_c 的位置），会看到三段：

• 低温段（约 100 K 以下）：杂质冻析（freeze-out），施主只部分电离，导带电子很少，E_F 靠近甚至高于施主能级，随温度升高而下降（因为电离度上升）。这一段器件一般不工作，但低温实验里必须考虑。

• 中温段（约 100—450 K）：完全电离，n₀ ≈ N_D 恒定，而 n_i 随 T 指数上升，所以 E_F 从 E_c 下方 0.21 eV 缓慢下移、逐渐靠近 E_i。这一段是器件的正常工作区，也是所有教材例题默认的区间。

• 高温段（约 500 K 以上）：n_i 接近甚至超过 N_D，E_F 逼近 E_i，掺杂失效，n₀ ≈ p₀ ≈ n_i，材料本征化。硅器件的 150—175 ℃ 上限就落在这一段的起点（§4.4 题 2 已经算过：350 K 时 n_i 才 4×10¹¹，还差得远；但功率器件的漂移区掺杂只有 10¹³—10¹⁴，本征化来得早得多）。

题 7（温度移动）　N_D = 10¹⁶ cm⁻³ 的硅，求 400 K 时 E_F 相对 E_i 的位置，并与 300 K 比较。

解：先算 400 K 的 n_i，用与题 2 相同的比例式（这样公共常数全部消掉）：

ni(400)/ni(300) = (400/300)3/2exp[−(Eg/2k)(1/400 − 1/300)]

其中 E_g/2k = 6499 K，1/400 − 1/300 = −8.333×10⁻⁴，故指数为 exp[−6499×(−8.333×10⁻⁴)] = exp(5.416) = 225；温度因子 1.5396。两者相乘得 346：

ni(400) = 1.5×1010 × 346 = 5.2×1012 cm−3

400 K 的热电压 kT/q = 0.0259 × 400/300 = 0.0345 V，代入导航式：

EF − Ei = 0.0345 × ln(1016/5.2×1012) = 0.0345 × ln(1923) = 0.0345 × 7.56 = 0.261 eV

作为对照，同样材料在 300 K：0.0259 × ln(10¹⁶/1.5×10¹⁰) = 0.0259 × 13.41 = 0.347 eV。

点评：温度从 300 K 升到 400 K，E_F 从 E_i 上方 0.347 eV 降到 0.261 eV——下移 86 mV，方向朝 E_i。同时 E_c − E_F 从 0.206 eV 变到 0.29 eV（E_c − E_i ≈ 0.55 eV 基本不变），所以 n₀ 仍约 10¹⁶（多子几乎不动）；但少子 p₀ = n_i²/N_D 从 2.25×10⁴ 涨到 2.7×10⁹，涨了 5 个数量级。温度几乎不动多子，只动少子——这正是第 3 章里 J_s ∝ n_i² 随温度暴涨的根源。

这里有两个高频误解要当场纠正。第一，「E_F 上移」不等于「电势升高」：E_F 是电子能量，上移意味着电子更多、材料更 n 型，电子的静电势反而是降低的（第 2 章 PN 结里 E_Fn 画得比 E_Fp 高，但 n 区电势更高，就是这个道理）。第二，不要以为「温度升高、载流子变多，所以 E_F 一定上移」——n 型材料的 E_F 是下移、朝 E_i 靠拢；p 型材料则上移、也朝 E_i 靠拢，方向都是「回中间」。

【一句话记住】

掺杂把 E_F 推离 E_i，温度把它拉回 E_i；多子看掺杂，少子看温度。

5 第五节：掺杂——把纯净变成有用

5.1 先讲为什么：本征硅的导电能力太弱

本征硅在室温下 n_i = 1.5×10¹⁰ cm⁻³，而硅原子本身有 5×10²² cm⁻³。载流子占比只有 10⁻¹²，电阻率高得没法做器件。掺杂（doping）就是有控制地掺入百万分之一量级的杂质，把载流子浓度提高 4—6 个数量级，同时决定导电类型。掺杂是半导体工业的灵魂：同一块硅片，靠不同区域的掺杂类型和浓度，就能做出 PN 结、晶体管、电阻、电容

5.2 施主：V 族原子多一个电子

磷（P）、砷（As）、锑（Sb）有 5 个价电子。替位进入硅晶格后，4 个电子参与成键，多出 1 个电子。这个电子只受磷原子核的微弱库仑吸引，只需很小的能量（硅中约 0.045 eV）就能跃迁到导带，成为自由电子。这种杂质叫施主（donor），它给电子、不产生空穴，所以得到的材料叫 n 型（n 指 negative）。

施主电离后自己变成带正电的离子（固定不动），而电子进入导带参与导电。能带图上，施主能级 E_d 画在 E_c 下方很近处（硅中 E_c − E_d ≈ 0.045 eV，室温 kT = 0.0259 eV，所以几乎全部电离）。

图 1-6　施主能级 E_d 位于 E_c 下方很近处，电子容易跃入导带（课件第 55 页）

5.3 受主：III 族原子少一个电子

硼（B）、铝（Al）、镓（Ga）、铟（In）只有 3 个价电子。替位后有一个共价键缺电子，形成一个空位；邻近键上的电子很容易跳过来填补，于是在原位置留下一个空穴。这种杂质叫受主（acceptor），它接受电子、等效于产生空穴，材料叫 p 型（p 指 positive）。

受主能级 E_a 画在 E_v 上方很近处（硅中 E_a − E_v ≈ 0.045 eV）。价带电子跳到 E_a 上被硼原子捕获，价带里留下空穴。电离后的受主带负电，同样固定不动。

【易错提醒】

· 离子不动、载流子动。施主/受主电离后成为晶格中的固定电荷，它们不贡献电流，但贡献空间电荷——这正是 PN 结耗尽层的电荷来源。

· 掺杂浓度写成 N_D、N_A（D = donor，A = acceptor）；不要把 N_D 与 n₀ 混为一谈——只有完全电离且 N_D ≫ n_i 时才有 n₀ ≈ N_D。

5.4 完全电离与多子近似：工程上怎么用

课件第 8 页（第 7 章开头）把两条基本假设讲得很清楚：① 玻尔兹曼近似成立（非简并）；② 杂质完全电离（温度不能太低）。满足这两条，n 型材料就有 n₀ ≈ N_D、p₀ ≈ n_i²/N_D；p 型材料反过来。

n0 ≈ ND， p0 ≈ ni2/ND （n 型，ND ≫ ni）

多子由掺杂决定，少子由质量作用定律决定。p 型对称：p₀ ≈ N_A，n₀ ≈ n_i²/N_A。

为什么可以这样近似？以 n 型为例，电中性要求 n₀ = N_D⁺ + p₀；完全电离时 N_D⁺ = N_D，而 p₀ 比 n₀ 小十几个数量级，所以 n₀ ≈ N_D 的误差可以忽略。这种只留最大项的做法，在后面每一章都会用到。

6.1 核心结论（背下来）

① 半导体与绝缘体的区别只有 E_g 大小：E_g 小到室温能激发少量电子-空穴对，就是半导体。

② 载流子 = 座位 × 上座率：n = ∫g_c(E)f(E)dE，p = ∫g_v(E)[1−f(E)]dE。所有浓度公式都是这一句话的展开。

③ f(E_F) = 1/2 与温度无关，这是定位费米能级最快的办法。

④ n₀p₀ = n_i² 与掺杂无关：掺多子必然压少子，乘积锁死在 n_i²。

⑤ n_i 对温度指数敏感：E_g 越大越耐高温，宽禁带材料因此适合功率与高温应用。

⑥ 掺杂决定类型，温度决定上限：室温靠掺杂，高温靠本征，两者的交叉点就是器件的温度极限。

⑦ E_F 每移动 60 mV，载流子浓度变化 10 倍（300 K 下 ln10 × kT/q = 0.0596 V），这条经验贯穿全书。

⑧ 离子不动、载流子动：离化的施主/受主是空间电荷的来源，不参与导电。

⑨ 有效质量决定一切：m* = ħ²/曲率，它同时定态密度（座位数）与迁移率（跑多快）；小 m* 的材料座位少但速度快。

⑩ 重掺杂要换公式：E_c − E_F 不到 3kT（硅约 10¹⁸ cm⁻³ 以上）就是简并，必须用费米积分，发射区与欧姆接触全在这一区。

【一句话记住】

数座位（DOS）× 算上座率（费米分布）= 载流子浓度；掺杂挪水位，温度改斜率。

7 自测题（含详解）

1. 硅在 300 K 时 N_c = 2.8×10¹⁹ cm⁻³。求 E_c 上方 0.10 eV 处的态密度 g_c 的值。

2. 一块 n 型硅，N_D = 5×10¹⁵ cm⁻³，室温下求 n₀、p₀ 及 E_F 相对 E_i 的位置。

3. 判断题：温度升高时，本征载流子浓度增大，因此 n 型硅的电子浓度也一定增大。

4. 为什么说费米能级落在禁带里并不矛盾？它对半导体意味着什么？

5. 用玻尔兹曼近似计算 E − E_F = 2kT 处的占据概率，并与精确值比较，求相对误差。

6. 一块硅样品的 E_F 位于 E_c 下方 0.15 eV。判断它是否简并，并估算 n₀。

7. Al_xGa_{1−x}As 中 x = 0.3，求 E_g 与对应的发光波长；x 超过多少时变成间接带隙？

8. 为什么「掺杂越重、电阻率越低」这句话在 10²⁰ cm⁻³ 以上不再成立？给出两个原因。

参考答案

1. 用比值法最省事：g_c(E) = 4π(2m_n*)^{3/2}/h³ · √(E−E_c)，在 300 K、m_n* = 1.08m₀ 时该系数为 7.6×10²¹ cm⁻³eV⁻¹（E 以 eV 计）。代入 √0.10 = 0.316 得 g_c ≈ 2.4×10²¹ cm⁻³eV⁻¹。

2. n₀ ≈ N_D = 5×10¹⁵ cm⁻³；p₀ = n_i²/n₀ = (1.5×10¹⁰)²/5×10¹⁵ = 4.5×10⁴ cm⁻³；E_F − E_i = kT ln(n₀/n_i) = 0.0259 × ln(5×10¹⁵/1.5×10¹⁰) = 0.0259 × 12.72 = 0.329 eV（E_F 在 E_i 上方）。

3. 错。n₀ 由电中性条件 n₀ = N_D + p₀ 决定，室温下 n₀ ≈ N_D 几乎不变；温度升高只让 p₀（少子）按 n_i²/N_D 迅速增大。直到 n_i 接近 N_D（硅约 200 ℃ 以上），n₀ 才显著偏离 N_D——这叫本征化。

4. 费米能级是统计分布的参考水位，不是必须存在的量子态。半导体在室温下 E_F 就在禁带中（g(E) = 0），所以 E_F 处没有电子完全正常。它的意义是：E_F 离 E_c 越近，导带占据概率越大，电子越多。

5. 近似值 f ≈ exp(−2) = 0.1353；精确值 f = 1/(1+e²) = 1/8.389 = 0.1192。相对误差 = (0.1353−0.1192)/0.1192 ≈ 13.5%。可见 2kT 处近似误差还很大，工程上要求 3kT 以上（3kT 处误差约 5%）。

6. 先换成 kT 的倍数：0.15/0.0259 = 5.8kT > 3kT，所以是非简并，玻尔兹曼近似可用。n₀ = 2.8×10¹⁹ × exp(−5.8) = 2.8×10¹⁹ × 3.0×10⁻³ = 8.5×10¹⁶ cm⁻³。自洽性检查：8.5×10¹⁶ < 1.4×10¹⁸（3kT 判据的上限），确实落在非简并区。若 E_c − E_F 只有 0.05 eV（1.9kT），就必须改用费米积分，否则 n₀ 会算小一半以上。

7. 由直接带隙段的线性式：E_g = 1.424 + 1.247×0.3 = 1.798 eV。对应波长 λ(μm) = 1.24/E_g(eV) = 1.24/1.798 = 0.690 μm，即 690 nm 红光。x 超过 0.45 后导带底从 Γ 谷转到 X 谷，带隙变间接（交点处 E_g ≈ 1.98 eV，λ ≈ 626 nm），发光效率骤降——所以 AlGaAs 发光器件的组分一律卡在 x < 0.45。

8. 至少有两个原因。① 固溶度上限：硅里磷的固溶度约 10²¹ cm⁻³，再高就析出成 SiP 沉淀，电活性浓度不再上升，n 趋于饱和。② 迁移率随掺杂下降：电离杂质散射使 μ ∝ 1/N_i，ρ = 1/(nqμ) 里 n 饱和而 μ 继续降，电阻率反而回升。此外还有两个次要原因：简并后 E_F 进入导带，载流子不再随掺杂指数增长；重掺杂的带隙收缩与 Auger 复合让少子寿命骤降。结论：掺杂有最优值，不是越重越好——这也是「掺杂有最优值、不是越重越好」的由来。
